# 地下小家园（Underground Home）

面向 7 岁儿童的 2D 横截面地下家园建造与探索游戏：地表风暴迫使小伙伴搬入旧避难所，玩家通过自由挖掘、修复设施、建立地下生态，把避难所逐渐变成温暖、能运转的家园。

技术栈：**Vite + Vue 3 + TypeScript + PixiJS + Vitest**。

## 快速开始

```bash
npm install
npm run dev      # 开发服务器（默认 http://localhost:5173）
npm run build    # 类型检查（vue-tsc）+ 生产构建（输出 dist/）
npm run preview  # 预览生产构建
npm test         # Vitest 单元测试
```

## 当前状态：P2 M1 睡眠舱选址交互（待验收）

本轮先收口选址：点亮核心后选“睡眠舱”，点一下想放小床的地面，就会以点击格为舱体底边中心显示预览；预览旁的短句和绿／红轮廓会说明能不能建。选中后可以再点别处换位置，点“确认建造”落位，点“取消”或再点“睡眠舱”退出。舱底仍要有实心地面，侧门连通家园；不能压住核心、入口或堵住已有舱门。左侧能源石旁、右侧软土都可自由选址，没有固定建造点。粗版不消耗建造资源。

本阶段只开放第一间睡眠舱：建成后建造工具收起，避免出现无人使用的空舱；撤销后工具恢复。建成后两位伙伴移到双人床位、闭眼休息；“撤销”支持撤回本次会话的建设和挖掘。存档仍为v3，v1 / v2自动迁移并保留原地图及点灯进度。睡眠舱任务按实际设施判断，拆回后会回到待建设状态。

造型暂用程序化示意，伙伴入住仍是简易位移，不含寻路与居民AI；真正的入舱路径和睡眠反馈留到下一小步。新增点击锚点用例后现有95项测试通过，生产构建通过。本地浏览器操作被Work设置禁用，本轮尚未完成浏览器试玩或截图；下一步请先验收选址、预览、确认／取消和空间尺度。

- 可启动、可构建、可测试；模块职责分离，没有包揽全部职责的巨型 GameEngine。
- 已实现：
  - 固定小地图渲染：风暴地表、旧避难所大厅与竖井、松软泥土、坚硬岩层、未点亮时的昏暗地下灯光；
  - 初始镜头一眼看到避难所、能源核心与左侧能源石区；单击挖一格（严格单格）；拖动平移；缩放；悬停高亮；鼠标指针随区域变化；
  - 小鼹鼠阿土：一句短话只说当前唯一目标 + "做完会怎样"，配"带我去看看"（只移动镜头）；
  - 地图高亮当前目标区域（线索，不代替挖掘；小鼹鼠只给一个问题和一个真实目标）；
  - 当前主线四步：挖开泥土找到能源石 → 收集能源石 → 修复能源核心 → 自由选址安置睡眠舱；
  - 修复演出：核心启动闪烁 → 顶灯一盏一盏依次亮起 → 伙伴撒花庆祝 → 镜头自动拉开展示点亮后的家园；
  - 挖错撤销：LIFO 撤销；已挖开的能源石不会被"撤销"埋回去（避免任务状态矛盾）；
  - 带版本号的 IndexedDB 自动存档与恢复（v3，含 v1 / v2 旧档自动迁移）；损坏存档降级不白屏。
- 尚未实现（后续阶段）：睡眠舱精修、泉水、水培温室等，详见 `docs/PHASES.md`。

能源核心机身已替换为透明 PNG，保留原有三态状态灯和启动 / 点灯演出。素材、规格和生成提示词位于 `src/assets/art/landmarks/`；验证结果及截图见 [能源核心美术验收](docs/acceptance/energy-core-v1/README.md)。

能源石已接入透明 PNG，补充收集上浮和进入核心槽口的短暂演出；挖掘、任务和存档判定保持不变。详见 [能源石与安装反馈验收](docs/acceptance/crystal-v1/README.md)。

入口梯架与7盏顶灯已接入透明PNG，保留原位置、黑暗遮罩及逐盏点亮时序。详见 [梯架与顶灯美术验收](docs/acceptance/fixtures-v1/README.md)。

```
src/
  core/              纯逻辑（无 DOM / PixiJS 依赖，可单测）
    world.ts         世界数据模型与岩层蓝图（避难所、软土口袋、关键地点、进度位）
    dig.ts           挖掘规则（单格、岩石不可挖、边界保护、挖开即发现能源石）
    build.ts         睡眠舱占地、承托、侧门连通与唯一通路保护
    interact.ts      互动规则（收集能源石 / 修复能源核心的判定）
    history.ts       挖掘 / 建造LIFO撤销栈，保护能源石、设施与通路
    missions.ts      任务链定义、完成判定与地图高亮指引
    persistence.ts   v3存档：设施校验 / v1和v2迁移 / IndexedDB与内存适配器
  render/            渲染层（PixiJS）
    camera.ts        相机换算（屏幕 ↔ 世界坐标、平移、缩放约束）
    PixiRenderer.ts  瓦片地图、风暴地表、灯光过渡、伙伴、高亮与挖掘特效
    sleepPods.ts     嵌入洞壁的双人睡眠舱粗版造型
  input/             输入层
    gesture.ts       点击 / 拖动阈值判定（互不误触）
    pointerControls.ts  指针事件 → 交互意图
  app/
    session.ts       组合根：装配 world / rules / missions / persistence / render / input
  App.vue            界面壳层（小鼹鼠引导卡、任务徽章、撤销、缩放、提示、图例）
tests/               Vitest 用例（规则、互动、撤销、任务、存档、手势、相机）
```

- 人工试玩验收待完成（指引是否更清楚、点亮演出观感、初始镜头与撤销保护手感）。
