# 储物架与旧住户故事（S4 / 基线 2D）决策

> 日期：2026-10-24。分支 `zcode/storage-shelf-v1`，基于 main（含 S3）。
> 上游依据：分阶段实施方案 S4 批次；设计基线 §5.7（发现物 #6 旧照片、#7 旧钥匙）、§7.2（设施 #5 储物架）。

## 解决的问题

材料与旧物没有"看得见"的家：旧物故事只在背包弹窗里，五件旧物（原三件）互相没有关联；发现收藏系统没有故事弧。储物架是设施面板框架迎来的第一个**新设施**，也是 2D 的主体。

## 决策

1. **储物架（新设施，v15）**：第一层自由摆放的一格设施，费用石料 1 + 旧木料 2，规则与菜槽同构——有地面承托、已挖空、不压睡眠舱/房间/菜槽/其他架子，避让竖井、能源核心区、收藏架、旧物格子和预设洞室蓝图。可撤销、退材料。
2. **面板（设施框架第一个新设施）**：点架子本体打开面板——状态摘要显示石料/旧木料/旧物 n/5；主操作：旧物没挖完 →「找找没挖到的旧物」（镜头带到第一件未挖旧物旁，复用 focusRelic）；挖完了 →「翻翻旧物的故事」（打开物品栏旧物页）。次要入口「看看它」。
3. **架上摆旧物**：挖到的旧物以小图标摆上每一格架子（程序化造型：立柱 + 两层隔板 + 旧物小图标；没有旧物时摆材料示意）——"架子上摆着谁留下的东西"一眼可见。
4. **旧照片、旧钥匙（发现物 5→7）**：埋在第一层左右翼泥土里（照片 x26/y9 右翼、钥匙 x2/y9 左翼深处）；两条故事把五件旧物串成"旧住户"弧线——照片讲"这张桌子很早以前就热闹过"，钥匙为第四层旧门埋线。沿用"挖开即发现"，不进任务链。
5. **入口**：建造工具行第一层出现「📦 摆储物架」（点亮核心后）；"家里的小清单"加第四项"储物架"。不加引导链步骤（旧物不锁主线）。
6. **存档 v15**：新增 `shelves`；v14 及更早旧档按没有架子补齐；加载时校验架子站在合法空地上（校验排除自身，避免自碰）。

## 边界（不做）

- 不做容量、分类、整理玩法；架子是"看得见"的收纳，不是库存管理。
- 不加引导步骤、不加新伙伴工作；不动大厅收藏架（两者并存：收藏架在厅墙上，架子是孩子自己摆的）。
- 架子暂为程序化造型，手绘素材留待美术批次。
