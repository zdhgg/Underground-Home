# 第八章 · 旧地脉遗迹

2026-10-26。用户授权设计并实现第八章。本章把前七层的灯、水与共同建设连成故事，为第九层地心暖光终章作铺垫。继续使用九位既有伙伴，本轮没有新增伙伴或提前制作第九层。

## 完整章节

听风工区巡游完成 → 铃铃听见旧拱后的回声 → 与阿岩检查旧拱 → 安装旧拱护框 → 阿岩沿实际梯道逐格凿岩 → 阿土走进遗迹 → 阿木延长第八站电梯 → 自由选址布置岩壁拓印台、遗迹柔光灯、地脉故事壁 → 玩家任选三段原岩画的先后顺序 → 对应伙伴到场看清岩画 → 在拓印台做夹板拓印 → 阿木把这一段修复到故事壁 → 三段修复齐全 → 玩家选择“围坐家园”或“一路建家” → 确认后阿木添上九枚小爪印 → 阿土、阿灯与阿木各自实际走到故事壁前 → 同一目标面板庆祝第八章完成。

三个故事分别是阿灯的“一盏灯”、小泉的“一条水路”、阿木的“一起建造”。每段都同时讲从前住户和玩家已建成的家。已找到的旧灯罩、旧照片或旧钥匙补充相似纹样对白；没有旧收藏也能完整通关，没有密码、猜谜或收齐旧物的门槛。

原岩画留在固定的岩壁上，玩家建造的故事壁位置自由。原岩画在上方，设施交互在下方，已建设施不会遮住或吞掉原岩画入口。旧石印与旧小爪印是可选发现，故事和三份拓印进入物品栏，可定位原处；大厅相册增加第八章完成记录。

## 连续地图与设施

地图扩到 **44×100**，净空 y91—94，地板 y95，旧地脉岩盖 y83—90。前七层的前 88 行蓝图保留。既有 x16／x27 两条梯口均可接入，不分离地图，不穿岩瞬移。

| 设施／动作 | 费用 | 用途 |
| --- | --- | --- |
| 旧拱护框 | 石料 3、旧木料 2、部件 1 | 只开放新的岩盖施工 |
| 第八站电梯 | 部件 2、晶簇 1 | 新增遗迹站，旧七站继续使用 |
| 岩壁拓印台 | 石料 2、旧木料 3 | 宽 4，制作三份夹板拓印 |
| 遗迹柔光灯 | 石料 2、部件 1、晶簇 2 | 宽 1，照清旧岩画 |
| 地脉故事壁 | 石料 5、旧木料 2、部件 1 | 宽 6，逐段显示修复图案与今天一页 |
| 回忆石长凳 | 石料 2、旧木料 2 | 宽 3，可选、可反复坐一坐 |
| 每段拓印 | 旧木料 1 | 一块旧木料做夹板；不新增纸张资源链 |
| 看清／修复／添页／走走 | 无额外材料 | 到场完成后写入进度 |

四类设施各一件，可改变位置和建设顺序。只要求四格高、有实心地板、连通梯口的洞壁，保留梯口，不与其他设施重叠。后侧设施不阻断前侧人物通行。石凳不影响主线；章末后仍能换今天一页的呈现、重读故事、继续扩建、坐一坐和乘电梯。

旧拱问题只有新区域施工前的征兆与加固，不影响旧水、食物、风路和房屋，不加入倒计时、塌家、伤害或战斗。

## 单一关注对象与交接

| 情境 | 当前关注对象 | 唯一主要操作 | 退出方式 | 完成后的交接 |
| --- | --- | --- | --- | --- |
| 旧拱／岩盖 | 当前旧接缝或这一段凿岩 | 检查、护框、凿岩之一；工作中无推进按钮 | 收起、Esc、停下来 | 下一岩段或实际下楼 |
| 设施选址 | 当前设施的一个位置框 | 就在这里建造 | 收起、Esc | 建成后下一目标 |
| 原岩画 | 所选一段故事与对应伙伴 | 看清、拓印、修复之一 | 收起、Esc、停下来 | 同一面板显示故事／拓印结果，再交下一步 |
| 今天一页 | 当前故事壁与待选呈现 | 确认添上这一页 | 收起，选择意图不保存 | 阿木完成后亮出九枚小爪印，再交走走 |
| 章末走走 | 故事壁前三位实际站位 | 开始走走；途中无推进按钮 | 停下来、收起、后台取消 | 同面板庆典，继续建设 |
| 石凳／重读 | 当前石凳或一段故事 | 坐一坐或回到下一目标 | 收起、Esc | 保留已完成成果 |

故事列表、呈现选项、折叠建设与八站电梯均为辅助操作。主面板标记 `data-attention-panel`，主操作标记 `data-primary-action`；真实 App 测试覆盖状态替换、工作、庆典、全景和旧设施交接。短屏说明可内部滚动，主按钮和停止按钮固定；刷新不重复定位，动作结束不夺回玩家拖动后的镜头。

伙伴沿真实通道移动，到场完成后才扣费或写进度。取消、重复点击、过期回调、停帧、后台／离页都不能补结算；章末等待三位到不同格子。拓印、修复、建造、延长和呈现可按依赖撤销并退材料，已用通路和已发现岩画的可达性受保护。
