# 第六章 · 蓄水回廊

2026-10-25。用户授权设计和实现第六层。本次加入河狸团团与完整水工章节，第七至九层继续保留规划，第九层仍为终章。

## 章节与伙伴

花园散步完成 → 观察下方渗水岩缝 → 阿岩安装止水护框 → 逐块凿开岩盖并保留施工梯 → 阿土实际下楼 → 在左侧认识河狸团团 → 团团在当前面板自我介绍 → 延长六站电梯 → 自由建滤水口、蓄水池、分水闸、水轮 → 团团沿挖通的洞壁接管渠 → 关闸蓄水 → 玩家确认水路 → 提一格水去花园 → 提一格水去大厅 → 给团团留真实床位 → 阿土、团团、小泉到场巡游 → 第六章完成，继续建设与供水。

团团稳定身份 `tuantuan`，床位优先位 7，独特动词“筑渠”。扁尾巴、门牙和蓝绿领巾形成独立轮廓，工作使用接头和转闸轮短动作。小泉负责引水蓄水，团团负责管渠、水闸与提水，阿木负责水轮和电梯，阿岩负责入口，不挤掉原伙伴的职责。前七位伙伴的 ID、床位优先位和动词保留，原四层暖屋宴固定六位老朋友。

地图 44×76，前五层的前 64 行保留；净空 y67—70、地板 y71，岩盖施工 y59—66。x16／x27 两种旧梯口均接入。v20 存档接受真实尺寸 v16 44×28、v17 44×40、v18 44×52、v19 44×64；迁移只追加缺失蓝图并补第六层空状态。

## 建设与水循环

| 设施／工作 | 费用 | 结果 |
| --- | --- | --- |
| 止水护框 | 石料 2、旧木料 2、部件 1 | 导开新梯口的渗水，开放这一段施工 |
| 六站电梯 | 部件 2、晶簇 1 | 从真实脚下楼层出发，保留旧站与梯子 |
| 卵石滤水口 | 石料 3、旧木料 1 | 宽 3；小泉引水，嵌在后侧岩壁 |
| 嵌岩蓄水池 | 石料 5、旧木料 2、部件 1 | 宽 5；三格存水，面板与池内水位同步 |
| 双路分水闸 | 石料 2、旧木料 2、部件 1 | 宽 2；关闭／花园／大厅，一次只走一条水路 |
| 提水小水轮 | 石料 2、旧木料 3、部件 1 | 宽 4；实际提水后播放 2.5 秒轴标记与管内水珠 |
| 河狸岩壁小窝 | 石料 3、旧木料 3 | 宽 4，提供真实床位；也可复用苔苔小窝等空床 |
| 连接／转闸／蓄水／提水 | 不额外收费 | 伙伴真实走到现场工作完毕后才结算 |

四件设施各建一件，位置和顺序由玩家决定；管渠沿它们之间连续四格高的已挖空洞壁延伸到梯口，不穿岩石、不锁定唯一布局。梯口、地板、重叠、材料和通路均校验，前侧保留走路空间。小窝可选，已有空床就无需再建。

水量只属于第六层的新设施：关闸后蓄到三格，满了拒绝再蓄；切换水路不送水，转动水轮每次消耗一格。花园一次收到两次清水照料额度，最多四次；真正照料一张菌床时用掉一次，菌苗从小芽直接展开，原有光、水、菌毯条件仍需满足。撤销照料退清水，已经使用的清水不能被撤回。大厅收到水后长桌边多一瓶清水，纪念墙增加实际供水记录。

这不是全家饮水消耗系统。原第二层引水与第五层供水继续有效；没有口渴、断水、洪水、倒计时、离线衰减或流体物理。入口未加固只暂停新施工，不损坏旧家。可选发现“水纹贝印”“芦苇小穗”留在原处，物品栏记故事并可定位，不作为章末门槛。

## 关注与交接

| 情境 | 当前关注对象 | 唯一主要操作 | 退出 | 完成后交接 |
| --- | --- | --- | --- | --- |
| 渗水／施工 | 当前岩缝或阿岩这一段施工 | 检查、护框、开工中的一个；工作中无推进按钮 | 收起、Esc、停下来 | 下一段／实际下楼 |
| 相遇 | 左侧团团与旁边的阿土 | 打招呼，再读团团的介绍 | 收起、Esc | 玩家读完后进入电梯目标 |
| 选址 | 当前设施位置框 | 就在这里建造 | 收起、Esc，不扣料 | 建成反馈、下一设施 |
| 分流 | 当前分水闸 | 确认转动水闸 | 收起，尚未转闸 | 团团工作完毕后交水轮 |
| 蓄水／提水 | 当前池子或水轮 | 蓄水或提水中的一项 | 停下来、收起 | 水位变化与收水结果 |
| 巡游 | 三人实际站位 | 开始巡游；途中无推进按钮 | 停下来、收起 | 同一面板内章末庆祝 |

方向选择、六站导航与折叠建设菜单为安静辅助操作。主要面板和按钮标记 attention 契约；相遇与庆典不再同时弹出中央成就卡。短屏说明可滚动，主推进／停止按钮固定可见。刷新只刷新内容，不抢镜头；主动拖图、关闭后不反复聚焦。重复点击、取消、后台／离页、停止出帧和过期回调都不能补扣材料或造水。
