# 预设洞室与挖掘材料

日期：2026-10-20。用户批准前两层先规划好、直接点击建造，同时要求挖出物品进入物品栏并用于建设。此阶段降低空间规划负担，不增加制作配方树或复杂经济。

## 玩家流程

点轮廓或“修建洞室” → 看用途和材料 → 点“开工” → 阿土沿可达通道逐格清土 → 自动完成设施。位置、大小、走道自动安排，建筑嵌入土岩层；坚硬岩石不被自动挖除。

第一层：两人小窝、暖暖客厅；首次抵达第二层后开放新朋友的小窝。第二层：接水后修泉边小菜园；相邻洞室在小菜园和休息角之间二选一。x36起的软土仍可自由挖掘、摆菜槽。首层房间有实际床位或客厅，菜园使用现有种植与收获系统；休息角是座椅设施，不增加居民AI。

## 材料

- 起始石料4、旧木料3，第一间小窝无需先刷材料。
- 每次成功挖软土获得1件材料，坐标和为3的倍数时给旧木料，其余给石料；裂纹岩给石料。失败、空地、坚硬岩石均不掉落。
- 小窝费用3石料+2旧木料；客厅4+2；第二层洞室各2+2；自由摆一个菜槽1+1。顶部显示库存，挖掘处短暂显示掉落。
- 开工时检查材料，完工才扣费；缺料提示短缺数量，并提供“去挖土找材料”。不提前扣款，不重复扣款。

## 中断、撤销与兼容

停工使后续回调失效，已挖的土和材料保留；重新开工从剩余部分继续。施工期间任意点击不会替换内部工作，拖动仍可看地图。切工具、退出或页面隐藏会停工。关闭面板、切换视角不丢已完成工作。

本次会话内撤销建造退材料并保留挖出的空间；撤销挖掘回收对应掉落。保护有人依赖的通路和已建设施，避免恢复的土堵路。历史撤销栈不写入存档。

存档v13保存库存及建造标识，验证数量、用途、设施与可达性。v12及更早支持版本迁移后保留房间、床、作物、水电与伙伴，补起始库存。旧设施不被预设覆盖；未完成旧蓝图通过“继续原来的…”入口进入原施工面板。错误存档明确反馈，不覆盖原数据。施工队列不跨读档继续，回到洞室可再次开工。

## 实现与验证

规则分别在`core/sites.ts`、`core/materials.ts`；施工队列在`app/siteEditor.ts`，复用`atuOrders.ts`；Vue面板与Pixi轮廓/掉落反馈独立。核心和会话回归覆盖真实逐格施工、取消回调、路网、费用/退款、掉落、旧档迁移和损坏字段。验证结果与实景见[验收记录](acceptance/preset-building-v1/README.md)。

此阶段不实施第三层、更多材料、背包整理、配方树、自由装饰或新的居民行为。材料反馈与预留洞室沿用现有美术，尚未组织7岁儿童现场试玩。
