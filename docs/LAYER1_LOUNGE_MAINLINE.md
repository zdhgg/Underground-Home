# 第一层客厅：进主线 + 一起坐一会儿（存档 v28）

日期：2026-10-29。基线：`282da32`（两块能源石）。

## 问题

客厅其实早就做完了——`RoomKind` 有 `lounge`、房间面板里有「客厅」按钮、预设洞室「暖暖客厅」在 `(28,9)`、石拱长椅茶桌两张手绘素材都接着——但只做了两件事以外的东西：**主线里没有它，建成之后也没有任何用途**。跟着阿土走的孩子会：点亮 → 安床 → 听水声 → 换镐 → 挖通 → 下楼，客厅永远停在「还没建」；就算建了，也只是一张好看的空屋子。

分两步补上：先让它进主线，再给它一件真的能做的事。

## 第一步：客厅成为主线第 5 步

排在**安床之后、下楼之前**：

| 主线 | 内容 |
| --- | --- |
| 1–3 | 能源石 ×2 → 修好核心（点亮） |
| 4 | 给伙伴留床 |
| **5** | **给家里留个一起坐的地方（客厅）** |
| → | 交给"楼下有谁在喊饿"，开始第二层的 12 步探索链 |

- 门口按钮在挖空前后分别是「看看要挖的客厅空间」和「修建暖暖客厅」；挖空时阿土会说"发现了暖暖客厅的旧痕迹"。
- 蓝图仍由阿土逐格清土、完工才扣材料（4 石料 + 2 旧木料），和两人小窝完全同一套流程。
- **不锁死选址**：`loungeBuilt()` 认预设洞室，也认自己挖出来、自由布置的客厅（任何 `kind === 'lounge'` 的已建房间）。
- **旧档不补课**：`loungeTaskDone()` 把"已经下到第二层"也算作这一步已完成。已经玩到楼下的存档不会突然被要求回头建一间它从来没被引导过的房子。

顺序把关放在**引导层**而不是规则层：客厅没建好之前，阿土不会把目标交给"楼下有谁在喊饿"，`guideHighlight` 也不会指向裂纹；但如果孩子自己找到裂纹并执意下楼，一次下去之后客厅这一步就自动完成，主线直接接到第二层——不制造"卡在客厅"的死锁，也不往 `inspectCrack` 和存档校验里加新门槛（否则旧档会读不回来）。

## 第二步：一起坐一会儿

建成之后点客厅，房间面板里的主要按钮变成 **「☕ 一起坐一会儿」**（扩建降为次要）：

1. **伙伴真的走过来**：用第二层共餐那套围坐走位，伙伴从记录站位走到长椅前的座位。座位刻意避开房间左右两个角——那是伙伴平时待命的位置，坐下时应该看得出"走过来"。
2. **说一句家里的近况**：第一次永远是"阿灯：以前我一个人守着这里，现在有人一起坐了。"，之后按家里处境换（收过菜 / 接过水 / 一起吃过几顿）。
3. **客厅越坐越暖**：第 1 次铺上地毯，第 2 次角落多一盆花，之后不再添东西。次数写进存档，刷新后不会消失。
4. **可反复做**：不消耗食物、不消耗材料、没有倒计时，也不用等。第一次给一个里程碑卡片（"客厅暖起来了"），之后只在面板上记一句"一起坐过 N 次"。

为什么不是"吃饭"：经济循环已经在菜园 → 灶台 → 围坐开饭那条线上，客厅如果也吃食物，会和第二层的章末抢同一种资源。客厅提供的是**第一层唯一一处"什么都不做也合理"的地方**——这也是它的本来用途（设计基线写的是"日常休息、伙伴待命"）。

## 存档

`WORLD_VERSION` 27 → **28**，新增 `lounge: { rests: number }`（一起坐过的次数，只增不减）。v27 及更早的存档没有这个字段，载入时补成 0 次；当前版本缺字段或次数非法按损坏处理。

客厅建没建不占存档字段：`builtSites` / `rooms` 已经能推导。

## 验证

- `npm test`：**67 个文件、835 项测试通过**（新增 `tests/lounge.test.ts` 9 项：建成判定、座位、走位、次数与档位、台词、v27→v28 迁移、非法次数拒绝）。
- `vue-tsc --noEmit` 与 `vite build` 通过。
- 生产构建实机：载入"客厅已建、0 次"的存档 → 点客厅，面板显示「☕ 一起坐一会儿 / 一起坐过 0 次 · 还空着」→ 点了之后阿灯走到长椅前、出现里程碑「客厅暖起来了」与台词、地板铺上地毯 → 再点一次，面板变成「2 次 · 有花了」，茶几旁多了一盆花。截图见 `docs/acceptance/v1.3-lounge/`（05–08）。

## 已知限制

- 卧室只有一间时只有阿灯会坐过来；伙伴越多，围坐越满（受床位数限制，这是现有规则）。
- 盆栽与地毯是程序化画的小道具，不是手绘素材；和长椅茶桌放在一起还协调，但不适合再往上堆更多装饰。
- 客厅仍要 15 格手挖（5×3，和两人小窝的 9 格是同一套点一下挖一格）。如果试玩觉得太长，把预设改成 4 宽（12 格）是一行改动，美术本来就支持缩窄。
