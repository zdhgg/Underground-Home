# 第 3 层 · 晶簇与工坊

实施日期：2026-10-25。承接 `GAME_MASTER_DESIGN_V1.md` 的 5.4、11.4 节；本次用户明确要求实施完整第三层，因此从既有“两层收口”推进到第三层章节，不延伸第四层。

## 章节体验

**孩子把地下的一点晶光，接成能加工、能照明、能上下运送伙伴的家园。**

1. 第二层共餐且已送电后，右侧洞室外出现穿山甲阿岩，岩壁旁传来抓挠声。玩家主动打开线索，阿土沿通路走到他旁边相遇。
2. 阿岩获得自己的稳定身份和“凿”能力。从玩家已选的旧梯口开工，沿可达面逐段凿开晶纹盖层，落手时才改地形，施工梯逐段接长。
3. 玩家选择下到第三层。天然晶簇露面，第一次只取松动晶尖，得到晶簇 3、矿石 3；根部留在洞壁上。
4. 自由选址搭晶簇采集台、配电箱、晶光壁灯、岩壁工坊和小石炉。设施靠后侧岩壁，前侧始终留出真实通行空间。
5. 工作台搭好，松鼠阿木在工坊旁加入。矿石加工成金属锭，金属锭与晶簇加工成设施部件。
6. 阿岩加固竖井，阿木组装安全吊篮。第一次乘电梯把伙伴与材料运回暖窝层，出现第三层完成反馈。
7. 章末后仍能扩挖、加工、升级、乘梯往返，也能随时回到原有两层生活。

没有现实等待、饥饿倒计时、惩罚、货币或交易。采集台可重复取材料，避免用完晶簇后卡住。

## 地图和自由度

- 连续剖面由 44×28 扩为 **44×40**，原有 0—27 行逐格保留。
- 泉水层下方 y22—30 是指定盖层施工带，使用已选旧梯道 x16 或 x27；其余硬岩保留。
- 晶簇层可建设带 y31—33，地板 y34。天然洞穴之外有左右软土口袋，可以自己挖开、拓宽和重新选址。
- 五类设施没有固定建设点。只检查空间、地板、材料、连通、设施重叠，并保留梯口与天然晶根。
- 一般泥土一次挖一格、拖动只平移。挖掘和建造共用已有撤销栈；有人站着、有人依赖的路和已经投入使用的交通不能被填埋。
- 硬岩镐只处理 x10—11、y31—33 的小矿脉，每块产矿石 2。不能挖穿整片基岩、层间地板或地图边界。

主要面板使用 `data-attention-panel="deep"`，工作期间为 `deep-construction`；仅当前推进按钮有 `data-primary-action`。建设目录和楼层导航是次入口。原有设施、伙伴对话、房间施工接管时，仍由 App 同一条互斥渲染链保证一个主面板。

阿木、阿岩和阿土工作时优先站相邻格；阿岩初次出现站在旧洞室蓝图外。镜头只在主动选择当前目标或开始行动时定位；拖图后不因状态刷新反复抢回。下层抵达只在未主动拖图时做最后一次归位，保持楼层标记一致。

## 工程、存档与验证

- `core/deepTopology.ts` 管纵深坐标、真实梯道、可达建设带；`core/deep.ts` 管设施、资源、配方、升级和章末规则；光传播在 `core/lighting.ts`。
- `app/deepChapter.ts` 管单次行动令牌、到场工作、停止、选址与面板状态。`render/deepScene.ts`、`deepArt.ts`、`deepSound.ts` 分别管场景、图片和合成音效，没有把规则堆入渲染器。
- 存档 **v17**，继续使用现有存储库。v1—v16 既有兼容保留；真实旧 44×28 地图补入新行，不改变原地图。未知设施、负数资源、不合法硬岩开挖、伪造交通前置条件等会报告加载失败。
- 存档只写已完成格子与安全站位，不写动画中间帧。页面隐藏立即停止；连续约 3 秒无新帧或一项行动超过 30 秒也会解锁。取消及完成都会废弃旧回调，重复结束不会重复产出。
- 自动化覆盖完整章节、双梯口、自由建设、资源不足、升级效果、撤销、光不穿岩、存档迁移与拒绝损坏数据、施工中断、乘梯取消及真实 App 主面板切换。实景截图与最终结果见 `docs/acceptance/layer3-v1/README.md`。
