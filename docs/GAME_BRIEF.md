# 《地下小家园》游戏设计基线 v0.5（开发交接）

> 2026-10-20 用户批准调整：为降低7岁儿童的空间规划负担，前两层起步建设改为预设洞室，直接开工；第二层保留一个用途二选一洞室与右侧自由建设空间。成功挖掘获得石料/旧木料，存入物品栏供建设使用。本阶段此决策替代下文要求新手自行选择房间大小、位置的流程；自由探索、点击挖一格、拖图、撤销和岩层限制继续适用。详见[简化建造决策](PRESET_BUILDING_SCOPE.md)。

## 一句话定位
面向7岁儿童的2D横截面地下家园建造与探索游戏。地表风暴迫使小伙伴搬入旧避难所，玩家通过有限区域自由挖掘、修复设施、建立地下生态，让避难所逐渐变成温暖、能运转的家园。

## 核心体验（优先级顺序）
1. **为什么挖**：为了找到能源、水源、开辟居住与生产空间；禁止使用纯“挖N块土”充当主线目标。
2. **怎么建**：玩家自主选择房间位置、挖掘路线、层数。新手时期岩石围出可控建设区域；不能误挖太大。
3. **建成的反馈**：灯光逐渐亮起、小伙伴开始使用睡眠舱、温室发芽和收获、堡垒全景逐渐繁荣。
4. **探索感**：未开放的岩层、隐约的泉水和能量石，建立下一次向下拓展的期待。
5. **温和生存**：缺电缺水引导调整，不死亡、不突然毁档、不强迫持续在线。

## 第一夜的故事
地表刮着大风，几位小伙伴进入一座昏暗的地下避难所。玩家找到能源石、修复能源核心，挖出可用的睡眠舱空间，向下发现天然泉水，在合适位置建造水培温室并收获第一批蔬菜。结尾从整体视角展示灯火通明的避难所。

主线给“问题和目标”，不规定唯一的房间摆放方式。自由建设时进度可暂时搁置，已完成的有效设施仍计入任务条件。

## 首章必须支持的交互
- 点击松软泥土只挖一格，灰蓝坚硬岩石不能挖；后续才升级小铁镐、钻机。
- 拖动以平移视角为主，不连续误挖；需要清晰的挖掘工具状态。
- 可放置标准尺寸的岩洞式设施，位置自由但不能重叠、悬空或堵住唯一入口。
- 操作目标区域高亮；点击容错、建造预览、撤销、回到家园、缩放。
- 新任务展示“为什么做/现在该做什么/做完会发生什么”，少术语，短句配图标。
- 存档可恢复，关闭重新打开不丢主要进度。

## 可成长方向（首版不必全部实现）
- 下一章：升级铁镐，解锁岩层外的新洞穴。
- 之后：地下湖、地热区、植物园、水循环、能源分区和更丰富的装饰。
- 长期：仍在同一张地图上经营、完善地下堡垒。

## 明确暂缓
服务器和账号、联机、商城、角色社交系统、物理级流体和气体模拟、怪物战斗、复杂建筑承重、无限随机地图。
