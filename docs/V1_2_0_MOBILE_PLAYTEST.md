# v1.2.0 实体手机试玩清单

> 状态：**待人工验收**。本清单用于发布前在真实手机上触摸试玩；当前自动化验收只覆盖无头 Chromium，不等同于实体手机测试。

建议设备：一台 390–430px 宽、带触屏的手机；浏览器保持默认缩放，不使用鼠标模拟。

## 1. 启动与存档

- [ ] 首次打开进入页，页脚显示 **v1.2.0**。
- [ ] 点“更新记录”，第一条为 **1.2.0 · 2026-10-29**。
- [ ] 开始游戏，雪景开场能正常播放或跳过。
- [ ] 完成任意一次操作后退出浏览器，再次打开可以“继续游戏”，进度保留。
- [ ] 旧存档（v25 或更早）能继续进入，没有报错或重开要求。

## 2. 探索小本子

- [ ] 手机首次进入时小本子默认收起，只露出一条紧凑入口。
- [ ] 点入口可以展开，再点左上角“‹”可以收起。
- [ ] 展开后先看到当前主线，心愿在中间，楼层在下方。
- [ ] 点“去哪里？”下的楼层可以切换；镜头移动自然，不遮挡角色。
- [ ] 点未开放楼层会说明原因，不会提前进入。
- [ ] 展开“看看更深的地方”后，第一条锁定楼层真实可见。
- [ ] 按两次 Esc：第一次收起帮助（如展开），第二次收起整个小本子。

## 3. 家园心愿与触控

- [ ] 两项心愿同时出现时，每项都是“图标＋短名称＋去看看”，没有横向溢出。
- [ ] 心愿按钮足够大，手指一次能点中；两个按钮不会互相误触。
- [ ] “去哪里？”和第一条楼层入口在初始可视区域内。
- [ ] 点“去看看小窝”后，小本子收起，镜头能看见第一层小窝。
- [ ] 点“去看看菜园”后，小本子收起，镜头能看见成熟菜槽。
- [ ] 缺料时第二行仍显示“还差1个工坊部件……”，不会被裁掉。
- [ ] 页面在竖屏下没有左右晃动或横向滚动。

## 4. 装灯与收菜

- [ ] 第三层完成后，点心愿定位到小窝，再点小窝可以进入“给小窝添盏灯”。
- [ ] 阿灯能沿通路走到小窝，施工完成后暖光灯亮起，部件数量减 1。
- [ ] 撤销后灯消失、部件退回；再次安装仍正常。
- [ ] 退出重进后，已安装的暖光灯仍在。
- [ ] 成熟菜槽点下去，小满能走到菜槽并收菜；食物数量增加。
- [ ] 收完最后一槽后，“菜长熟啦！”心愿自动消失；再成熟后重新出现。
- [ ] 点击心愿本身不会自动装灯或自动收菜。

## 5. 手机操作手感

- [ ] 单指拖动地图自然，不会误挖或误点建筑。
- [ ] 缩放按钮可点；没有双指缩放要求。
- [ ] 长按、快速连点不会出现重复扣料或重复收菜。
- [ ] 伙伴工作时打开小本子，不会取消工作；楼层仍可查看。
- [ ] 章节面板、伙伴工作、设施面板出现时，心愿和主线自动让位。
- [ ] 底部工具栏、物品栏、撤销按钮没有被小本子遮挡。

## 6. 性能与异常

- [ ] 连续拖动、切换楼层、开关小本子 2–3 分钟后没有明显卡顿。
- [ ] 手机没有异常发热、闪退或黑屏。
- [ ] 弱网/切后台再回来，游戏能恢复；自动保存没有重复结算。
- [ ] 页面控制台或浏览器提示中没有应用错误。
