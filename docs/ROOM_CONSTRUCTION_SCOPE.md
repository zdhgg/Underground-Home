# 功能先行的房间建设

> 2026-10-20：当前新手入口已由用户批准的[预设洞室与建材流程](PRESET_BUILDING_SCOPE.md)替代。本文保留历史决策与旧蓝图兼容行为，不要求新玩家调宽度、选位置和逐格点完整房间。

日期：2026-10-18。用户已批准本次调整。此决策替代第2阶段“挖空后圈用途、再自由摆设施”的入口；第1、3、4阶段的真实施工、伙伴工作和照明升级继续保留。个人床位、厨房和共同生活仍待后续单项确认。

## 玩家流程

选“建房与扩建” → 选功能 → 调大小和位置 → 放蓝图 → 点土让阿土逐格施工 → 挖好并接通大厅 → 确认建成 → 使用或扩建。

蓝图可覆盖首层软土或已挖空间，不会隔空挖土、提前送床位，也不规定唯一布局。可以收起面板去探索、刷新后继续，或取消施工蓝图；已挖空间和原设施保留。普通点击仍只挖一格，拖动只平移地图。高处继续使用有限触及范围和一格短踏台；踏台上方被土挡住时，指出先清理的具体格子。

梯口邻格没有侧向踏台落脚点时，先挖出自身两格净空，再在实心地面用12px矮凳向正上方挖顶土。角色身体留在已挖空间内，不在梯子上架台、不叠台，也不解锁更高岩层；这是实景施工发现的死角修复。

| 功能 | 默认宽度 / 最小宽度 | 建成后的基础功能 |
| --- | --- | --- |
| 住处 | 3 / 3格 | 每完整3格宽最多安置一组双人床，供伙伴入住 |
| 种植区（旧档兼容） | 5 / 3格 | 旧档已有的第一层种植区继续可用；新菜园改到第二层，用「🌱 种植槽」自由摆放 |
| 客厅 | 5 / 4格 | 公共休息座与通行空间；本次不新增聚会、满意度或生产加成 |

宽度上限9格，普通新房高3格，旧床可纳入原有2格高洞室。既有设施不移动、不清空；预览显示规格最大容量，建成后显示实际设施数量。已有设施完全占住新功能所需空间时不能确认，提示扩大或换位。自动布局避开遗物、核心、梯口与原设施。

## 通行与扩建

房间表现为岩层中的洞室、后侧设施、前侧步道和开放门框。阿土与伙伴可以在已挖出的两格高通道内经过床和菜槽，土、岩石、地板与真实梯道继续约束行动。新房生成的床位记录后侧属性；历史房间内完整包含的床也使用前侧通道。房外的历史独立床沿用原规则。

选已有房间可扩建。默认向远离大厅的一侧增加足以提高容量的宽度，避免把旧床留在中间、两边都放不下新床。玩家仍可调宽、点图改位置；必须完整包住原房间，用途不变。施工期间原房间继续运作；确认后沿用原房间ID、保留原设施，只补充新增容量。不允许同一房间多份扩建蓝图。已建新房暂不提供拆房或改用途，避免无提示地删除成果。

## 撤销与存档

- 蓝图创建、调整、取消、建成及扩建完成均可在当前会话中撤销。施工中的挖掘仍受角色、设施和回家通路保护；已建房间不会被旧挖掘撤销填回土。
- 完工撤销只撤掉本次新增设施并恢复蓝图；扩建还恢复原房间。接水后才自动生成的菜槽有房间归属，撤销时同样能正确处理。水、食物、收成计数、工具及学会的能力不回滚。
- 最后一组床已参与后续探索时保持原前置保护，不通过撤销产生无法加载的世界。
- 存档v12保存施工蓝图、扩建引用、已建房间管理状态、后侧床位和自动菜槽归属。兼容v11及此前支持的试玩版本；旧房间、床、苗、食物、水电、灯罩、人物位置与地图均保留，不自动圈房或重布旧设施。
- 只使用原试玩IndexedDB。加载失败显示原因，临时试玩不覆盖失败数据；不保存半段动画或施工队列。

## 文件职责与验证

`core/roomConstruction.ts`管理功能规格、施工剩余量、自动布局、接水启用与完工；`core/rooms.ts`管理边界、扩建关系和撤销；`core/passages.ts`统一后侧设施的通行语义。`app/roomEditor.ts`只管理选址/施工面板状态，`session.ts`继续协调已有阿土和伙伴行动。Vue与Pixi只表现这些规则。

测试覆盖蓝图不改土、真实高处施工、两格走道、容量扩建、原设施保护、晚接水及撤销、存档迁移/损坏、模式取消和接水会话集成。生产预览实测与截图见[本轮验收](acceptance/room-construction-v1/README.md)。真实儿童理解与手感仍需试玩判断。
