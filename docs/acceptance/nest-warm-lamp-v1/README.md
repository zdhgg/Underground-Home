# v1.2-A 小窝暖光灯验收

实施依据与文件清单见 [设计实施记录](../../V1_2_HOME_GROWTH_DESIGN.md)。本目录的存档均为规则测试夹具生成的测试数据，没有读取玩家个人档案。

## 自动化

- 完整 `npm test`：63 个测试文件、765 项测试全部通过（最终单独执行 89.54 秒）；完整结果见 [test-output.txt](test-output.txt)。新增规则、真实 PartnerMotion 施工时序、会话取消/旧回调、保存/撤销、主动拖图后不重新弹出说明，以及真实 Vue 面板互斥测试。
- `npm run build`：生产构建通过，日志见 [build-output.txt](build-output.txt)；应用版本仍为 1.1.1。构建器保留主包超过 500 kB 的体积提示，本批次没有引入新的依赖或贴图。
- `node docs/acceptance/nest-warm-lamp-v1/verify.cjs`：通过 Playwright 驱动生产构建中的真实 Vue 与 Pixi WebGL 2 画布，使用独立临时 Chromium 上下文。测试地址默认 `5198`；仅夹具生成从开发服务 `5197` 导入纯规则模块。可通过 `LAMP_TEST_URL`、`LAMP_FIXTURE_URL` 改端口。

复跑浏览器前，分别启动 `npm run dev -- --host 127.0.0.1 --port 5197 --strictPort` 和 `npm run preview -- --host 127.0.0.1 --port 5198 --strictPort`，并先运行生产构建。脚本使用本机已配置的 Playwright 依赖路径；换机器时需调整 require 路径。

最终浏览器断言结果见 [browser-results.json](browser-results.json)。两种尺寸均检查单一主要面板和推进按钮、v25 载入后开工、预览不扣材料、真实行走后取消不扣费、到场施工、完成仅扣 1、撤销退回 1、再次安装与保存重进、多小窝独立，以及左右门两盏灯均装好后部件从 2 降到 0。第二盏灯施工期间真实打开/关闭物品栏，验证工作持续、结果单次结算。另验证没有房间的独立睡眠舱入口和安装。

行走路线从阿灯已有站位 `(24,11)` 逐格到小窝入口 `(15,11)`；取消测试记录实际停在 `(22,11)`，没有把角色送到目标旁。部件、标记、记忆和第三层其他字段均读取 IndexedDB 实际存档核对。没有替换真实渲染器或调用游戏内部完成接口。

## 视觉观察与边界

- 已查看真实截图：新增铜架、圆润乳白灯罩、暖黄灯芯位于入口端；左右门镜像，标记、两张床、前侧通道和阿灯仍可辨认。完成后灯体与局部光晕持续显示，重进后仍在。
- 预览详情接管主要操作；窄屏装灯工作面板移到下方，给上方小窝和到场的阿灯让出空间。完成详情不含再次安装按钮。
- 浏览器验收采用无头 Chromium / SwiftShader 软件 WebGL，属于真实 Pixi/WebGL 运行，不是静态单元测试。尚未在实体手机触摸、真实硬件 GPU、Safari 或 Firefox 上实测，也未从空档人工连续游玩完九章；九层规则回归使用完整自动化测试。
- 观察到原有窄屏镜头的显示边界：建筑位于上方、面板留在下方时，导航仍按视口中心推断层位，有时会显示“2层 · 泉水”，尽管当前选中的是第一层小窝。本批次未扩大范围修改九层镜头/判层规则。
- 画风和灯光强弱仍待美术人员主观复核。本批次没有修改原小窝贴图；原贴图顶部的小装饰光也保留，新增暖光灯是靠入口的一盏壁灯。
- 沿用既有存档周期和当前会话撤销栈；重进不恢复历史撤销记录。没有模拟操作系统断电或 IndexedDB 设备故障；取消、旧回调、前后台中断和存档往返的逻辑由自动化覆盖。
- 曾在完整测试与软件 WebGL 并行运行时触发原大厅测试的 5 秒超时；停止并行渲染后，按原超时标准重新执行完整套件。未修改测试超时或放宽断言。
