## 行为

- 7.6秒：阿土从雪地左侧奔向入口 → 对准井口下梯 → 沿大厅地面走到停转核心左侧 → 看向左侧泥土里的蓝光 → 镜头拉回原家园视角，显示“找到发光的能源石”。仅三句短字幕。
- 复用现有地表风雪、入口、梯架、阿土及核心；阿土沿用原走路/攀爬姿态，附加交替攀梯手脚。原梯架止于大厅上部，同一PNG续接到已有地面，未修改地图或通行判定。
- 只有读取结果为空的新游戏播放。包括刚结束开场、尚未挖土的存档在内，恢复时均不重播；读取失败也不播放，并保留原有失败反馈及禁止覆盖保护。
- 始终显示“跳过开场”，Esc也可跳过。自然结束、跳过和切后台共用一个收尾出口：正式阿土仍在原初始格，镜头恢复原家园构图，任务保持0/4；演出不挖土、不收能源石、不修改任务位。
- 开场屏蔽点挖、平移和缩放，收尾后复位指针。结束时按现有v12格式保存初始世界，不新增字段、存档版本或存储键。
- “开启声音”在用户手势中启动本地WebAudio风声、脚步/梯档声与蓝光提示音；跳过立即清理声音。浏览器限制自动发声，所以首次进入默认静音，画面照常播放。

## 验证

- `npm test`：28个文件、313项通过。新增路线身体包围检查（120Hz采样）、自然结束与多个时点跳过的渲染状态对比、新档/旧档识别、输入屏蔽和后台收尾测试。
- `npm run build`：类型检查、生产构建通过。仍有原有主包超过500kB提示，未扩展本轮范围做拆包。
- 隔离Chromium上下文验证完整播放、0.1/1.9/3.1/5.35/6.35秒跳过（3.1秒使用Esc）、900×620窄屏、未操作新档恢复、既有建房v12旧档恢复、跳过后实际挖土；逐项比对世界数据与最终镜头，结果见[browser-report.json](browser-report.json)。未读取玩家浏览器中的存档。
- `verify.cjs`可复跑，`OPENING_TEST_URL`指定开发服务或生产预览；`--capture-only`只采集四个演出阶段。四阶段截图固定浏览器时钟后通过CDP采集真实Pixi画布，避免截图编码耗时错过短镜头；场景代码没有测试专用分支。
