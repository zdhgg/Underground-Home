# 验收：引水与第一层种植（阶段 2）

基线提交：`3728a35` 之后的阶段 2 改动。分支 `codex/first-spring-breakthrough`。

验证方式：内置浏览器载入一份"已找到泉水 + 水已引到家里 + 两槽菜（一槽熟了）"的合法存档（用项目自己的
`serialize` 生成并通过 `deserialize` 校验），然后在页面上操作。

| 截图 | 看什么 |
| --- | --- |
| `01-water-supplied-farm-ui.png` | 引水之后的整体界面：任务徽章「安顿新朋友 7/8」；建造工具多出「🌱 种植槽」；左下角出现「💧 水到家啦 · 种菜、收菜、请伙伴吃饭」与「🥕 种植槽 2 · 熟了 0 · 食物 0」；伙伴面板给出「🍽 先收点菜再开饭」。 |
| `02-water-line-barrel-and-planter.png` | 放大画面：大厅地面上一条水管接到**水缸**，旁边是长着嫩芽的**种植槽**；能源核心在运行、两位等床的新朋友站在大厅。 |

同一次验证里通过真实指针事件确认过的行为：

- 点成熟的槽 → 提示「🥕 收了一份！家里有 1 份吃的。」，计数从「熟了 1 · 食物 0」变成「熟了 0 · 食物 1」。
- 点还没熟的槽 → 提示「🌱 还没长熟：你每干一件事，它就长高一档（现在 1/3）」，不消耗、不删除。
- 点「🍽 请大家吃饭（食物 1）」→ 食物回到 0，提示「🍽 伙伴们吃得好开心！再去收点菜吧。」

没能在这个面板里跑完的部分：**引水演出**（阿土沿梯道走去接水管）依赖逐帧推进，而该面板的帧会被节流，
3 秒后由施工看门狗安全收尾（提示「⏸ 阿土停下来了，再点一次就好。」）。按钮会正确解锁（本轮顺手修的：
中断不再把按钮卡在"阿土在接水管……"）。演出本身由 `tests/session-exploration.test.ts` 的链路用例覆盖。
