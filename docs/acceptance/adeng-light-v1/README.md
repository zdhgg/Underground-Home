# 阿灯聚光灯罩：第4阶段验收

日期：2026-10-18。状态：工程实施和自动检查完成，待玩家试玩。依据[分阶段方案](../../ATU_HOME_IMPLEMENTATION_PLAN.md)第4阶段及[本阶段小方案](../../ADENG_LIGHT_UPGRADE_SCOPE.md)。此次只交付阿灯第一项专业能力成长。

## 体验与操作

先找到泉水、把电送到第二层、装一盏普通壁灯。在它附近挖出可到达的新空间，如果有普通灯覆盖不到、聚光灯能照到的地方，向导卡会出现可忽略的“阿灯有个照亮新地方的办法”。也可以直接与阿灯聊天查看条件。

1. 主动点“学会做聚光灯罩”，对话说明“左右各2格 → 各4格”。没有经验、材料或食物消耗，只能学一次。
2. 点“去布置聚光灯”。如果镜头仍在营地，此次明确的“去”操作会定位下层旧灯；已经在泉水层则保留镜头。
3. 点普通旧灯，阿灯沿真实通路过去加装；也可点合法新灯位，安装带灯罩的新灯。动手时才改变设施配置和实际光场。
4. 加装后空间的暖光覆盖扩大，灯具顶部有灯罩。可以停止、重试或撤销；撤销加装退回原普通灯，学习成果保留。

新增能力没有加入主线任务计数，不要求特定房间或固定布局。旧设施可以继续使用，不需要先学习。原阿土探索、房间标记、小满收菜、小泉引水和阿灯普通安灯流程保留。

## 照明规则与边界

普通灯与聚光灯使用同一独立规则计算横向覆盖：从灯所在列向左右各2格或各4格传播，遇到身体通道中的泥土/岩石停止。只在已有的、两格净高可通行的泉水层空间覆盖已挖空格，灯位仍要求原来的三格净高和真实路线。

覆盖强度向边缘衰减，洞壁暖光使用同一格子光场并作柔和插值；多盏灯取较强值，不无限叠亮。原有灯圈和基础通电亮度保留，普通灯也得到局部光场表现；新增光场不落在土和岩里，不解锁地层、不替玩家开挖、不把整层提亮。原有探索迷雾、基础灯圈仍沿用原表现。

桌面指向合法灯位时可看到覆盖格预览。触摸沿用原来的点灯位下达指令，有即时工作反馈和停止入口，不增加拖框或第二次确认。退出工具、切建造或切楼层时清掉预览，避免遗留灯光选区。

学习只更新能力状态，不自动改造全部旧灯；逐盏加装后才扩大该灯覆盖。阿灯必须从当前安全位置走到安装列，不穿土、不瞬移。工作期间仍一次一项，可拖图/缩放/定位/停止；不强拉镜头去追工作。动手前取消没有灯罩，动手后取消保留已发生结果，旧回调失效。新灯与灯罩加装分别进入撤销栈，撤销不收回学会的能力。

## 存档

格式升级为**v11**。`partnerUpgrades`只保存稳定升级ID `wide-lamp-shade`，能力归属继续使用伙伴定义中的 `light`；每盏灯可保存 `wide: true` 表示已加装。两者分别描述“会不会做”和“设施有没有装”，没有重复等级字段。

- v10及此前受支持存档迁移为未学会，原灯保持普通配置；地图、房间、床位、角色站位、食物、水电、铁镐和探索成果保留。
- 学习后即使撤销最后一盏灯，能力仍保留，后续新灯自动带罩。
- 未知/重复升级ID、缺失字段、未学会却带罩、非法灯配置或缺少照明前置成果加载失败有反馈，不覆盖原失败数据。
- 不保存半段工作。刷新只恢复能力、设施结果和安全站位，不自动重播加装或重复结算。
- 沿用独立试玩库，未访问正式旧库，也未修改用户正在玩的存档。
