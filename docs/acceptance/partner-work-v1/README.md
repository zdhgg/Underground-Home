# 伙伴专业工作：第3阶段验收

日期：2026-10-18。状态：工程实施和自动检查完成，等待玩家试玩。范围依据：[分阶段方案](../../ATU_HOME_IMPLEMENTATION_PLAN.md)第3阶段，包含3A小满收菜、3B小泉接水、3C阿灯装灯。

## 玩家得到的变化

| 操作 | 伙伴做什么 | 真实结果 |
| --- | --- | --- |
| 点成熟菜槽 | 小满从当前站位沿通路走到菜槽旁，做采收动作 | 落手时食物和累计收获各加1，作物归零重新种苗；连点不重复收成 |
| 点“把水引到家里”或已发现、尚未供水的泉水 | 小泉到泉边接管，再沿原通路返回营地 | 动手时接通原供水状态，水管/水桶出现，原种植条件开放；阿土不代为移动 |
| 选择壁灯工具，再点合法泉水层位置 | 阿灯沿已有通道和梯道过去，在已清空的安装列短暂升起安装 | 动手时才出现原壁灯和照明；保留原供电条件，安灯仍可撤销 |

收菜、安灯原先立即结算，接水原先由阿土执行；本阶段按批准方案改为伙伴到场动手。伙伴保留原床位，但不再因入床而无法协作；建床后确认的是住处与床位，不再把专业伙伴永久锁在睡眠画面里。

伙伴优先在已有菜槽、壁灯、供水设施旁使用合法站位；没有设施时选择公共区域或大厅。工作结束后小满/阿灯在设施旁待命，小泉接管后回营地，并选择避开阿土与其他伙伴的空闲位置。没有作息、自动干活或居民任务规划。

阿土仍是唯一主要探索角色，玩家无需先选人。右下角“伙伴在哪”展开已加入伙伴的小列表，点名字只定位镜头和给一句回应，不切换角色。工作左侧卡替换向导，显示一位操作者、走路/动手/返回状态、“看看伙伴”和“停下来”。低高度窗口收紧楼层导航，避免与伙伴入口重叠。

## 路线、取消与建设保护

- 从伙伴最近实际到达的安全格寻路，沿已挖通、有身体净空的地面或真实梯道行走。房间标记不形成障碍，也不是工作前置条件。床体、泥土、未开通岩层都不能穿过；无路就解释如何开路，不偷偷改起点或补挖。
- 首版最多一项专业工作。工作期间暂停阿土新行动、建设和撤销，地图拖动、缩放、定位与取消仍可用；没有队列。点同一设施不会开启多份工作。
- 动手前停止不产生设施效果；完成后停止返程保留已有效的供水/收获/灯。取消令旧抵达与落手回调失效，切后台、页面离开、关闭会话或画面不再出帧时同样安全收尾。
- 逐格保存已到达位置，重载恢复安全格，不保存半步、半空安装姿态或待执行工作。刷新不自动补收菜、装灯或接管。
- 伙伴工作和供水反馈不自动拉走镜头。玩家主动点“看看伙伴”或“伙伴在哪”才定位。
- 建床若会覆盖伙伴或截断其回营地路线，先安排真实退让，再确认床；取消让位不继续建造。没有安全退路就保持原样。
- 撤销不能埋住伙伴身体或切断其回家路径，暂时受伙伴占用影响的挖掘记录保留供以后重试。原房间、设施、阿土站位和唯一通路保护继续有效。

## 存档与拓展边界

格式升级为**v10**，新增`workers`，按稳定伙伴ID保存安全格。v9和此前受支持旧档仍保留地形、房间、床、菜槽、食物、水电、工具和探索成果；只在首次恢复/伙伴加入时选择合法待命点。已有站位不会为了接工作改成更近的起点。

未知身份、未加入伙伴、土内/半格站位或无回家路的伙伴数据加载失败有反馈，并禁止覆盖原失败数据。仍使用独立试玩数据库，不打开正式旧库。

正常撤销首床时，小满的加入条件随之取消，运行中的伙伴名单和对应站位会同步清理；不会把已离开伙伴的位置写成下一次无法读取的存档。床位/角色仍按原稳定ID映射。

已供水的旧档不要求重接管，已安装的灯不会熄灭或重新施工。没有新增经验、等级、材料或水量字段。专业伙伴ID类型和校验名单从现有伙伴定义派生；增加伙伴可扩展定义、工作目标与对应表现，不依赖四人同屏、数组下标或四间卧室。新角色的具体加入条件、动作与能力仍需实际实现。

## 限制与未完成项

- 本阶段只有玩家触发的三项工作；没有自动种植、作息模拟、任务队列或四人自由切换。工作期间阿土新行动暂时暂停，玩家可取消后继续探索。
- 小泉接水是现有的一次性供水闭环，供水已完成的旧档不新增分水/泵站工作；送电仍沿用阿土原流程。
- 不能穿过已建床体或只有一格高的旧通道。旧设施本身保留，但若无身体可通过的路径，须先在允许区域开路；不会以瞬移掩盖布局问题。
- 第4阶段专业能力升级、第5阶段个人住处/厨房/共同活动均未启动；无新增角色或第三层。
- 刷新只恢复成果和安全站位，未完成工作需要再次点选；撤销栈仍只限本次会话。
- 未做真实儿童试玩，仍需判断伙伴到场的等待、设施点击和停止入口是否易懂。主包超过500kB的构建提示仍存在。
