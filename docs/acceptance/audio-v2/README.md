# 家园音乐与轻环境声 · 第二批验收

完成当前两层的背景声音，不新增玩法、任务或设置面板。第一批关键音效与统一开关继续使用。

## 听到什么

- 原创 60 BPM、12 小节、48 秒家园主题，柔和拨弦/木琴式音色和少量低音，留有休止与混响尾音。
- 核心未启动：只保留主题中的稀疏音符与低声洞穴气流。
- 能源石安装完成、核心亮起：同一乐句中的完整家园主题渐入，不在点击安装时提前庆祝。
- 已发现泉水且当前看泉水层：加入轻流水与稀疏水滴；回家或看全景时淡出。尚未发现泉水时不提前播放水声。
- 伙伴出现/对话期间，背景音量降至正常的 30%；关键庆祝期间降至 18%，结束后平滑恢复。
- 标题和开场不播放家园主题，开场继续使用原有风声。开场结束/跳过或继续存档后才进入家园音乐。

四条循环始终共用相位，切层和通电只调整音量，不重启旋律。静音和后台停止循环，恢复时复用缓冲并接续乐句，不补播旧事件。只使用原有声音开关及 v1 设置，不变更世界存档结构。

## 实现边界

`backgroundScore.ts` 是确定性的纯 PCM 乐谱与环境声合成；`backgroundWorker.ts` 在后台线程计算，`scoreLoader.ts` 转移内存并清理线程；`backgroundSound.ts` 管理四轨、相位和渐变；`gameAudio.ts` 管理开始、静音、后台、事件降音和释放。

渲染器只传递当前可见的通电、楼层和对话状态，不修改世界规则。音乐准备失败时单独停用背景声，已有操作音效、文字和画面继续工作。没有外部音乐服务、音频下载素材、新依赖或配音。

首次计算在独立线程完成，完成后创建并缓存四个单声道 22050Hz 缓冲，约 16.9MB PCM；静音期间保留缓存，销毁游戏时释放。复测中主线程发起音乐准备为桌面 1.6ms、窄屏 0.6ms；这只是本机软件渲染浏览器的设置调用耗时，不代表目标平板性能。

## 验证结果

- `npm test`：40 个测试文件，422 个测试全部通过。包括固定音源数量、切层不重复分配、淡入淡出目标、对话/庆祝降音、静音/后台与缓存恢复、销毁后的旧线程回调无效、合成失败降级、波形有限/首尾连续等回归。
- `npm run build`：通过，生成独立的约 1.38kB 音乐工作线程文件；仍有既有主包超过 500kB 的体积提示。
- `node docs/acceptance/audio-v2/verify.cjs`：桌面 1440×960、窄屏 390×844 的真实浏览器场景验证通过，零页面错误。检查标题/开场不重叠播放、安装完成后转入家园音乐、对话降音与退出恢复、已发现泉水才播放水声、全景退出水声、后台恢复及存档静音。
- `node docs/acceptance/audio-v2/verify-production.cjs`：通过生产构建预览，线程资源返回 HTTP 200，四条真实 48 秒循环可播放、可静音；继续游戏保留静音，再开启时正常开始音乐，零页面错误。
- 三份真实 `OfflineAudioContext` 导出各 50 秒，覆盖一次 48 秒循环接缝。峰值约 0.011—0.026，未削波；接缝相邻采样差小于 0.000001。详细数值见 `waveforms.json`，其中 `offlineSynthMs` 是测试导出时同步合成的耗时，游戏运行时使用后台线程。
- 已查看本目录的窄屏对话与桌面泉水层截图，声音入口未新增面板或遮住角色。机器波形检查不代替主观试听。
