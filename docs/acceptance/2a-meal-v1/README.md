# 第二层 2A 做饭与围坐 · 试玩复现清单

日期：2026-10-24。基线：分支 `zcode/second-layer-2a-v1`，2A 主体提交 `6d27f5f`，含后续工作区收口提交。
范围：泉边灶台、围坐餐桌两个预设洞室，实体共餐演出，旧「请大家吃饭」按钮兼容。不含水塔、育苗、新菜色、饥饿条；存档仍为 v13。

## 快速到达路径（新档全流程）

1. 开始游戏 → 播放开场 → 挖开泛蓝光泥土找到能源石 → 点一下收好 → 点大厅能源核心修好。
2. 点「两人小窝」蓝图开工 → 建成后点岩壁裂纹听水声 → 和阿土聊天换上小铁镐。
3. 点裂纹逐段破岩（委托两段后可「一路挖到底」）→ 点「沿梯子下去」，第一次下到第二层遇见小满。
4. 一格一格挖到泉边，点泉水（小泉出现）→ 点「把水接到菜园」。
5. 回第一层给小满、小泉留床（「新朋友的小窝」或扩建已有住处）。
6. 修建「泉边小菜园」→ 干几件事等菜成熟 → 点熟菜，小满来收（第一份收成）。
7. 点「把家里的电送到下面」，第二层亮起来。

## 2A 验收步骤

1. 送电后底部提示「🔨 点『泉边建设』修一个灶台」。点「泉边建设」（或直接点左侧洞室出现的蓝图），选「泉边灶台」→「开工」。费用 2 石 2 木，完工才扣；阿土沿真实通路逐格挖出连接走道并完成设施。
2. 只建好灶台时，完工里程碑是「再配上另一件，就能围坐吃饭」；此时吃饭仍是原有简化演出。
3. 再选「围坐餐桌」（2 石 3 木）开工。两件都建好后弹里程碑「小厨房开张啦！」。
4. 收一份菜，展开底部「更多工具与家园」，点「请大家吃饭」：
   - 镜头到餐桌，灶台先热起来（做饭动画）；
   - 伙伴从当前站位沿真实通路走到餐桌前围坐（餐桌 4 个座位，走不到的伙伴不勉强）；
   - 彩纸庆祝、小满说「一起吃，饭更香！」、弹里程碑卡片「大家围坐吃饭啦！」。
5. 食物只扣 1 份。演出期间点地图或「停下来」→ 提示「大家先停一下」，演出安全结束，不重复扣、也不退款（结算在开饭时已完成）。
6. 建造可中断：「停下来」后已挖空间和材料保留，重新开工续挖。点「撤销」可撤回整间设施并退回材料。
7. 旧档兼容：用没有灶台/餐桌的 v13 存档继续 → 原按钮、原简化演出；两件都有的存档 → 实体围坐演出。
8. 演出中途刷新页面 → 回到安全状态，无重复结算、无卡死输入。
9. 窄屏（<720px）：建筑详情面板在底部、洞室预览在上方；施工状态条有独立「停下来」。
