# 能源石 PNG 与收集 / 安装反馈验收

日期：2026-10-17。本轮只补齐能源石素材和短暂反馈，没有进入新建设阶段。

## 变更文件

- `src/assets/art/landmarks/energy-crystal-v1.png`：一张透明能源石PNG。
- `src/assets/art/landmarks/ENERGY_CRYSTAL_V1.md`：实际规格、生成方式与完整提示词。
- `src/render/crystalTexture.ts`：纹理加载及显示规格。
- `src/render/CrystalFeedback.ts`：独立的收集上浮、安装弧线和尾迹演出；使用一份临时精灵，不读取或修改世界。
- `src/render/PixiRenderer.ts`：埋藏 / 露出 / 收集显示、动画衔接、加载时取消瞬时反馈。安装0.7秒结束后，才执行原启动闪烁、逐盏点灯与庆祝；自动拉远仍可由手动平移 / 缩放取消。
- `src/app/session.ts`：只将成功收集后的渲染通知改为收集反馈，并把原修复粒子参数移入渲染器，衔接安装演出；互动判断、任务推进、保存时机不变。
- `tests/crystal-feedback.test.ts` 与 `tests/terrain-renderer.test.ts`：补充演出生命周期、快速覆盖 / 取消、三阶段显隐、点灯顺序、存档加载及镜头取消回归检查。

`src/core/`、`src/input/`、相机换算、32px世界网格及v2存档结构没有修改；没有新增依赖。

## 自动验证

- `npm test`：**10个测试文件、88项全部通过**。
- `npm run build`：**vue-tsc类型检查和Vite生产构建通过**。
- 原图使用 Pillow 仅解码检查：1254×1254 RGBA，alpha范围0—255，1,062,320个完全透明像素。生成的PNG原样复制到项目，未修改图像。
- 测试确认：收集上浮缩小后清理，不触发安装；安装到达槽心只发一次完成信号；快速安装覆盖收集尾迹且复用精灵；重置不会触发延迟回调。
- 渲染集成测试确认：埋藏时无PNG、挖开后显示、收集后移除；任务 / 世界数据在动画前已完成，逐帧演出不改变序列化数据；安装未完成时不启动 / 点灯，结束后正常衔接。
- 载入已完成世界取消瞬时演出，直接显示正常运行和点亮状态；安装期间手动平移仍取消自动拉远。

## 浏览器实测

生产预览：`npm run preview -- --host 127.0.0.1 --port 4175`。在独立本地端口走新存档流程，不覆盖原4173 / 4174端口的进度。

- 初始泥土只透出微光；挖开后可见蓝色切面PNG，任务0/3 → 1/3。
- 点击撤销不会把已发现的能源石埋回；2.2倍近景能看清晶体轮廓和切面。
- 点击收集，晶体上浮、缩小、消失；地图不残留，任务进入2/3。
- 点击原核心互动区域，晶体从携带位置进入能源槽，核心短暂显示“正在安装”；随后启动、顶灯亮起、庆祝和镜头演出继续。
- 任务和保存即时完成，所以安装的0.7秒内UI可先显示3/3；这是瞬时渲染延迟，未把任务或保存绑定到动画结束。
- 最终生产构建刷新后恢复3/3、运行核心和已点亮顶灯；能源石没有残留，不重播收集 / 安装。浏览器 warn/error 日志为空。
