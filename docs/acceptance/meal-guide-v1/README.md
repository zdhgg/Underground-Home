# 第二层章末收口 · 验收记录

日期：2026-10-24。分支 `zcode/meal-guide-v1`。范围与决策见 [MEAL_GUIDE_SCOPE.md](../../MEAL_GUIDE_SCOPE.md)。

## 行为变化

- 探索引导从 9 步延到 12 步：送电后依次是「在泉边修一个灶台」「再摆一张餐桌」「请大家吃第一顿饭」，每步带地图高亮和一个主按钮。
- 第一次围坐共餐：弹里程碑卡片「第 2 层 · 完成啦！」，镜头拉到全剖面停约 2 秒（回望）再回到泉水层；拖动、缩放或点楼层导航会立即结束回望，不抢镜头。
- 章末完成后，引导面板主按钮轮换为「做一顿饭」（灶台餐桌还在时）；无食物时提示先收菜。
- 存档升级 v14：新增 `farm.sharedMeals`。v13 旧档按 0 次补齐，已建两设施的旧档停在「第一顿饭」一步（消耗 1 份食物即可触发章末，不损失成果）。
- 共餐发生后，撤销不再允许拆掉灶台/餐桌（进度位单调，避免存档矛盾）。

## 复现步骤（试玩）

1. 读档或玩到「把电送到下面」并送电。
2. 跟着鼹鼠面板：主按钮依次「修建泉边灶台」（开工、完工扣 2 石 2 木）→「再摆一张餐桌」（2 石 3 木）。
3. 收一份菜（或确认手里有食物），主按钮变「请大家吃第一顿饭」，点击：围坐演出 → 卡片「第 2 层 · 完成啦！」→ 镜头拉出全剖面 → 回到餐桌。
4. 引导显示「家越住越大！」，主按钮为「做一顿饭」；再开一顿饭只有普通庆祝，不再弹章末卡片、不再回望。
5. 刷新页面继续：进度停在 12/12，主按钮仍是「做一顿饭」；不重播章末。
6. 旧档检查：用没有灶台/餐桌的 v13 存档（v0.2.x 旧进度）继续，吃饭仍是原简化演出；计数为 0。
7. 撤销检查：共餐后点撤销，灶台/餐桌不会被拆掉。
