## 冒烟发现并修复

**1494px 宽度下第 8、9 层和“全景”被挤出视口。** 顶部栏原本只在 1120px 以下换行，九层导航总宽约 1170px，加上品牌、物品栏和工具后超出视口；导航不是滚动容器，右侧入口无法点击。

修复：把桌面换行断点从 1120px 扩到 1840px（`src/App.vue`）。1494px 下导航改为第二行、10 个入口全部可见，复验坐标均在 `0—1494px` 内；窄屏两行五列布局保持不变。修复后重新构建并通过冒烟。

## 复现

```sh
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 5174 --strictPort
```

终章隔离页：

```sh
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

打开 `/tests/manual/finale.html?phase=ready`（准备赴席）、`?phase=completed`（终章完成）或 `/tests/manual/finale-device.html`（398×756 窄屏）。隔离页只使用内存存档，不读写玩家 IndexedDB。
