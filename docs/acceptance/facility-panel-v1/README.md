# 设施面板与菜园浇水 · 验收记录

日期：2026-10-24。分支 `zcode/facility-panel-v1`。范围与决策见 [FACILITY_PANEL_SCOPE.md](../../FACILITY_PANEL_SCOPE.md)。

## 行为变化

- 点建好的**泉边小菜园 / 泉边灶台 / 围坐餐桌**本体，打开对应设施面板（左上角，同洞室面板位置）；再点一次收起，点别处收起，拖动地图不收起。
- **菜园面板**：菜槽状态图示（·/🌱/🌿/🥕 按生长档）+ "熟了 N 槽 · 共 M 槽"；主操作——有熟菜 →「叫小满来收菜」，没熟 →「请小满浇浇水」，没有菜槽 →「去种一槽菜」；次要入口「自己摆菜槽」「看看它」。
- **点未熟的菜直接派小满浇水**（不再只是一句文字）：小满走到菜旁动手，所有未熟菜各长一档；熟透的不再长。
- **灶台面板**主操作「做饭，请大家吃」、**餐桌面板**主操作「大家坐下来吃饭」：与引导按钮、折叠抽屉按钮同一条 `serveMeal` 结算，一次只扣一份食材。
- 面板打开时引导面板让位；对话/伙伴工作/施工接管时面板关闭；attention 契约测试覆盖。

## 复现步骤（试玩）

1. 玩到引水完成、菜园建好（或用已有进度）：点菜园的洞室（菜槽以外的部分，比如上面的拱顶区域）→ 面板打开，能看到每槽菜的状态图示。
2. 没有熟菜时点「请小满浇浇水」：小满走到菜旁、水声 + 一句"浇好啦"，面板让位给工作状态；完成后菜各长一档。
3. 直接点一株**未熟**的菜：同样派小满浇水（直点快捷路径）。
4. 有熟菜时面板主操作变「叫小满来收菜」；点熟的菜也直接收——两条路都是小满到场收、食物 +1、只结算一次。
5. 建好灶台和餐桌后：点灶台 → 「做饭，请大家吃」；点餐桌 → 「大家坐下来吃饭」。两个按钮和引导主按钮、抽屉里的旧按钮效果完全一致（同一结算）。
6. 面板打开时点伙伴聊天 → 面板让位给对话；关掉对话 → 回到设施面板；再关面板 → 回到引导。
7. 窄屏（<720px）：面板在底部、按钮 44px 高。

## 已知限制与待人工检查

- 面板位置、菜槽图示（emoji）与手绘美术的协调需实景观感确认；菜槽图示暂用文字符号，未接入手绘小图。
- 浇水的动作动画复用通用"手边工具"动作（蓝色），未做专门的水壶/水花造型。
- 伙伴在设施区域内站立时，点击优先打开面板而非对话（贴身点击伙伴需等其站在设施格外）——需实机确认观感。
- 壁灯、泉水、住处扩建仍是旧入口（按 S2 边界未迁移）。
