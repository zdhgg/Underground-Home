# 环境生命感 · 验收记录

日期：2026-10-24。分支 `zcode/ambient-life-v1`。范围与决策见 [AMBIENT_LIFE_SCOPE.md](../../AMBIENT_LIFE_SCOPE.md)。

## 行为变化（全部纯视觉）

- 修好核心后，大厅顶灯与第二层壁灯的光里能看到缓缓打转的微尘。
- 泉水找到后：洞顶水珠滴进泉面、涟漪一圈圈扩散（叠加在原有水面微光上）。
- 第二层洞壁：地面苔斑之外，洞顶也垂下小簇苔藓，与地面错开；洞道挖高三格后垂苔上移。
- 待命的伙伴约每 2.4 秒身边飘起一颗小微粒（小满嫩叶、小泉水珠、阿灯暖光）；站着的朋友约每 7 秒轻轻起伏一下。

## 复现步骤（试玩）

1. 新档修好核心：大厅灯亮后停留 10 秒——灯光里有微尘缓缓浮动。
2. 下到第二层、找到泉水：停在看泉水的画面 10 秒——水珠从洞顶滴落、涟漪扩散、水面微光闪动。
3. 安两盏壁灯后：灯光处同样有微尘。
4. 引水后点菜园旁的小满所在处：等几秒，她身边飘起嫩叶色小微粒；小泉在泉边有水色微粒。
5. 观察第二层洞顶：与地面苔错开的位置有小簇垂苔；把某列挖到三格高，垂苔挂到更高的岩沿。
6. 站着不动的伙伴：约每 7 秒轻轻起伏一下（睡觉和干活时没有）。

## 已知限制与待人工检查

- 微尘/微粒/涟漪的观感（大小、亮度、密度、节奏）需桌面与窄屏**实景观感确认**，尤其要检查不与黑暗遮罩打架（环境层位于黑暗之下，暗处的微粒会被遮暗——这是有意的）。
- 目标平板帧率未实测；本轮全部为轻量 Graphics 绘制，风险低。
- 垂苔与洞顶手绘美术的协调（若后续洞顶换素材，垂苔位置规则不变）。
