## 已覆盖的行为

- 完整章节从旧拱检查、护框、逐格落手、实际下楼、自由选址，到三段岩画的看清／拓印／装壁、今天一页和三人到场庆典；所有会话中间快照都可恢复。
- x16／x27 两条梯口保留前七层地形，八层能沿真实路线走回家；坚硬基岩、实心地板和梯口继续受保护。
- 两套设施位置和建设顺序、倒序故事修复都能完成；缺料、无净空、重叠、占梯口和不可达被拒绝。
- 看清前不能拓印、拓印前不能修复、重复操作不重复扣料；每段明确使用一块旧木料做夹板。
- 看清后停留在这一段对白，拓印后交修复，修复后交下一故事；旧收藏补充对白，不构成通关条件。
- 今天一页只在确认并完成实际工作后写呈现和次数，章末后仍可更换。
- 原岩画上侧点击和设施下侧点击分开；土块不被故事命中吞掉，重复发现可以继续点原处设施。
- 章末等三人到不同格子；取消、重复点击／落手、过期结束、停帧、后台／离页不补扣费、不提前揭画或通关。
- 撤销拓印退材料、修复退状态、切换呈现退上一版；已使用电梯延长、通路和已发现岩画可达性受保护。
- 八站电梯从真实第八层发车、回八层后阿木走出吊篮，旧七层档不能提前乘入未延长的新站。
- 真实会话切换旧章、阿土对话、物品栏定位和后台／离页取消；引导与存档摘要进入第八章。
- 真实 App 覆盖入口、选址、三段故事、呈现选择、工作、庆典、八站辅助导航、全景、旧设施与伙伴对话：最多一个主要面板、一个主要推进按钮。
- Pixi 对象覆盖修复图案在石壁前、设施与图案在人物后，既有九位伙伴保持原样，398×756 视口的目标在面板上方。
- 七类本地 WebAudio 音效服从统一静音和后台门禁。
- v22 支持真实 v21 44×88 存档只追加新层，不改输入；更早各层迁移继续回归；拒绝伪造护框、重复数组、拓印依赖、计数、呈现与越界设施。
