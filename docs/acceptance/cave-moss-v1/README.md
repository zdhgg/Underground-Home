# 泉水层背景苔斑验收

日期：2026-10-23。

## 显示规则

- 移除原先反复出现在地面、像可采集石块的立体苔藓石堆，停止加载其 PNG；原素材文件保留。
- 使用程序绘制的扁平苔斑，只在已探索洞壁稀疏出现，候选间距由三格增至六格。苔斑高不足八个世界像素，透明度 24%，不发光、不摆动、不参与交互。
- 背景层位于房间、家具、伙伴与光照遮罩之下，不挡住主体。
- 泉水、梯口、水缸旁留白。已建洞室（含灶台、餐桌、菜园）、房间蓝图、睡眠舱与自由摆放菜槽的范围及边缘一格不显示苔斑。
- 建成、放置菜槽、撤销或恢复存档后，由当前世界数据重新推导显示；未建设洞壁可以保留少量苔斑。上层建筑不会误删下层装饰。不修改存档结构和交互规则。

## 本轮文件

- `src/render/caveMoss.ts`：新增背景绘制与设施避让。
- `src/render/explorationScene.ts`：拆出背景层，移除前景石堆。
- `src/render/PixiRenderer.ts`：背景层次与建筑/种植变化后的即时刷新。
- `src/render/environmentArt.ts`：停止加载旧石堆图片。
- `tests/cave-moss.test.ts`、`tests/terrain-renderer.test.ts`：覆盖避让、撤销恢复、层次与完工即时刷新。
- 本目录：浏览器脚本、报告和截图。

其他既有工作区改动保留，本轮未更改它们。

- `git diff --check`：通过。
- 隔离 Chromium、软件 WebGL：1440×960 与 390×844 实景检查通过，运行时错误 0。使用当前规则完成设施、序列化校验的独立夹具，不访问玩家存档。
- 浏览器夹具中建设前苔斑位于第 12、30、36 列；灶台、餐桌、菜园建好后仅第 36 列的未建设洞壁保留，验证结果见 [browser-report.json](browser-report.json)。
