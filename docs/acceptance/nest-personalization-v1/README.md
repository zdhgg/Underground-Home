# 心心的小窝标记：交互与实景验收

- 当前关注对象：刚建好或主动打开的那一间小窝。阿土根据真实床位说出入住伙伴。
- 主要操作：选择星星、叶子或水滴后，点“把标记挂上去”。关闭、Esc 和“先去探索”可退出；之后回到当前引导或自由建设。
- 标记随小窝写入 v24 存档；房间详情提供再次选择入口，旧式独立床舱可以直接点开。撤销小窝时标记随设施移除。旧档未选标记不会被强制补选。
- 玩家在入住演出期间接管画面或离开时，不再次拉回镜头或弹出邀请。小窝说明在有空间时避开设施的完整范围；极窄舞台没有足够空间时使用屏内兜底。

2026-10-27 在隔离的内存存档场景实测：约 947×592 桌面视口和 390×844 手机视口，从预设小窝开工到伙伴入住、选择标记和回到引导均可走通；标记选择时小窝保持可见。另一轮检查了旧式小窝的重新选择与已选状态。

已知限制：约 256×555 的极窄视口中，舞台可用宽高不足以同时容纳完整小窝与面板，面板仍可能遮挡小窝，后续应设计更紧凑的交接方式，不能仅靠结构断言视作通过。
