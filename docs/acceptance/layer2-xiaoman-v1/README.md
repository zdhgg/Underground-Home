# 第二层小满与第一层引导验收

> 2026-10-20 后续：种植区、菜槽、水缸和第一顿饭已整体移到第二层，见[第二层菜园验收](../layer2-garden-v1/README.md)。本页保留“小满先下到第二层 + 第一层引导”这一轮的记录。

2026-10-20。按用户建议调整：第一层保留阿灯，小满改为第一次下到第二层时出现；同时给第一层加直接建房入口和一张“家里的小清单”。

## 为什么这样改

- 第一层是“家”：阿土（挖）+ 阿灯（照），把黑暗的避难所点亮、安床。
- 第二层才有“水与土”：小满（种）在那里第一次出现，小泉（引）在找到泉水时出现。
- 原来的“建好床小满就在大厅等”会让第一层同时承担居住、换人、种植三件事，第二层只剩一条取水路。现在把第一次见面放下去，玩家有一个亲自挖下去的故事理由。
- 第一层不是变空了，而是把已经存在但没被看见的内容露出来：住处、旧物、客厅。

## 实际行为

- 第一层建好第一间床时，只有阿土和阿灯入住，**不会凭空出现小满**。
- 第一间床的提示变成“楼下有谁在喊饿”，点裂纹、挖梯道、下去之后，小满出现在泉水层梯脚旁的天然洞穴里，头顶名字可悬停查看。
- 进入第二层后，第二间床才可建；小满在下面等，回大厅建好床就有床位。
- 引导面板在“给伙伴安一个睡眠舱”时直接出现 **「🏠 去建房与扩建」** 按钮，点开就是原来的房间规划面板。
- 收起状态用一行小字显示“家里还能做：住处 / 旧物 n/3 / 客厅”；展开“提示与工具”后是完整的小清单。
- 旧存档里“建好床就加入”的小满站位会被丢弃，整份存档仍可读取；不会因为规则变化读不出旧家。
- 种植区在这一轮仍在第一层；随后已整体搬到第二层，见[第二层菜园验收](../layer2-garden-v1/README.md)。
