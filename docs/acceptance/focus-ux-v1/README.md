# 首间小窝交互聚焦验收

日期：2026-10-23。范围：修复核心、阿灯出场与对话、准备首间小窝、查看建筑、施工与完工；精简共用建议卡和洞室详情。不扩充章节、居民 AI 或存档结构。

## 行为

- 修复核心后，先播放安装与点灯，接着镜头聚焦飞出的阿灯，落地后才出现完整对话。修复时的地图刷新与伙伴站位初始化不会跳过出场。
- 完整对话跟随角色投影位置，避让舞台边缘，短句逐条阅读，最后才出现主要操作。阿灯可带玩家去准备小窝，也可以暂时离开。
- 对话时任务卡、其他建造工具和任务高亮让位，不同时重复绘制角色短气泡。点击地图只关闭对话；拖动可退出对话并看地图。出场期间主动拖图后，不再自动抢镜头或补弹对话。加载已修好核心的存档不重播出场。
- 建议卡只有一个当前主要动作，“需要帮忙？”只解释当前一步。物品栏、伙伴定位保持原入口；壁灯、聊天、梯道、吃饭和家园小清单移入底部的“更多工具与家园”。
- 小窝未挖空时，引导只定位和标出空间，不提前生成蓝图或自动挖掘。挖空后，按钮变为“修建两人小窝”，直接进入这一间的详情。
- 主动打开修建工具时先展示当前楼层的洞室列表；点击具体蓝图或任务则进入单间详情。详情不混入其他洞室列表，用“返回洞室列表”返回。
- 施工时详情收成状态条；收起信息不等于停工，停工使用单独操作。完成后保留当前房间成果，由玩家选择继续探索。
- 窄屏建筑详情放在底部，洞室预览放在上方；楼层标记与返回列表仍以当前洞室为准。

## 本轮变更文件

- `src/App.vue`：互斥的关注区、精简建议、独立辅助工具入口。
- `src/app/session.ts`：出场到对话的交接、关闭点击消耗、准备小窝和高亮协调。
- `src/app/guideAction.ts`（新增）：从现有世界规则选择当前建议动作。
- `src/app/siteEditor.ts`：区分浏览列表与选择单间，保留当前洞室楼层。
- `src/components/GuidePanel.vue`、`PartnerConversation.vue`、`SiteTools.vue`：建议、角色对话、建筑详情与施工状态。
- `src/core/partnerInteractions.ts`：缩短阿灯首次对话，提供准备小窝动作。
- `src/render/PixiRenderer.ts`：出场事件、对话角色坐标、镜头构图与刷新时的出场保护。
- `src/render/conversationAnchor.ts`（新增）：对话定位与边缘避让。
- `tests/focus-ui.test.ts`（新增）、`session-exploration.test.ts`、`terrain-renderer.test.ts`、`partner-interactions.test.ts`：界面、会话交接、真实渲染顺序和文案回归。
- 本目录：浏览器复测脚本、结果与截图。

开始本轮时工作区已有未提交改动（含蓝图出现规则、存档与其他测试）。本轮在其基础上实施，未撤回原改动；上面只列本轮触及的文件，不把其他工作区改动归入本轮。

## 验证

- 实施前 `npm test`：35 个文件、381 项测试通过。
- 最终 `npx vitest run --pool=threads --maxWorkers=1`（`NODE_OPTIONS=--max-old-space-size=512`）：36 个文件、387 项测试通过。
- `npm run build`（`RAYON_NUM_THREADS=2`）：类型检查与生产构建通过。保留现有主包超过 500 kB 的构建提示。
- `git diff --check`：通过。
- `node docs/acceptance/focus-ux-v1/verify.cjs`：通过；开发服务器默认 `http://127.0.0.1:5198/`，可由 `FOCUS_TEST_URL` 指定。
- 浏览器使用隔离 Chromium 上下文、当前版本序列化/反序列化验证过的夹具、真实鼠标操作，未访问玩家浏览器进度。软件 WebGL 渲染覆盖 1440×960 与 390×844；运行时错误 0，详见 [browser-report.json](browser-report.json)。
