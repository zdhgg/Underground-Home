# 进入页与从头试玩验收

> 2026-10-20 更新：本记录描述的“每次从头开始、不保存进度”已被[首页存档验收](../home-save-v1/README.md)取代。进入页现在支持继续游戏、自动保存、重新开始确认和更新记录；以下内容保留首轮验收历史。

2026-10-19。按用户最新要求，当前不需要存档，每次直接从头开始。

## 当前行为

- 打开页面先显示雪景进入页：游戏标题、“开始游戏”、版本号，以及“每次从头开始 · 本次试玩不保存进度”。只有一个主要操作，没有继续游戏、存档列表或旧进度复制入口。
- 进入页复用现有风暴远景、雪林和避难所入口PNG；场景在后台预加载，准备完成前按钮显示准备状态。标题页期间游戏区域设为inert，不能误点或用Tab进入游戏工具。
- 点击开始后才播放已有7.6秒开场，并在同一次点击手势中开启声音。按钮或Esc可跳过，自然结束和跳过都交给原能源石任务。重复开始调用不会重播或重入。
- 默认会话不打开IndexedDB，不读旧存档、不自动保存。刷新回到进入页，再次开始是一张初始地图。旧数据库不参与试玩，也不执行清除操作。
- 版本号从package.json读取，目前为0.1.0，显示“开发试玩版”。
