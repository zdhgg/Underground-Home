# 第01批地形素材接入验收

验收日期：2026-10-17。仅接入提供的 terrain-v1.0 地形 PNG；没有生成、修改或扩大美术范围。

## 变更范围

- `src/assets/art/terrain/`：原样复制16张 PNG，并保留原包 README 与 manifest。
- `src/render/terrainTextures.ts`：加载泥土、岩石各3个变体、洞穴背景、土岩各四向叠图与地表草边；linear 过滤与 mipmap。
- `src/render/PixiRenderer.ts`：64px 图块显示为32px，坐标 hash 选择固定变体；洞穴背景连续平铺；边缘叠加在朝向空洞的实心格上，可多方向组合；草边保留竖井缺口。
- `src/app/session.ts`：仅调整挖掘 / 撤销后的渲染通知，普通变更刷新本格与四邻，发现能源石时仍完整刷新地标。
- `tests/terrain-renderer.test.ts`、`tests/terrain-textures.test.ts`：增加24项资源 / 渲染检查。

世界网格仍为32×32像素，地图44×29格。`src/core/`、`src/input/`、相机、灯光演出和存档数据结构未修改。存档仍为v2。

## 验证记录

1. 原有57项测试在接入检查开始时通过。
2. 先修正实际渲染发现的尺寸错误：`Texture.EMPTY` 上 `setSize` 只留下缩放，切换64px PNG后瓦片会放大；改用记住目标尺寸的 `width` / `height`，真实 Pixi Sprite 测试确认基础纹理与叠图都是32×32。
3. 核对16张运行 PNG 与原包 SHA-256：全部一致。尺寸符合64×64 / 背景512×512；9张边缘图均包含透明像素及可见像素。
4. 用 Pillow 解码实际源 PNG，逐像素比较左右与上下边界；泥土3张、岩石3张及洞穴背景共7张，两个方向的RGB平均绝对误差均为 **0.0**。对照原包 `previews/seamless-repeat.png` 检查单张重复。
5. 自动测试覆盖四向全部16种组合、土岩实心交界、挖掘后两种材质的洞壁、撤销恢复、悬停框清除、地表草边和地图边界、坐标变体稳定性、渲染不修改世界数据。
6. 上述正确性通过后，把局部刷新从9格缩至5格。测试确认单格更新5格、相邻双格去重后8格、地图角落3格；复用既有精灵，不重建整个地形池。没有将刷新格数变化宣称为帧率提升。
7. `npm test`：**9个测试文件、81项测试全部通过**。
8. `npm run build`：**vue-tsc 类型检查和 Vite 生产构建通过**。运行时依赖未增加。
9. 在 `npm run preview -- --host 127.0.0.1` 的生产版浏览器实测单格挖掘与撤销、0.6与2.2倍缩放、发现与收集能源石、修复核心并点亮顶灯、岩石不可挖。刷新页面并等待资源加载后，3/3任务、已挖开的能源石格与点亮状态均恢复。观察中没有明显背景漏线；浏览器 warn/error 日志为空。

## 限制和待验收项

- 素材本身是四向叠图近似方案，不包含独立转角或完整16组合图集；此轮没有补画。不同变体相邻时仍能看到各自石纹走向和重复图案，保留源素材表现。
- 性能验证限于刷新范围及精灵复用，没有跨设备帧率基准。
- 用户最终美术观感验收待完成。开始工作前已有的 `docs/ART_PLAN.md` 与原始 `png素材/` 目录保留，不作为本次提交的新规划或重复素材；运行所需素材和原包说明随代码提交。
