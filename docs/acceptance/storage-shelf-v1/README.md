# 储物架与旧住户故事 · 验收记录

日期：2026-10-24。分支 `zcode/storage-shelf-v1`。范围与决策见 [STORAGE_SHELF_SCOPE.md](../../STORAGE_SHELF_SCOPE.md)。

## 行为变化

- 第一层（点亮核心后）建造工具行出现「📦 摆储物架」：点它进入摆放模式，点第一层有地面的空格放预览，绿/红轮廓 + 短提示，确认建造扣石料 1 + 旧木料 2；可撤销、退材料。
- 挖到旧物后，每一格架子上都会摆出旧物小图标；没有旧物时摆材料示意。
- 点架子本体打开设施面板：石料/旧木料/旧物 n/5 一目了然；主操作「找找没挖到的旧物」（没挖完时，镜头带路）或「翻翻旧物的故事」（挖完后，打开物品栏）。
- 新增两件旧物：**旧照片**（右翼上方泥土，x26 一带）和**旧钥匙**（左翼深处，x2 一带）。照片讲旧住户围桌吃饭的往事，钥匙为更深处的一扇旧门埋下线索。发现计数变为 5 件，物品栏与大厅收藏架同步。
- "家里的小清单"新增"储物架"一项；存档升 v15，旧档照常读取（按没有架子补齐）。

## 复现步骤（试玩）

1. 修好核心后回到第一层：底部工具行有「📦 摆储物架」；「家里的小清单」多了"储物架"一项。
2. 选「摆储物架」，在大厅或左右翼挖空的地面上找一格：绿框可放、红框有原因；确认后扣 1 石料 2 旧木料。
3. 去右翼挖 x26 一带的泥土 → 挖到「旧照片」；去左翼深处挖 x2 一带 → 挖到「旧钥匙」。
4. 回到架子前：两件旧物的小图标已经摆上架子；点架子打开面板，主操作变成「翻翻旧物的故事」→ 打开物品栏，读照片和钥匙的故事。
5. 点「撤销」：架子拆掉、材料退回；旧物不丢（发现过的还在物品栏与收藏架）。
6. 刷新页面：架子、旧物、材料都在（v15 存档）；用 v0.2.x 的旧档继续也正常。

- 旧物小图标在窄屏下的可辨识度需实机检查。
