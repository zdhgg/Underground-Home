# 育苗架与新菜种 · 验收记录

日期：2026-10-24。分支 `zcode/nursery-v1`。范围与决策见 [NURSERY_SCOPE.md](../../NURSERY_SCOPE.md)。

## 行为变化

- 点已建好的菜园打开面板，底部多了一条虚线入口「🌿 搭育苗架，种新菜」；点击进入摆放（第二层、石料 2 + 旧木料 2、绿/红预览、可撤销）。
- 育苗架搭好后：点它打开面板，主操作「摆一槽番茄」；第二层工具行也出现「🍅 摆番茄槽」。番茄槽和蔬菜槽一样：浇水/干活长大、熟了小满来收（反馈是"红红的番茄"）、食物 +1。
- 还有番茄苗时，撤销不会再拆掉育苗架；番茄槽本身可撤销。
- 泉水边多了两簇发光蘑菇（呼吸的柔光）：第一次点它采下菌伞、弹「发现发光蘑菇！」，整簇随之消失，菜槽随后可以放到这些格子。（2026-10-28 修正：先前采集后仍保留菌根贴图、残光和呼吸光圈，容易被理解为没有拾取成功，详见[拾取验收](../mushroom-pickup/README.md)。）
- 泉水右侧的红土层（x19—21 上两格）挖出红黏土，进物品栏；第一块弹「发现红黏土！」。物品栏在拥有黏土后多一张材料卡。
- 存档升 v16；v15 及更早旧档照常读取。

## 复现步骤（试玩）

1. 玩到引水完成、菜园建好：点菜园 → 面板底部「🌿 搭育苗架，种新菜」→ 摆在泉边空地（2 石 2 木）。
2. 点育苗架 → 「摆一槽番茄」→ 点空地放下；浇水、干活让它长大——果实是红色的一串。
3. 熟了点它（或菜园面板「叫小满来收菜」）：小满收番茄、食物 +1、提示"红红的番茄"。
4. 点撤销：番茄槽可撤；番茄还在时育苗架撤不掉（提示保留）。
5. 到泉水边找两簇发光蘑菇（泉水右侧、菜园一侧的洞壁）：点一下 → 「发现发光蘑菇！」；试着在蘑菇格摆菜槽 → 会提示这里要留空。
6. 挖泉水右侧偏红的泥土（x19—21 一带的上两层）→ 挖到红黏土，物品栏多一张卡。
7. 刷新页面：育苗架、番茄、黏土、发现状态都在；v0.2.x 旧档继续玩正常。

## 已知限制与待人工检查

- 育苗架与番茄为程序化造型（无手绘 PNG）；蘑菇菌伞仍为程序化绘制，采集后整簇消失，不再保留菌根素材。
- 番茄与蔬菜做出的饭在灶台/餐桌演出中不区分（同一结算同一画面）；若试玩中孩子期待"番茄饭"，后续可加菜盘差异。
- 黏土暂无用途（本阶段只入栏）；物品栏材料卡仅在拥有黏土后出现。
