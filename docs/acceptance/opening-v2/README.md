# 开场地面演出 v2

2026-10-19。本轮在现有开场中展开“冷 → 发现入口 → 避风回暖”的情绪，随后接回原能源核心与能源石线索。

## 演出

| 时间 | 画面与台词 |
| --- | --- |
| 0–0.7 秒 | 阿土在风雪中走来，减速停下。 |
| 0.7–3.2 秒 | 收拢爪子、发抖、呼出白气：“好冷呀……” |
| 3.2–5.6 秒 | 抬头轻跳一下，头顶短暂出现惊讶亮线；入口透出柔和灯光：“咦？那边有个入口！” |
| 5.6–7.6 秒 | 加快脚步靠近入口，扶梯进入避风处。 |
| 7.6–9.8 秒 | 停下来缓一口气，停止发抖，局部暖光与风声减弱配合：“啊，暖和一点了！” |
| 9.8–14.8 秒 | 镜头随下梯移动，走到停转核心旁，转头发现蓝光。 |
| 14.8–16.55 秒 | 蓝光后停在核心旁，阿土对心心说：“这里就是我们的地下小家园。”画面出现轻量家形标记，字幕与气泡保持同一关注对象。 |
| 16.55–18.1 秒 | 镜头拉回家园视角，交接给“找到发光的能源石”第一项行动。 |

四句对白分别停留 2.5 / 2.4 / 2.2 / 1.75 秒，显示对白时角色与镜头不移动。气泡字号由 12 调至 14 世界像素，宽度随文字计算；底部字幕同步显示角色说的话。小于600px的窄屏使用更近的镜头，让阿土与入口同框。惊讶轻跳只发生一次；回暖效果集中在入口与角色身边，地表风雪仍继续。此处的暖意表示避风后好受一点，核心仍未修好；最后的家形标记把停转核心旁的空间交给心心，避免开场只像一次任务导航。

纯时间线统一提供角色、镜头、天气与声音的节拍。演出仍使用独立替身，收尾或跳过后正式角色在原位置，任务保持 0/4。

## 验证

- `npm test`：28 个测试文件、321 项全部通过。覆盖全程 120Hz 路线与身体范围、移动连续性、每句至少两秒、对白期间镜头停留、入门后才回暖、天气分段连续、各阶段跳过和自然结束的世界与镜头一致性。
- `npm run build`：类型检查和生产构建通过；保留既有的主包超过 500kB 提示。
- 浏览器 20 项检查全部通过，运行时错误为零：桌面八个故事阶段、自然结束、九个时点跳过（含 Esc）、900×620 和 390×844 完整播放与任务衔接。详细结果见 [browser-report.json](browser-report.json)。实景已核验四句气泡、家形标记、入口回暖、手机取景及底部对白可见。
- 浏览器验证脚本：`node docs/acceptance/opening-v2/verify.cjs`，使用隔离 Chromium 上下文与固定时钟。`OPENING_TEST_URL` 可指定服务地址，默认 `http://127.0.0.1:5194/`。使用 Windows D3D11，以 10fps 驱动真实 ticker，气泡和动作通过真实画布截图核验；测试不注入世界或任务状态。

## 本轮变更文件

- `src/render/openingTimeline.ts`：集中定义节拍、停顿、路线与天气曲线。
- `src/render/OpeningScene.ts`：白气、收爪发抖、惊讶动作、柔和局部暖光、家形标记和气泡排版。
- `src/render/openingSound.ts`：风声衰减和脚步速度跟随新节拍。
- `src/render/PixiRenderer.ts`：对白同步到底部字幕，竖屏开场拉近取景。
- `tests/opening.test.ts`、`tests/terrain-renderer.test.ts`：调整并补齐节奏、路线、完整播放与跳过回归。
- `README.md`、旧版验收入口及本目录：更新时长与验证资料。

当前无必需工程项遗留。对白仍以文字气泡呈现，声音为现有合成风声、脚步和提示音，未加入真人配音；儿童实际阅读速度与主观观感还需试玩观察。
