# 自由房间基础：第2阶段验收

日期：2026-10-18。状态：工程实施和自动检查完成，等待玩家试玩。范围依据：[分阶段实施方案](../../ATU_HOME_IMPLEMENTATION_PLAN.md)第2阶段；本次“继续下一阶段”只推进房间基础。

## 体验与操作

点亮能源核心后，底部出现“房间”入口。选用途，点暖窝层已经挖通的空间，用“−／＋”调整宽度，预览合法后确认。拖动仍只平移地图；关闭面板或按Escape取消未保存的预览。

- 三种用途：住处、种植区、客厅。先划区域，再按原规则放床或菜槽；用途不限制混合设施，不凭标记新增床位、水、作物或产量。
- 宽度3至9格，创建时自动适配两格或三格高的洞室。旧床上方可能还有土，因此不强制三格净高，也不要求拆床重建。编辑已有房间时保留原高度。
- 房间只圈已挖空、有地面、接到大厅的首层空间；不能重叠、跨梯口、压住能源核心或切开睡眠舱。后放的床也须完整落在区域内，或完整在区域外。
- 地面色带、洞壁角线和小标牌表现嵌入岩层的区域。没有实体隔墙，标记不阻断阿土的路线；全景缩小时隐藏标牌。
- 点已有房间或面板中的条目可选中；调整用途和宽度，或点另一片未划区空地预览新位置，再“保存调整”。重定位只移动标记，不搬设施。
- 可“布置新房间”或“移除标记”。移除保留床、菜槽和地形；创建、调整、移除都进入本次会话撤销栈。刷新后仍不支持撤销刷新前的动作。
- 未划区的旧设施照常可用；建床后只给可跳过的房间建议，不增加强制任务。规划面板替换左侧向导，退出即恢复原探索操作。

## 存档与保护

格式升级为**v9**，新增独立的房间数组及单调递增的房间编号。房间拥有稳定ID、用途和范围，不提前加入伙伴工作、等级或个人床位字段。

旧v8及此前受支持存档保留原地形、设施、工具、水电和作物，房间默认为空；不会自动把连通洞穴全部认作房间。编号在移除和撤销后不复用。损坏的房间范围、重复编号或未知用途显示加载失败反馈，并禁止本次会话覆盖失败数据。继续使用独立试玩库，不访问正式旧库。

撤销旧挖掘不能把已划房间或其承托填回土；先移除相关标记。设施仍使用原有通行、建设和资源判定，房间不额外引入门、供氧、封闭性或生产规则。

## 未完成项与限制

- 第3阶段伙伴专业工作尚未启动；本阶段没有自动生活、成长升级、四间独立卧室、厨房或烹饪。
- 只在首层已有建设带划房间；不扩图、不放开深层建造、不改变坚硬岩层权限。
- 客厅目前提供用途与视觉分区，没有新增聚会模拟；空种植区不提供种植功能。
- 宽度可调，高度按现有洞室自动选取；没有手动拉框、多边形房型、门窗或承重模拟。
- 窄窗口的长房间列表需滚动；触屏房间操作和真实儿童对“划区域”的理解仍需试玩确认。
- 主包仍超过默认500kB提示线，未调高阈值隐藏提示；拆包优化未纳入本阶段。
