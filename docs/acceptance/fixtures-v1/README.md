# 入口梯架与顶灯美术验收

日期：2026-10-17。本轮只补入口梯架和顶灯两件美术，没有进入新建设阶段。

## 变更文件

- `src/assets/art/landmarks/shaft-ladder-v1.png`、`ceiling-lamp-v1.png`：内置imagegen生成的透明PNG，原样保留。
- `src/assets/art/landmarks/SHELTER_FIXTURES_V1.md`：实际规格、透明度检查、显示约定和两份完整生成提示词。
- `src/render/shelterFixtures.ts`：加载两图，创建一份梯架和7份灯具精灵。梯架仍起于原竖井顶部、长160世界像素；灯具共用原灯光坐标，宽32世界像素，灯芯锚点校准为`(0.5, 0.59)`。
- `src/render/PixiRenderer.ts`：替换旧线条梯架，加入静态灯具层；结构受原黑暗遮罩影响。未通电灯具压暗，随原逐盏点亮进度恢复。光晕、灯芯大小、闪动、点亮顺序和时序保持原实现。
- `tests/terrain-renderer.test.ts`：增加未通电显隐、灯具数量 / 坐标 / 比例 / 分层、地标刷新复用、渐亮和灭灯回归验证。
- `README.md`：新增验收记录入口。

`src/core/`、`src/input/`、`src/app/session.ts`、相机换算、32px世界网格和v2存档没有修改；没有新增依赖。

## 实际验证结果

- `npm test`：**10个文件，90项测试全部通过**。
- `npm run build`：**vue-tsc类型检查、Vite生产构建通过**。
- Pillow仅用于解码检查：梯架1024×1536 RGBA、1,212,348个完全透明像素；顶灯1254×1254 RGBA、835,166个完全透明像素。两图四角透明，梯架踏棍之间透明，未修改生成图像。
- 新建本地端口4176的生产预览，实测0/3 → 挖开能源石 → 收集 → 安装 → 3/3点亮流程。
- 未通电时灯具可见但玻璃明显压暗；通电后恢复明亮，光晕和灯芯对齐。修正了初次实景中浅色玻璃看起来像已通电的问题。
- 自动测试验证中途只有前3盏发光、最终7盏全部亮起，光晕和灯芯共14条绘制指令；退回未通电状态会重新压暗。
- 地标刷新、逐帧光照不重建8份固定结构精灵；复用一张梯架和一张灯具纹理。
- 2.2倍近景检查梯架、金属固定件、灯壳与灯芯，无图像拉伸；拖动与回到家园保持正常。
- 0.6倍最小缩放已验证，画面可正常显示；刷新等待素材加载后仍为3/3，梯架、灯具和点亮状态恢复，不重播安装。浏览器warn/error日志为空。
