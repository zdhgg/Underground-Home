## 自动测试已覆盖

- 完整终章从检查、护框、逐格凿岩、实际下楼到天然暖晶说明；玩家读完确认后才交电梯，不让发现被下一任务盖过去。
- x16／x27 两条旧梯口接入，前八层地形保留，九层能沿真实通道回家；基岩、地板、梯口和暖晶受到保护。
- 两套不同布局和建设顺序都能通关，九人长桌可放左翼或右翼；九个座位互不相同，不锁唯一蓝图。
- 阿灯和阿木实际到暖光台协作；小满在五层装粮后送达，团团与小泉在六层装水后送达，铃铃从七层送新风铃；大厅原作保留。
- 备餐到达长桌后才扣粮仓食物 1／回廊存水 1；重复点击不重复扣费，取消取货或运输、过期回调都不能补结算。
- 九条赴席路线并行，每位实际到达只记一次；最后一位之前不开席。中断保留已送达备餐，可继续邀请，不瞬移、不重复消耗。
- 苔苔铺菌叶、阿土留故事；主题选择只改变待确认意图，铃铃实际布置后才改变场景。
- 玩家主动进入全剖面回望，九页回忆手动翻阅；中断保留已读页，不要求全收藏，不自动翻页或定时拉回镜头。
- 九页未读完不能完成终章；完成态可保存和恢复，继续游戏页显示“九层家园 · 终章已完成”。
- 后日谈能重读、再看全景、自由建石凳／休息、换布置；再次聚餐顺序接好送食物、送清水、九人赴席，永久完成态不回退。
- 备餐撤销可退食物／清水，池子已满时不溢出退款；开席、已读回忆和终章里程碑不撤销，已使用电梯延长和必要通路受保护。
- 停帧、后台／离页、取消、重复落手与重复回调安全释放；各进度阶段和跨层移动代表性快照均可恢复。
- 九站电梯从真实当前楼层发车、阿木到站后走出吊篮，旧八层档不能提前进入未延长的新站。
- 真实 App 与真实面板覆盖暖晶说明、选址、备餐、布置确认、赴席、九页回忆、庆典、旧设施／对话、全景与九站导航：同一可交互舞台最多一个主要面板、一个主要推进按钮。
- 真实 Pixi 场景对象覆盖设施／备餐／纪念图案在人物后侧、九位伙伴保持；窄屏目标不沉底。主动回望后可缩放、平移，连续帧不触发自动返回，不修改世界数据。
- 八类本地 WebAudio 音效经过统一静音与后台门禁；生成暖晶进入物品栏，可定位原处；四层相册有终章回馈。
- v23 支持真实 v22 44×100 存档只追加新层，原输入不变；更早版本迁移继续回归。拒绝伪造护框、暖晶、设施、备餐／聚餐计数、主题和回忆顺序。

测试替换 GPU／资源入口或动画时钟，保留真实规则、控制器、Vue App 和 Pixi 对象。测试环境中的备用绘制提示来自受替换的旧素材加载，不代表运行游戏时 PNG 加载失败。

首次相机测试发现“全图已容纳视口时，平移受边界约束”及测试假视口与假渲染器尺寸不一致；修正测试为先缩放、使用一致视口，再验证平移与连续帧不返回，生产镜头规则未放宽。终章最后复查补了暖晶介绍的玩家确认交接，并重新验证。

## 实景尚未验收

已启动隔离开发服务器并尝试通过内置浏览器打开终章待开席页面，工具仍因 Work 设置禁用本地浏览器使用而阻止。没有绕过设置，也没有第九章游戏截图。生成原图查看、DOM 和 Pixi 对象断言不能代替颜色、镜头时序或人物遮挡检查。

仍需检查：暖晶 alpha 柔光与岩层融合、九个凳子／九位角色的比例与遮挡、桌面食物瓶碗和风铃落点、纪念壁九格图案对齐、并行赴席与跨层搬运节奏、移动端两行楼层导航和短屏主按钮、触屏点挖与拖图区分、实际音量、首次加载与低性能设备表现。

## 隔离复现

执行 `npm run dev -- --host 127.0.0.1 --port 5174` 后：

- `/tests/manual/finale.html`：前八章完成，准备检查暖晶接缝。
- `?phase=entered`：刚进入第九层，准备挖路和建设。
- `?phase=working`：主线设施与暖光就绪，准备跨层搬运。
- `?phase=ready`：三路送物、菌叶、故事与布置就绪，准备邀请九位伙伴。
- `?phase=completed`：永久终章完成，测试重读、再看全景、再次聚餐、自由布置。
- `/tests/manual/finale-device.html`：398×756 独立 iframe，供窄屏实景复验。

以上开发页使用内存存档，不读取或覆盖玩家 IndexedDB，不进入生产入口。真实玩家从第八章完成后使用第九层导航进入终章。
