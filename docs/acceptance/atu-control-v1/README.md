# 阿土移动与实际挖掘：第1阶段验收

日期：2026-10-18。状态：工程实施和自动检查完成，等待玩家试玩。范围依据：[分阶段实施方案v2](../../ATU_HOME_IMPLEMENTATION_PLAN.md)第1阶段。

## 体验与操作

- 点可到达空地，阿土沿真实通道走过去；点较高空洞会寻找该位置下方的合法地面。
- 点松软泥土，立即标出目标和施工方式；阿土自动走近，落爪接触土面后才挖开所选的一格。
- 近处低层侧挖、较高处向上伸爪，现有三格建设带的顶部使用一格高短踏台。踏台有地面和净空检查，不能跨洞、叠加、压设施或让阿土穿顶。
- 土面被挡住、道路不通、身体净空不足时，提示先开路；不会替玩家挖掉前面的格子。普通坚硬岩石仍不能挖，裂纹岩沿用小铁镐、真实走位和原连挖条件。
- 点新目标可替换普通移动或泥土施工；重复点同一目标不会重新走路。已发生的挖掘保留，尚未发生的旧回调失效。
- “停下来”或Escape取消操作；拖动只看地图。右下角“找到阿土”只定位镜头，不瞬移角色。手动拖图后不强拉镜头，找到阿土后可恢复边缘跟随。
- 阿土只显示一个可操作形象，床位保留，建床后继续陪玩家探索。其他伙伴保留原来的入住和休息。角色名按指向显示，单次短回应仍保留。

建床时若阿土会被设施占住或隔断回家路，先沿真实通道走到安全一侧再施工；取消让位过程不会继续建床。撤销挖掘时若会埋住阿土的身体，先退到安全格再恢复土；没有退路则保留地形和待撤销记录。

## 存档

位置与“发现裂纹”解耦，因此格式从v7升级为**v8**，继续使用同一个独立试玩数据库，不打开正式旧库。没有新增经验、资源或角色等级字段，仍复用`exploration.explorer`和原工具标记。

- v7已有地图、床、镐、水、电和种植成果保留。
- 旧档若把阿土放在只有一格高的旧通道里，迁移到安全大厅并显示说明，不修改地形。
- v8检查站位、身体净空和回家通路。非法站位读取失败有反馈，并沿用禁止覆盖失败存档的保护。
- 移动途中只记录实际到达的安全格；踏台高度和半段动画不写入存档，重载不会重复落爪或悬空。
- 原有历史存档兼容测试保留；撤销仍只覆盖本次会话，刷新后不能撤销刷新前的操作。

## 当前限制与未完成项

- 只完成第1阶段。房间、独立卧室、其他伙伴专业工作及能力升级均未开发。
- 只鼠标/触摸点按控制阿土；无WASD、跳跃、四人切换、普通土批量队列和通用施工梯。
- 短踏台覆盖当前三格建设带；更高施工暂不可用。站位会复用，踏台每次动作后收起，尚未增加跨指令保留踏台的优化。
- 阿土当前保持可操作待命，保留床位；没有新增主动睡觉操作或睡眠模拟。
- 设施占地仍会限制可达道路，伙伴站位和房间空间关系在后续阶段完善；不能靠新移动功能穿越已建睡眠舱。
- 未进行真实儿童试玩。需要玩家判断点选目标、短踏台动作、远距离走路和镜头跟随是否易懂、节奏是否合适。
- 构建主包刚超过默认500kB提示线，未通过调高阈值隐藏提示；拆包优化留待后续。
