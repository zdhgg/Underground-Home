# 游戏界面收整验收

日期：2026-10-18。范围：收紧游戏 HUD，让地图成为主要画面；沿用现有玩法、地图、建造、伙伴工作与存档规则。

## 已调整

- 目标与计数合并进左上角阿土卡片，去掉顶部重复任务。桌面默认卡片实测约 288×122px；完整台词、结果说明、聊天及工具在“提示与工具”展开后显示，可按 Esc 收起。
- 引水、送电、铁镐升级、阿灯的新办法、连续挖掘、吃饭按现有可用状态显示一个快捷操作。完整操作仍保留在展开区；壁灯选址时提供直接退出入口。
- 原右侧楼层面板改为顶部三个文字按钮：暖窝、泉水、全景，保留选中状态。窄屏改成标题下面单独一行，按钮至少 44px 高。
- 缩放合并成一个控制组；寻找伙伴与阿土靠近右下角撤销。建设入口收紧后放在左下，去掉两行重复说明。
- 地图图例与资源信息移至底部状态栏，旧存档导入移至展开区。原有里程碑与操作反馈保留。

## 变更文件

- `src/App.vue`：HUD 组合、条件快捷操作、状态栏与布局样式。
- `src/components/GuidePanel.vue`：紧凑目标、展开收起、Esc 与焦点恢复。
- `src/components/DepthNavigation.vue`：横向楼层导航与窄屏排布。
- 本目录：验证说明、默认/展开/窄屏效果图。
