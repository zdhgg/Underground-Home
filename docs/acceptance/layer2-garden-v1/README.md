# 第二层菜园与第一顿饭验收

2026-10-20。承接上一轮“小满在第二层出现”，把种植区、菜槽、水缸和开饭演出整体移到第二层；第一层只保留住处、旧物和客厅。

## 实际行为

- 找到泉水后，引导从「把水引到家里」改成 **「把水接到菜园」**；小泉仍在泉边接管，水缸和短水管就在第二层菜园边。
- 下到第二层后，左下角工具出现 **「🌱 种植槽」**；点它，再点泉水边有地面的空地，确认后菜槽落在第二层。
- 菜槽仍按“玩家干活”生长；熟了之后小满从她的位置走过去收，收成后可以在第二层直接请伙伴吃饭。
- 引导最后一步改成 **「在泉水边种出第一份食物」**；高亮从第一层建造区改为第二层菜园建议区。
- 第一层的“建房与扩建”只剩 **住处 / 客厅** 两种新用途；旧存档里的第一层种植区仍可读、可扩建、可收菜，只是不再作为新玩家的引导。
- 第二层菜槽不能放在泉眼、梯道列或没有地面承托的位置；没真正下过第二层时也不能隔层种。
- 第一层的水缸和上楼水管只在旧档仍有第一层菜园时绘制；新开档的水管只连到第二层菜园，避免两套水路同时出现。

## 实际验证

- `npm test`：**30 个文件、336 项通过**。
- `npm run build`：**类型检查与生产构建通过**。
- 生产预览：`http://127.0.0.1:5196/`，隔离 Chromium 上下文，使用第二层验收夹具。
- 浏览器验证 2 组：第二层工具放下菜槽并写入存档；第一层“家里的小清单”仍只讲住处、旧物、客厅，不混入菜园。
- 无页面运行时错误。结果见 [browser-report.json](browser-report.json)，复跑脚本为 [verify.cjs](verify.cjs)。

## 变更文件

- `src/core/farm.ts`：菜槽允许第二层，必须真正下过第二层；泉眼和梯道留空；第一层旧槽继续通过校验。
- `src/core/missions.ts`：引水改为接水到菜园，菜园高亮指向第二层，最后一步改名。
- `src/core/world.ts`：新增 `gardenSuggestion`，菜槽注释改为第二层。
- `src/render/farmProps.ts`：水缸移到第二层，新增第二层短水管；旧第一层菜园保留上楼水管。
- `src/render/PixiRenderer.ts`：水流动画、接水水花、开饭水花移到第二层；旧档走旧水管。
- `src/App.vue`：第二层“种植槽”工具、接水按钮文案、去第二层种菜的引导。
- `src/app/session.ts`：`startPlanting()`、菜槽确认后的提示、开饭镜头下移、引水里程碑改名。
- `src/app/roomEditor.ts`、`src/components/RoomTools.vue`：新房间只保留住处/客厅，并提示菜园在第二层。
- 测试新增第二层菜槽会话链路，更新引导文案、伙伴对话和菜槽层规则。

## 未做

- 第二层还没有“菜园房间”这种可圈地扩建的房间类型；现在用一格格种植槽自由摆放，先验证孩子能不能自己找到并种下。
- 厨房、灶台、餐桌仍是后续；本轮只把“种菜 → 收获 → 开饭”的镜头和位置放到第二层。
- 旧第一层菜园不强制迁移；如果实际试玩觉得两套位置容易混，再单独做迁移或引导清理。
