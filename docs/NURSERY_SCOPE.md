# 育苗架与新菜种（S5 / 基线 2C）决策

> 日期：2026-10-24。分支 `zcode/nursery-v1`，基于 main（含 S4）。
> 上游依据：分阶段实施方案 S5 批次；设计基线 §5.7（发现物 #8 发光蘑菇、#9 红黏土）、§6.3（升级 #3 育苗）、§7.2（设施 #9 育苗架）。

## 解决的问题

农场循环单一（只有一种菜）；设施面板框架还没有兑现"升级入口"的承诺；2C 的两项发现物（发光蘑菇、红黏土）未落地。

## 决策

1. **育苗架 = 菜园面板的第一个升级入口**（S2 护栏的兑现：升级随内容批次出现，且必须是新动词）。菜园面板出现虚线次入口「🌿 搭育苗架，种新菜」（一次只出现这一项）；点它进入摆放模式（石料 2 + 旧木料 2），规则与菜槽同构（第二层、承托、避让、不重叠）。
2. **新菜种：番茄**。育苗架搭好后：点育苗架面板的「摆一槽番茄」、或第二层工具行的「🍅 摆番茄槽」，番茄槽与蔬菜槽费用相同、照料与收获完全同一条路（浇水/干活长大、小满到场收、食物 +1），画面上番茄有红色果实外观、收番茄有不同的反馈语——"我会种番茄了"是孩子说得出的新做法。
3. **旧菜园不变**：已有蔬菜槽照旧；撤销护栏——还有番茄苗时育苗架不能"撤销没建过"（番茄失去来处）；番茄槽本身可正常撤销。
4. **发光蘑菇（发现物）**：泉水边固定两簇（泉水右侧与菜园一侧的潮湿洞壁），呼吸的柔光纯视觉；这些格子对菜槽保留（不与作物抢地）；第一次点到采下菌伞并弹「发现发光蘑菇！」卡片，整簇随之消失，原地恢复为可建设的空地。（2026-10-28 修正：先前采集后仍保留菌根贴图、残光和呼吸光圈，容易被理解为没有拾取成功；现在改为一次性清空，见[拾取验收](acceptance/mushroom-pickup/README.md)。）
5. **红黏土（发现物 + 材料）**：泉边红土层（泉水右侧 x19—21 的上两格泥土）挖出红黏土，进物品栏（挖与撤销对称）；第一块弹「发现红黏土！」卡片。本阶段不做配方——它是后续陶罐/装饰的材料，红黏土不阻塞任何前置。
6. **存档 v16**：新增 `nurseries`、`Planter.crop`、`foundMushroom`/`foundClay`、`Inventory.clay`（可选）。v15 及更早旧档按默认补齐（无育苗架、无番茄、未发现）；"有番茄却没育苗架"的存档判损坏。

## 边界（不做）

- 不做真实时间等待、配方、菜种轮换策略；番茄与蔬菜照料规则完全一致。
- 不做烹饪差异（番茄与蔬菜做出的饭同一结算、同一演出）；不把蘑菇做成可收获材料（采下后整簇消失，不进物品栏）。
- 升级入口一次只出现"育苗架"一项；不出现数值、等级。
