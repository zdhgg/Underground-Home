# 阶段 2：水向上、菜长在暖窝层

> 2026-10-20 更新：本记录描述的是当时的“第一层种植”。现在新菜园已移到第二层泉水边，见[第二层菜园验收](acceptance/layer2-garden-v1/README.md)；第一层旧菜园仅作旧档兼容保留。以下内容保留历史实施记录。

基线：`3728a35`（阶段 1：床数 = 伙伴数、泥土里有遗物）；分支 `codex/first-spring-breakthrough`。
诊断与总路线见 `docs/LAYER1_CONTENT_REVIEW.md`，本轮做的是其中的③「种植与生产」。

## 要解决的问题

阶段 1 之后，第二层的水第一次有了用处（新朋友肯来住），但水本身还停在泉水层：玩家把水找到就结束了，
第一层仍然没有"需要照看的东西"。这一轮把水引上来，让第一层从居住空间变成**生产空间**——
也就是 GAME_BRIEF 里"为什么挖：能源、水源、居住与生产空间"里的生产那一块。

## 1. 引水：水从第二层回到第一层

| 阶段 | 玩家要做的 |
| --- | --- |
| 找到泉水后 | 伙伴面板出现 **「🚰 把水引到家里」** |
| 点它 | 阿土沿真实通道走到泉边接水管 → 水花从泉边一路往上冒 → 镜头跟着管子走 |
| 完成 | 大厅出现**水缸**，梯道旁一条**水管**从泉水层直通上来；水管里有水在流动 |

- 规则层只加一个纯判定 `canSupplyWater(world)`（找到泉水且还没引水），**位置不用玩家选**——水管只能沿唯一那条梯道走，让 7 岁孩子做这道选择题没有意义。
- 引水是一次委托：阿土先走位再施工，和破岩、听水声同一套"指定目标 → 阿土执行"的语言。
- 中断安全：切后台 / 画面被冻住时委托会被看门狗安全取消，**按钮立刻解锁**（本轮顺手修掉：原来中断后按钮会永久卡在"阿土在接水管……"）。

## 2. 第一层种植槽：一格一槽，位置自由

| 规则 | 内容 |
| --- | --- |
| 什么时候能种 | 水引到家里之后，建造工具里出现 **「🌱 种植槽」** |
| 能放哪儿 | 第一层已挖空、**下面有实心地面**的格子；梯道列、能源核心、能源石、遗物那一格、睡眠舱占位都不行 |
| 不能放哪儿 | 第二层（`layer`）：深层建设留给以后的阶段 |
| 怎么收 | 槽不能挖掉（点它是收菜）；放错了用左下角的撤销 |

## 3. 生长按"你干了多少事"推进，不用等

- 每放下一槽就自动种下一颗；**玩家每亲自做一件事**（挖一格土、破一段岩、安一盏灯、建一间舱、收一次菜）所有作物长一档。
- 三档成熟：种子 → 发芽 → 长大 → 熟（熟的槽每帧有呼吸光圈 + 小星星，一眼看出能收）。
- 符合 PHASES 的"无意义的强制等待不计入游戏时长"：孩子随时收，绝不会对着计时器等。
- 收获：成熟的槽 +1 份食物，槽自动重新种下；**第一份收成**弹里程碑卡片。

## 4. 请伙伴吃饭

- 收过第一份之后，伙伴面板出现 **「🍽 请大家吃饭（食物 n）」**；点它 → 伙伴原地开心蹦跳 + 爱心和彩纸 + 三音上行。
- 消耗一份食物；没有食物时按钮显示"先收点菜再开饭"并禁用。空舱、没伙伴时不能开饭（`feedPartners` 拒绝）。

## 5. 引导：8 步一条线

`explorationGuide` 从 6 步扩到 8 步，中间插进"把水引到家里"和"种出第一份食物"：

```
听水声 → 换镐 → 挖梯道 → 下去 → 找到泉水 → 把水引到家里 → 安顿新朋友 → 种出第一份食物
```

- 需求顺序仍然是"先有问题、再给手段"：泉水层是水，第一层是菜和床。
- `finished` 只有在**新朋友安顿好且收过第一份**之后才为真（本轮修掉一个小毛病：只收过菜时徽章就打了勾，但还有一步没做）。

## 存档：v5 → v6

- `WorldState` 新增 `farm`：`{ waterSupplied, planters: [{id,x,y,growth}], food, harvests }`；`WORLD_VERSION` 5 → 6。
- v5 旧档照常可读：`farm` 按默认值补齐（未引水、无槽、没有存粮），探索与睡眠舱进度原样保留。
- 严格校验（`validateFarm`）：没有泉水却"有水"、没引水却种了菜、生长档位越界、食物为负、槽位落回土里或悬空——一律拒绝并给出可读错误。

## 已知问题与下一阶段

- **引水演出没能在内置浏览器面板里跑完**：该面板的帧会被节流，3 秒后看门狗安全收尾；演出本身由自动测试覆盖，真实浏览器里正常。
- 作物生长靠"玩家干活"推进：如果孩子只想种菜不想挖土，攒食物会慢一点。这是刻意的取舍（不做真实等待），如果试玩觉得慢，只要调 `advancePlanters` 的调用点或成熟档数。
- 阶段 3（未做）：第一层专属设施（储物箱、书架、装饰）+ 把电从核心沿梯道下引到第二层设施。
