# 第一阶段双层纵深原型：风险与最小范围

## 设计决策

依据 AGENTS.md、GAME_BRIEF v0.5、PHASES 和 SPACE_DEPTH_REVIEW；采用一张连续剖面，不切换独立场景。评审中的44×46地层试点在用户反馈后收窄：**楼层按居住高度定义，不能在一层内再挖出好几层房间。**

最终蓝图为44×28：地表y0–3；第一层大厅y7–11，两翼住宅净高y9–11（3格、96px），统一地板y12；硬岩隔层y12–14；第二层低矮天然洞y18–21、共用底面y22，预览泉水位于(26,21)。核心大厅5格净高保留现有机身和灯具。两翼横向可用宽度31格（原左右口袋合计18格），允许自由选址，保持岩壁边界。

## 实施前发现的风险及处置

| 风险/基线差异 | 本阶段处置 |
| --- | --- |
| 原泉水偏在右侧，未体现“向下发现” | 下移到明确的第二层，配同图下移镜头与全景 |
| 原型最初把一层做成过高的土带 | 收至3格住宅净高，连续硬岩地板；左右建设，避免高洞与多层混在一起 |
| 原左舱常比大厅地面高2格，需要爬墙 | 常用舱位改到共同地板上；入口落地连通，测试验证伙伴路径无竖直段 |
| 世界尺寸变化会让正式旧档失效 | 使用独立Git工作树、独立原型数据库；不读取正式旧档，不采用评审建议的“重置旧地图” |
| 请求成功不代表IndexedDB事务已提交 | 保存等待事务完成；事务中止报告失败；损坏档读失败后禁止覆盖 |
| 全局点灯会把第二层一起照亮 | 第一层沿用原点灯时序，深层保留固定黑暗；不引入通用照明系统 |
| 地图放大可能触发全图寻路/悬停开销 | 最终地图面积略小于原图、可达住宅高度受限；同格悬停不重复校验，复用一次性路径；不做S1级寻路系统改造 |
| 缩远误挖、拖动迷路 | 全景只观察；当前楼层随镜头变化；一键回家恢复可操作缩放 |
| 落地入口扩展后，能源石邻格已空可能被提前收走 | 收集同时校验能源石本格已挖空，防止跳过发现步骤 |

## 边界

只实现第一阶段空间和导航原型。保留Vue3、PixiJS、现有四步任务和第一间双人舱。复用已有手绘PNG及冷暖调色，无新依赖、无新图像素材。第二层“未开放”是真实规则边界，查看按钮仅移动镜头。

暂不实施弱岩突破、工具升级、层灯建造、电梯/可建梯、跨层居民行为、泉水生产、温室、资源计数、通用设施系统、正式旧档迁移。未来如果开第二层，必须配真实竖向交通，不能让居民悬空穿层。等待用户验收后再确定下一阶段。
