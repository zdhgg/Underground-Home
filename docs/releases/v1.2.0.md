# 心心的小家园 v1.2.0

2026-10-29。**让探索的收获，变成家的温暖。**

这一版把第三层的工坊成果带回第一层，让已经建好的小窝继续变暖；把主线与九层导航收进阿土的探索小本子；再添两项可选的家园心愿，提醒玩家回到旧楼层看看还能做点什么。九层主线、家庭记忆、小窝标记和自由建设继续保留。

> 本文件为 v1.2.0 正式发布说明。GitHub Release：https://github.com/zdhgg/Underground-Home/releases/tag/v1.2.0

## 新增

- **小窝暖光灯**：第三层岩壁工坊做出的部件可以带回第一层，给真实建成的小窝添一盏暖光灯。阿灯沿现有通路走过去施工，到场并完成动作后才扣除 1 个部件；可以撤销，多间小窝各自独立，重进后灯仍亮着。第三层未完成、没有真实小窝或部件不足时不会安装。
- **我的家园心愿**：阿土的探索小本子里新增两项可选心愿：
  - **🪔 给小窝添盏暖光灯**：第三层完成后，第一层仍有未装灯的小窝时出现；全部装好后消失，新建未装灯小窝后会重新出现。
  - **🥕 菜长熟啦！**：真实成熟菜槽出现时提醒；收完最后一槽后消失，下一茬成熟后重新出现。
- 点击心愿只把镜头带到真实小窝或成熟菜槽，不自动安装、不自动收获、不扣材料、不保存独立任务进度。缺料时仍显示“还差1个工坊部件……”，不会误导成可以直接安装。

## 优化

- **探索小本子**：当前主线、家园心愿和九层导航收进同一本小本子；主线在上、心愿居中、楼层在下。选择楼层后小本子收起，让出游戏画面。
- **九层导航**：顶部恢复单行工具栏；已开放楼层直接可见，未开放楼层展开后说明原因；窄屏默认收起，章节、设施或伙伴工作出现时自动让位。
- **手机端空间与触控**：窄屏心愿改为“图标＋短名称＋去看看”的紧凑横向条目，普通说明收起但缺料提示保留；心愿按钮触控高度达到 44px。390/360 宽度下首屏可看到“去哪里？”和第一条楼层入口，无横向溢出、按钮文字不被截断。
- 桌面端继续显示完整心愿说明，视觉层级不变。

## 下载与启动

GitHub Release 附带 `Underground-Home-v1.2.0-web.zip`，内容是本版生产构建，共 84 个文件。解压后通过 HTTP 静态服务器提供目录，不能直接双击 `index.html`。例如安装 Python 后，在解压目录执行：

```sh
python -m http.server 3018 --bind 127.0.0.1
```

打开 `http://127.0.0.1:3018/`。源码运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3018 --strictPort
```

生产构建与预览：

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 3018 --strictPort
```

发布包为 **94,385,614 字节**，84 个文件已与最终生产构建逐文件校验。另附 `.sha256` 文件；ZIP 的 SHA-256 为：

```text
cef362a0904dbc0f9ea03bf79fc22ca8f12996ed9114285ce94d0b88ddeeda1b
```

## 存档与范围

- 世界存档保持 **v26**，兼容 v25 与更早受支持版本（含 v0.2.0 的 v13）。无需重开或额外迁移。
- 家园心愿完全由世界状态重新计算，不写入 `wishes`、`wishProgress` 或完成历史；旧档读取后会按当前小窝、材料和作物状态重新生成。
- 自动存档仍保存在当前浏览器、当前网站来源中。改变协议、主机或端口会使用不同的网站存储。
- 没有新增第十层、伙伴、资源、付费、后端、伙伴工作队列、家具系统或更多心愿；没有升级存档版本。
