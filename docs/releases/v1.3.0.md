# 心心的小家园 v1.3.0

2026-11-02。**让家里有等你回来的人，让每一步都知道自己在哪。**

这一版做两件事：让已经建好的家更像一个家——客厅进主线、伙伴会饿会困会等你一起坐；让九层建设每一步都接得上——第三层里程碑轨道、选址与挖掘输入分离、成果卡先落地再交接、各层都能「我自己去地图上找」。九层主线、家庭记忆、小窝标记和自由建设继续保留。

> 本文件为 v1.3.0 正式发布说明。GitHub Release：https://github.com/zdhgg/Underground-Home/releases/tag/v1.3.0

## 新增

- **暖暖客厅进主线（存档 v28）**：第一层「留个一起坐的地方」排进主线第 5 步——安床之后、下楼之前。蓝图仍由阿土逐格清土、完工才扣材料；不锁死选址，预设洞室和自己挖的客厅都算数。已经玩到楼下的旧档自动算这一步完成，不会被要求回头补课。
- **☕ 一起坐一会儿**：客厅建成后出现主要按钮。伙伴从待命位真的走过来坐到长椅前，说一句家里的近况；第 1 次铺上地毯、第 2 次角落添花，次数写进存档。不消耗食物和材料、没有倒计时，坐得越多客厅越暖。
- **两块能源石点亮家园（存档 v27）**：修好核心需要先找到两块能源石，第一块先让核心暖起来，给孩子看得见的「快好了」。
- **伙伴照顾时刻（存档 v29）**：隔一阵子伙伴会点名心心想吃饭（接现有围坐开饭），困了会自己回窝睡觉；家园节奏叠加安静时长信号，热闹之后留得出安静。
- **第三层交互连续性**：
  - 章内四个里程碑（🦔 凿开新路 → 💎 点亮晶簇层 → 🔧 建起工坊 → 🛗 三层电梯），把连续小步压成看得懂的大目标轨道。
  - 还没建的设施收进默认合起的可选目录，推荐顺序不变，锁住的条目写明前置原因。
  - 选址时点泥土**不再误挖**：只聚焦这块土并提示「先挖开这里」，切入明确挖掘模式后一次挖一格，「挖好了，继续摆放」一键回到原设施选址。
  - 建好或加工后先看**成果卡**（真实投入与产量），主动点「下一步」才切换目标和地图高亮；撤销成功会清掉旧成果说明。
- **九层「我自己去地图上找」**：第 4–9 章面板可以收起，当前目标在地图上发出金色引导框「在这里」；点中目标照常交接回面板，不反复抢镜头。
- **金色推荐位与影子吸附**：第三层建造给出金色推荐位，只提示不限制选址；各层选址影子跟着指针滑到最近能放下的位置，优先不压住发现点，点中推荐位直接使用。
- **章末主线移交**：晶簇层完成后的「下一步」指向全局主线真正的下一目标，与小本子主按钮同一入口。

## 优化

- **一起走过去**：阿土和动手的伙伴同时走向现场，都到了伙伴才开工；伙伴优先站相邻格，不再串行等位。
- **施工动作更实**：小满浇水改为俯身加水珠（去掉凭空手臂），小泉接水管俯身冒泉珠，阿灯升到灯位迸火花装灯。
- **面板头顶写明在哪**：各层详情卡显示「小满的菌床 · 第 5 层」式标题，自由拖图时也知道自己正在看谁。
- **手机任务卡**：固定在舞台下方、主要操作固定卡片底部、正文可滚动；材料、配方、自选建筑和升级默认收起；移除让人紧张的步数计数。
- **小本子更清楚**：区分「正在看」和「任务在」（主线已在另一层时不误导），主线按钮改为「去看看」；主动拖图或缩放后交回真实镜头判层，不再抢回。
- **镜头归位更准确**：竖井支撑与组装电梯定位到第三层井口（此前误用第二层坐标）；下层抵达只在未主动拖图时做最后一次归位。

## 下载与启动

GitHub Release 附带 `Underground-Home-v1.3.0-web.zip`，内容是本版生产构建。解压后通过 HTTP 静态服务器提供目录，不能直接双击 `index.html`。例如安装 Python 后，在解压目录执行：

```sh
python -m http.server 3018 --bind 127.0.0.1
```

打开 `http://127.0.0.1:3018/`。源码运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3018 --strictPort
```

生产构建与预览：

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 3018 --strictPort
```

发布包为 **97,515,520 字节**，84 个文件，内容与最终 `dist` 生产构建一致。另附 `.sha256` 文件；ZIP 的 SHA-256 为：

```text

```

- 本轮交互连续性沿用 v29 结构，不增加持久化任务状态；选址、明确挖掘、成果卡与引导高亮都是会话内交互，不写存档。

- 没有新增楼层、伙伴、资源、付费、后端、伙伴工作队列或家具系统；客厅「一起坐」不消耗食物和材料。
