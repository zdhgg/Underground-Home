# 心心的小家园 v1.1.1

2026-10-28。本次改善九层主线交接、楼层导航和伙伴工作反馈，让玩家在任何一层都能找到当前目标。家庭记忆、小窝标记、九层自由建设和原有章节规则继续保留。

## 交互变化

- **一个当前目标**：先完成第一、二层任务与探索，再依序交给第三至九层第一个未完成章节；每次进度刷新只提交一个最终目标。目标来自真实世界状态及原有 Goal、Ready、completed 判定，不用计数猜测章节是否完成。
- **共餐后继续探索**：第二层首次共餐后能接到第三层；仍可从灶台和餐桌重复做饭。后续章节新伙伴等床不会让第二层引导回退。
- **统一引导入口**：九层普通游玩共用楼层、目标、一个主按钮和折叠帮助。主按钮打开对应章节，关闭详情后回到当前主线；对话、施工、共餐演出和全景按现有注意力规则交接。
- **锁层可点按解释**：说明缺少的真实前置条件，保留锁定视觉状态。查看楼层只移动镜头、不让角色瞬移；窄屏收进“楼层”菜单，支持 Escape 退出。
- **伙伴工作更清楚**：显示姓名、工作和赶路/动手/返回阶段。拖图、缩放、查看楼层与物品栏不会取消工作；点新目标给出提示，点“停下来，换个目标”后恢复正常交互，已完成成果保留，旧回调无效。
- **终章后自由建设**：九层全部完成后显示“九层家园建好啦，接下来由你继续布置”，主按钮打开九层家园全景。

## 下载与启动

GitHub Release 附带 `Underground-Home-v1.1.1-web.zip`，内容是本版生产构建。解压后通过 HTTP 静态服务器提供目录，不能直接双击 `index.html`。例如安装 Python 后，在解压目录执行：

```sh
python -m http.server 3018 --bind 127.0.0.1
```

打开 `http://127.0.0.1:3018/`。源码运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3018 --strictPort
```

生产构建与预览：

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 3018 --strictPort
```

发布包为 94,489,064 字节，84 个文件均已与生产构建逐文件校验。另附 `.sha256` 文件；ZIP 的 SHA-256 为：

```text
eb0c9e654a4f3104edb6758ee87126a86770b14b89447cabdfad9a386877b3c9
```

## 存档与范围

- 存档格式保持 **v25**，兼容 v24 与更早受支持版本（含 v0.2.0 的 v13）；无需重开或额外迁移。旧档加载失败时继续说明原因并保护原数据。
- 自动存档仍保存在当前浏览器、当前网站来源中。改变协议、主机或端口会使用不同的网站存储，访问新端口不会自动带入旧端口的进度。
- 没有新增第十层、伙伴、资源、付费、后端、复杂 AI 或任务队列；没有更换美术和增加第三方依赖。

## 已知限制

- 未使用实体手机/平板做触屏、长期性能或麦克风权限测试，未进行儿童现场试玩。
- 九章阶段由真实世界夹具进入并实景检查，未人工从头连续通关；完整章节推进与中间存档恢复由自动化测试覆盖。
- 主 JS 包仍超过 500 kB，手绘素材使首次下载较大；本次未处理资源压缩。照片与录音随存档增加体积的原有限制继续存在。
- 未实现通用任务队列或双指捏合缩放。记忆匣照片/录音及极窄视口的原有未验收项见 [v1.1.0 说明](v1.1.0.md)。
