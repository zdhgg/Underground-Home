# 地下小家园 v0.1.0

首个公开发布版本，包含双层地下剖面与第一夜的点灯、睡眠舱建设体验。

## 可玩的内容

- 一张连续地下剖面：第一层暖窝住宅区、坚硬岩层、第二层天然泉水洞预览。
- 住宅净高3格，睡眠舱高2格；左右自由选择位置，共用实心地板，核心大厅稍高。
- 找到并收集能源石、修复核心逐盏点灯、自由建造第一间双人睡眠舱，伙伴沿通道入住。
- 单击挖一格、拖动平移、建造预览与确认/取消、挖掘和建造撤销。
- 回到家园、向下看看、家园全景；全景只观察，第二层暂不可挖建。
- Vue3 + PixiJS；延续手绘卡通地形和现有设施美术。

## 启动

源码需要Node.js与npm：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 3018 --strictPort
```

打开 `http://localhost:3018/`。本地门户若已启动3018服务，只需刷新原入口。

Release另附已构建的 `Underground-Home-v0.1.0-web.zip`：解压后用HTTP静态服务器运行，不能直接双击index.html。也可在源码中执行 `npm run build` 和 `npm run preview`。

## 存档与升级说明

新版使用带版本号的v4格式，数据库为 `underground-home-depth-prototype-v2`。原来的 `underground-home` 数据库保持原样，**旧版进度不会自动导入，新版首次打开会从新家园开始**。同浏览器、同来源下的双层原型存档可继续恢复。

存档按来源隔离，`localhost:3018`与`127.0.0.1:5185`的进度不同。读取失败会给出提示并禁止本次会话覆盖失败数据。撤销栈仅限本次会话，刷新后不会保留撤销历史。

## 验证与范围

115项自动测试通过；TypeScript类型检查和Vite生产构建通过。浏览器已验证找石、点灯、选址建舱、伙伴入住、撤销重建、刷新恢复、楼层镜头、全景和第二层锁定。

第二层解锁、工具升级、竖向交通、跨层居民行为、泉水生产、温室和完整生态尚未实现。尚未完成真实儿童试玩及目标平板实机性能验收。当前发布不包含战斗、付费、账号或后端。

美术素材与截图位于仓库内；项目保留MIT许可证。具体变更和试玩步骤见 `docs/acceptance/depth-v1/README.md`。
