# 施工委托式探索：实施决策与风险

基线：`b1fb502`（首次突破岩层试玩版）；开发分支：`codex/first-spring-breakthrough`。依据 AGENTS.md、GAME_BRIEF v0.5、PHASES 与 `docs/FIRST_BREAKTHROUGH_SCOPE.md`。本轮为同一分支上的操作定位收口，未发布。

## 为什么改

原实现里"玩家点击空地 → 阿土走过去"是一套自由移动操作，与"玩家是地下堡垒的建设者"的定位冲突：

1. 第二层的挖土其实不需要阿土在场（规则只要求挖在已探明的地面范围），但引导文案写着"点空地，我会走过去"，孩子会以为必须先移动角色。
2. 破岩是"隔空单格挖掘"：点一下裂纹岩，远处那块岩立刻消失，阿土全程站在梯口不动，破岩没有演出感。
3. 阿土的移动、挖掘、探索是三套互不相干的输入，孩子要同时记住三种操作。

本轮把操作统一为一句话：**玩家只指定目标，阿土自己执行**。

## 新操作模型

| 玩家点的地方 | 行为 |
| --- | --- |
| 普通泥土 | 立刻挖开一格（不变，不需要阿土在场） |
| 带裂纹的岩石（或它下面已挖开的梯段） | 施工委托：阿土沿真实通道走到那一段上方，挥镐，落镐那一刻才挖开，梯子同时接长一段 |
| 裂纹岩（还没换小铁镐） | 阿土走到裂纹上方听水声；只有走到才记录线索 |
| 露面的泉水 | 阿土沿已挖通的地面走到水边，抵达才算发现 |
| 已经挖空的空地 | 不再让阿土走动（只提示"这里已经挖空啦"） |

点击空洞格同样算继续施工：目标自动解析成"这条梯道最上面那块没挖开的岩段"，方便孩子连点同一个位置。

## 最小修改范围

- **规则（core）**：`exploration.ts` 新增 `moleRoute`（阿土的自动路线：优先从当前站位出发，还没进场时从大厅地面出发）、`shaftFrontier`（梯道下一个施工目标）、`HALL_STARTS` / `HALL_START_Y` / `SHAFT_LAST_Y` 常量；`inspectCrack`、`explorationAccessIntact` 复用这些常量。
- **存档校验（core/persistence）**：未抵达时阿土的合法站位从"必须在梯口 y=11"放宽为"必须在这条梯道内（x=梯道列，y 在梯口与最下一格之间）"。其余版本号、字段、校验强度不变，仍是 v5。
- **装配（app/session）**：删除"点空地移动阿土"分支；新增 `orderBreakthrough`（听水声 / 破岩的委托分流）与 `orderBreak`（走过去 → 挥镐 → 落镐才改世界）；泉水改为只认"露面泉水"这一个目标。
- **画面（render）**：`ExplorationScene` 增加挥镐演出（小铁镐、落镐时机回调）、裂纹呼吸与"下一块"目标环、洞口微光（接通后先在洞口透出一线），`PixiRenderer.playRockBreak` 与 `BurstOptions.gravity`（水汽上飘）。
- **文案（missions / App.vue）**：引导、图例、底栏、楼层提示改为"指定目标"的说法，删掉所有"点空地/我会走过去"。

**不改动**：地下分层与蓝图、梯子自动接长规则、任务链结构与完成判定、存档版本与存储键、既有美术素材、依赖清单；不新增角色控制、居民 AI、资源或新玩法。

## 风险与处理

| 检查发现 | 本轮处理 |
| --- | --- |
| 自由移动删掉后，玩家可能找不到阿土能去哪 | 每个可委托目标都有明确提示：裂纹脉冲 + "下一块"目标环 + 阶段化标签 + 任务高亮 |
| 演出期间点地图会插队或隔空破坏 | 走路与挥镐期间锁输入（复用 traveling），落镐才调用 `dig`，点别处只给一句提示 |
| 阿土在梯道里存档会不会被判为非法站位 | 校验改为"在梯道列内、位于梯口与最下一格之间"，并用测试和真实浏览器刷新验证半挖存档能读回 |
| 连点同一个位置、点错岩段 | 目标自动解析为最上面那块未挖岩段；另一条裂纹只给"以后再探索"的提示 |
| 第二层看不见变化 | 接通瞬间：水声、洞口凉风水汽、洞底光环、洞口透出一线微光；下梯后才全面揭开迷雾 |
| 新增演出拖慢节奏 | 一次委托约 1 秒（走路 + 挥镐），可连续点击逐段推进 |

## 验证与回退

- 自动测试：`tests/exploration.test.ts` 新增施工委托用例（目标解析、路线、半挖存档、非法站位拒绝），`tests/session-exploration.test.ts` 重写为"委托 → 走路 → 落镐"的会话流程并新增"点空地不移动"用例。
- 实机验证与截图见 `docs/acceptance/builder-orders-v1/README.md`。
- 回退：本轮只改本分支；如试玩认为破岩演出过慢或委托模型不合适，可单独回退 `src/app/session.ts` 的委托分流与 `src/render/explorationScene.ts` 的演出，规则层（`moleRoute` / `shaftFrontier`）与存档校验可保留。
