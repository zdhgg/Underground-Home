# 第七章 · 听风工区

2026-10-26。用户授权设计和实现第七章，本轮增加蝙蝠铃铃与完整通风／手作章节。第八、九层继续保留规划，第九层仍是终章。

## 完整流程与新朋友

蓄水回廊巡游完成 → 看见下方旧飘带一动不动 → 检查旧风井 → 阿岩装风井护框 → 沿实际梯道逐段凿岩 → 阿土下到第七层 → 挖通右侧路、认识蝙蝠铃铃 → 当前面板读完介绍 → 阿木延长第七站电梯 → 自由选址建进风口、风机、消音百叶、手作台 → 铃铃沿真实通道听风接管 → 玩家确认家园微风 → 检查飘带 → 确认工区风 → 选风铃或叶片风饰、做一件作品 → 调回家园微风 → 阿土与铃铃实际走回大厅送作品 → 给铃铃留真实床位 → 阿土、铃铃、阿木分开到场听风 → 第七章完成。

铃铃稳定身份 `lingling`，核心动词“听风”，床位优先位 8，是第九位伙伴。独立造型为大耳朵、折翼、小脚与赭黄领巾；沿已挖通的通道移动，施工动作使用耳侧回声线。没有任意穿岩飞行。旧八位的 ID、床位和顺序不变；四层暖屋宴继续固定原六人名单。

小泉与团团仍负责水路，阿岩负责凿岩，阿木负责机械和手作。铃铃靠听风检查管路与调节百叶，不取代原伙伴的工作。新层回馈是大厅里真正挂上的作品、轻轻摇摆的风铃／风饰，以及纪念墙的新记录。

## 自由建设与可重复手作

| 设施／动作 | 费用 | 结果 |
| --- | --- | --- |
| 风井护框 | 石料 2、旧木料 2、部件 1 | 只开放新风井施工，保留老家 |
| 七站电梯 | 部件 2、晶簇 1 | 实际抵达后更新位置，旧梯子与六站仍可用 |
| 岩缝进风口 | 石料 3、旧木料 1 | 宽 3，岩壁后侧格栅 |
| 岩拱送风机 | 石料 3、旧木料 2、部件 2 | 宽 4；关机／家园微风／工区风 |
| 消音百叶 | 石料 2、旧木料 2、部件 1 | 宽 2，明确飘带与风路反馈 |
| 听风手作台 | 石料 3、旧木料 3、部件 1 | 宽 5；制作铜管风铃或叶片风饰 |
| 铃铃岩壁小窝 | 石料 3、旧木料 3 | 宽 4，两个真实床位；老家已有空床可复用 |
| 听风／调模式／检查／送礼 | 不额外收费 | 伙伴实际到场完成后结算 |
| 做一件手作 | 旧木料 1、部件 1 | 工区风下做一件，明确扣料，只保留一件待送作品 |

四件风工设施各一件，位置和建设顺序由玩家决定。必须挖出四格高、有实心地板的洞壁，保留梯口与前侧通路；四件设施之间的连续净空决定横向风管，不会自动穿岩，完全不同的布局也可完成。只要求有空床，不强制把新伙伴的小窝建在某个位置。

模式有明确用途：关机停止风机和飘带运动，家园微风用于首次检查与大厅作品展示，工区风让台上的小风车转动并允许制作。选择模式只改变确认意图，实际模式在铃铃到场完成调节后改变。

手作采用“一件待送作品”：已有成品不能重复制作或换种覆盖；到大厅送达后，最新作品挂在固定展示点，前作保留在累计送礼记录里，不形成无限物品堆。章末后可再选另一种作品，仍交接“调回微风 → 实际送礼”，不会被重复巡游抢走目标。制作和送礼都能在本次会话按依赖撤销；取消送礼保留成品，章末床位与已用施工通路受保护。

风机不消耗第六层存水，也不新增全家空气条。环境问题仅为旧风井和静止飘带：不缺氧、不伤害、不闷倒、不损坏旧家，不增加倒计时、离线衰减、气流物理、战斗或后端。可选回声石与旧风标只记录故事，可在物品栏定位，不作为章末门槛。

## 关注对象与交接

| 情境 | 当前关注对象 | 唯一主要操作 | 退出方式 | 完成后的交接 |
| --- | --- | --- | --- | --- |
| 入口／凿井 | 当前岩缝或这一段阿岩施工 | 检查、护框、开工中的一项；工作中没有推进按钮 | 收起、Esc、停下来 | 下一岩段／实际下楼 |
| 铃铃相遇 | 右侧铃铃与站在旁边的阿土 | 打招呼，再读铃铃的说明 | 收起、Esc | 玩家读完后进入电梯目标 |
| 选址 | 当前设施的一个位置框 | 就在这里建造 | 收起、Esc，不扣材料 | 建成后进入下一目标 |
| 风机模式 | 当前风机和待选模式 | 确认调节风机 | 收起，模式不变 | 伙伴实际调节后交检查或手作 |
| 手作台 | 当前作品 | 制作或送礼中的一项 | 收起／停下来 | 成品反馈、调微风、送到大厅 |
| 送礼途中 | 携作品的阿土与铃铃 | 无推进按钮 | 停下来、收起、后台取消 | 到大厅才挂作品，下一床位／巡游目标 |
| 听风巡游 | 三人实际站位 | 开始；演出中无推进按钮 | 停下来、收起 | 同一面板内庆典，继续建设 |

模式选择、换作品、折叠建设与七站电梯为安静辅助操作，不并列为主要推进按钮。主要情境面板和主按钮标记 attention 契约；相遇与庆典不叠加中央成就卡。短屏说明内部滚动，主操作和停止按钮固定可见。玩家拖图或关闭后，送礼抵达不抢回镜头；刷新内容也不重新定位。

重复点击、过期回调、停帧、后台／离页和取消均不补扣材料、不提前送达。阿土与伙伴沿实际通道移动；巡游三人到达各自位置后才写完成态。
