# 环境生命感（S3）决策

> 日期：2026-10-24。分支 `zcode/ambient-life-v1`，基于 main（含 S2）。
> 上游依据：分阶段实施方案 S3 批次（纯渲染层，可与其他批次换序）。

## 解决的问题

两次点击之间世界是静止的：除了伙伴的呼吸/眨眼，环境没有自主的生命感。"温暖、安全、被需要"的情绪基调目前主要靠文字承载，画面本身承载得不够。

## 决策（全部纯视觉，不写世界、不进存档、不参与交互）

1. **灯光浮尘**（新模块 `ambientLife.ts`）：核心修好后，大厅七盏顶灯和第二层每盏壁灯的光柱里各有三粒微尘，沿确定性轨道缓缓打转、明暗呼吸。同一个小世界每次刷新得到同一批（无随机、无逐帧状态）。
2. **待命伙伴的微粒**：每 2.4 秒轮到一位在场伙伴，身边轻轻飘起一颗小微粒——小满=嫩叶色、小泉=水色、阿灯=暖光色，约 1.1 秒消散。
3. **泉水滴落与涟漪**：找到泉水后，洞顶水珠断续滴进泉面（从泉水上方第一块实心岩落下），砸出一圈圈扩散的涟漪；原有水面微光与上升水泡保留。
4. **洞顶垂苔**：苔藓从地面扩展到洞顶——与地面苔错开三列，挂在每列洞道最高空格上方的实心岩下沿；洞道挖到三格高时垂苔随之上移。避让规则与地面苔一致（设施、泉水、梯口、水缸、蓝图）。
5. **闲置轻起伏**：站着的朋友约每 7 秒轻轻起伏一次（幅度约 3px 的短促抬头），叠加在既有呼吸动画上；休息/工作/庆祝状态不叠加。
6. 地表风雪与树摇已由 SurfaceScene 实现，本轮不做。

## 验收口径

- 静止画面 10 秒内出现可见的自主变化：泉边（滴水/涟漪）、有灯的室内（浮尘）、有待命伙伴处（微粒、轻起伏）。
- 全部为低开销 Graphics 绘制（约 30 个圆点/帧 + 每列苔藓静态图元），不新增纹理与依赖；帧率以目标平板实测为准（本轮未做平板实测）。

## 实施结果

- 变更：新增 `src/render/ambientLife.ts`；`caveMoss.ts`（洞顶垂苔）、`explorationScene.ts`（滴落与涟漪）、`PixiRenderer.ts`（接入环境层与闲置起伏）。
- 验证：41 个文件 **435 项测试通过**（新增 5：浮尘确定性/条件、伙伴微粒节奏、垂苔列位与升降级）；`vue-tsc` 与 `vite build` 通过。
- 验收记录：[acceptance/ambient-life-v1](acceptance/ambient-life-v1/README.md)。
