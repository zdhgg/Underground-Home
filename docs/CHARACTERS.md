# 四位小动物

日期：2026-10-18
上游：`docs/GAME_DEFINITION.md`（为朋友造家）、`docs/GROWTH_DESIGN.md`（伙伴 = 动词）
本文是角色设定，不含代码改动。

---

## 一句话

**四个伙伴，四个动词，四种性格。**

孩子记住的不是"解锁了种植系统"，是"小满来了，我们能种菜了"。所以每个角色必须同时是三样东西：**一个能记住的形象、一个能学会的动词、一个能模仿的口头禅。**

---

## 阿土 · 鼹鼠 · 挖

> **"交给我！"**

**他是谁**：这个避难所的老住户。你进来的时候，他已经在挖了——虽然这里又黑又冷，但他一直觉得"再挖一格就会好起来"。

**性格**：热心、话多、有点逞强。别人还没开口，他就说"我来我来"。挖得很快，但经常挖过头，然后把土堆到自己身上。

**外形**
- 圆滚滚的灰褐色身体（现有 `0xa8ba8e`，可以调暖一点，像湿土）
- 两只大爪子，比身体还显眼
- 一副小圆眼镜——他视力不好，挖洞靠鼻子
- 粉色鼻尖，一直在动

**口头禅**
- "交给我！"
- "我闻到土的味道了！"
- "再挖一格，就一格！"（然后挖了三格）

**出场**：一开始就在，正在刨土。

**小动作**
- 走路：一蹦一蹦（腿短）
- 挖土：两只爪子快速刨，土往身后飞
- 开心：原地转圈，然后摔倒

**他会说的话**

| 场景 | 台词 |
| --- | --- |
| 第一次见面 | "你也是来躲风的吧？这里虽然黑，但是土很软，能挖。" |
| 玩家挖土 | "对，就是这样！再挖一格！" |
| 玩家挖到岩石 | "这个太硬了，我的爪子不行……得找把镐。" |
| 玩家建床 | "床！我最喜欢床了！" |
| 玩家闲着不动 | "要不要挖点什么？我手痒。" |

## 阿灯 · 萤火虫 · 照

> **"……我可以照亮这里。"**

**她是 who**：她一直躲在角落里。不是不想出来，是太黑了，她不敢。你点灯之前，她只有尾巴尖上一点点微弱的光。

**性格**：安静、胆小、温柔。说话很轻，经常说一半就停。但她是四个人里最会照顾人的——谁害怕，她就飞到谁旁边。

**外形**
- 圆圆的小身体，淡紫色（现有 `0xb9a7e0`）
- 一对半透明的小翅膀
- 尾巴末端有一盏小灯——不亮的时候是灰的，亮起来是暖黄绿
- 两条细触角

**口头禅**
- "……我可以照亮这里。"
- "别、别怕，我在。"
- "……"（小声，然后飞到你旁边）

**出场**：一开始就在，但躲在角落，只露一点点光。**修好核心的那一刻，她才飞出来。**

**小动作**
- 飞行：忽高忽低，像在水里飘
- 害怕：尾巴的光一闪一闪
- 开心：绕着你转圈，撒下小光点

**她会说的话**

| 场景 | 台词 |
| --- | --- |
| 点灯前（角落） | "……好黑。" |
| 点灯后（飞出来） | "亮了……你、你把家点亮了。" |
| 玩家挖到暗处 | "这里太黑了，我、我陪你去吧。" |
| 玩家建灯 | "灯……我喜欢灯。" |
| 玩家很久没回来 | "你去哪儿了……我有点怕。" |

**为什么她重要**：她是"点亮"这件事的**情感见证**。玩家修核心不是"完成了一步任务"，是"把一个怕黑的朋友从角落里请了出来"。

## 小满 · 兔子 · 种

> **"能吃了吗？"**

**她是谁**：她是闻着"家的味道"来的。有床、有屋顶、有人，就是家——她在上面闻到了，就下来了。

**性格**：活泼、爱吃、急性子。想到什么就说什么，经常打断别人。对"吃"有执念，什么都能联想到吃。

**外形**
- 长耳朵，一只立着一只耷拉
- 浅粉色（现有 `0xe9b6a7`）
- 两颗大门牙
- 圆尾巴

**口头禅**
- "能吃了吗？"
- "这个能吃吗？"
- "我饿了。"（平均每 30 秒说一次）

**出场**：第一间床建好后，她从竖井探出头："这里有人住吗？我闻到床的味道了！"

**小动作**
- 走路：蹦蹦跳跳，落地会弹一下
- 等待：脚一直在跺
- 看到菜：耳朵竖起来，流口水

**她会说的话**

| 场景 | 台词 |
| --- | --- |
| 第一次见面 | "你们有床！我可以住下来吗？我会种菜！" |
| 玩家种菜 | "种子要埋深一点……不对，再浅一点……算了，我来！" |
| 菜熟了 | "熟了熟了熟了！可以吃了吗？" |
| 吃饭 | "好吃！这是我吃过最好吃的东西！"（每次都这么说） |
| 玩家不种菜 | "那个……我们是不是可以种点吃的？" |

**为什么她重要**：她把"种植"从"一个系统"变成"一个吃货的请求"。孩子不会为了"产出食物"去种菜，但会为了"小满饿了"去种菜。

## 小泉 · 水獭 · 引

> **"水会告诉我们答案。"**

**他是谁**：他是从泉水里冒出来的。没人知道他为什么在那儿，他自己也说不清——"我一直在水里，然后就遇到你了。"

**性格**：慢悠悠、爱水、有点迷糊。说话慢，喜欢用"水"打比方。喜欢收集小石头，口袋里永远有几块。

**外形**
- 圆脸、小圆耳朵、三根胡须
- 沙黄色（现有 `0xe5cf95`）
- 身上总是湿漉漉的，有一层水光
- 尾巴又粗又扁

**口头禅**
- "水会告诉我们答案。"
- "慢慢来，不着急。"
- "这块石头真好看。"

**出场**：找到泉水后，他从水里冒出头，甩了甩水："咕噜……这水真甜。你要吗？"

**小动作**
- 走路：摇摇摆摆，像在陆地上游泳
- 开心：仰面躺下，肚皮朝天
- 引水：抱着水管接水，水花四溅

**他会说的话**

| 场景 | 台词 |
| --- | --- |
| 第一次见面 | "你找到我了。这水很好，我可以帮你引上去。" |
| 玩家引水 | "顺着管子走，水认识路。" |
| 玩家种菜 | "菜要喝水，就像我们要吃饭。" |
| 玩家挖到深处 | "下面的水更凉，我闻到了。" |
| 玩家着急 | "慢慢来，不着急。水也是慢慢流的。" |

**为什么他重要**：他是"深度"的信使。他说的"下面的水更凉"，是给玩家的第一个"下面还有东西"的暗示。

## 他们在一起的样子

一个好的"家"，应该能一眼看出四个人的分工：

```
阿土在左边刨土，土往身后飞
阿灯在他头顶飘着，照亮那一小块
小满坐在床边，脚在跺，等开饭
小泉躺在水缸旁边，肚皮朝天
```

**这就是"家"的画面**。不需要任何 UI，孩子看一眼就知道"这里住着四个人，他们各干各的"。

如果要加一个小细节：**四个人都在的时候，阿灯的光会稍微亮一点**（她不怕了）。

| 伙伴 | 出场条件 | 现在的代码 | 要改什么 |
| --- | --- | --- | --- |
| 阿土 | 初始 | 已存在（`BASE_PARTNERS = 2`） | 只改外观与台词 |
| 阿灯 | 初始就在，但躲在角落；**修好核心后出来** | 已存在（同一位） | 加"躲藏 → 出现"的演出 |
| 小满 | **建好第一间床后** | 现在要等"找到泉水"才来（`PARTNERS_AFTER_SPRING`） | 解锁条件从"找到水"改成"建好床" |
| 小泉 | **找到泉水后** | 同上 | 解锁条件改成"找到水"，单独触发 |

**一句话总结这个调整**：把"水位决定人数"改成"每个人有自己的理由"。

- 现在：`springFound` 一开，伙伴数从 2 变 4，两个人一起出现。
- 建议：建好床 → 小满来；找到水 → 小泉来。每人一个理由，每人一个时刻。

| 索引 | 现在 | 建议 |
| --- | --- | --- |

| 1 | 浅粉 | **阿灯**（淡紫） |
| 2 | 淡紫 | **小满**（浅粉） |
| 3 | 沙黄 | **小泉**（沙黄，不变） |

只需交换索引 1 和 2 的颜色，其他不动。

## 台词的三条规则

写所有台词时守住这三条，比写得多重要：

1. **不超过 12 个字。** 7 岁孩子读不完长句。超过就拆成两句，或者干脆不说。
2. **说"我"，不说"系统"。** "我饿了"而不是"食物值不足"；"这里好黑"而不是"照明范围不足"。
3. **每句都要有一个具体的动作或画面。** "再挖一格"比"继续挖掘"好；"土往身后飞"比"挖掘效率提升"好。

反例对照：

| 不要 | 要 |
| --- | --- |
| "检测到可建造区域" | "这里能放床！" |
| "资源不足，无法建造" | "还差两块土……我去挖！" |
| "解锁新的生产设施" | "小满来了！我们可以种菜了！" |
| "当前区域照明不足" | "这里好黑，我陪你。" |

## 视觉规格（给美术）

| 项目 | 规格 |
| --- | --- |
| 碰撞体积 | 保持现有 `FRIEND_RADIUS = 13`（直径 26px），规则层不变 |
| 视觉尺寸 | 可到 32–40px（耳朵、尾巴、翅膀超出碰撞体，不影响判定） |
| 朝向 | 只需左右两个方向（现有实现就是左右翻转） |
| 动画帧 | 每个角色 3 组就够：待机（呼吸/漂浮）、移动、开心（转圈/蹦跳） |
| 关键辨识点 | 阿土=大爪子+眼镜；阿灯=尾灯+翅膀；小满=长耳朵+门牙；小泉=胡须+扁尾巴 |
| 配色原则 | 身体用现有色值，特征用对比色（阿土的爪子更深，阿灯的灯更亮） |

**先做静态立绘 + 一个待机动画即可验证**，不需要一次做全套帧。

## 下一步

如果这四位你认可，落地顺序建议：

1. **改名字与台词**（零美术成本）：先把现有 4 个圆球叫成阿土/阿灯/小满/小泉，把台词换成上面的句子。
2. **改出场顺序**（小改动）：小满改成"建好床就来"，小泉"找到水就来"。
3. **加物种特征**（美术）：先做阿土的大爪子和阿灯的尾灯——这两个辨识度最高。
4. **加阿灯的"躲藏 → 出现"**（小演出）：这是"点亮"这件事的情感落点，值得单独做。

做完第 1、2 步就能试玩，看孩子会不会开始叫他们的名字。**如果孩子开始叫名字，这条路就走通了。**
