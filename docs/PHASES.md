# 分阶段实施与验收

## P0：工程起步（仅准备，不做完整游戏）
- 读完设计文件和 v0.4 参考，指出参考实现和新设计的主要差异。
- 用 Vue 3 / TS / Vite / PixiJS 搭建可启动项目并初始化 Git。
- 独立模块：world state、map/dig rules、render/input、missions、persistence；先保持模块最小化。
- 提供 `npm run dev`、`npm run build`、`npm test` 的可用命令。

## P1：地下挖掘和第一处成就（先完成这个）
- 可缩放、可平移的固定小地图；地表风暴、地下初始避难所、棕色泥土和坚硬岩层。
- 鼠标/触屏点土只挖一格，拖动平移地图；明确点击/拖动阈值；挖错可撤销；岩石不可挖。
- 小鼹鼠仅引导一个真实目标：找到发光能源石。高亮线索但不给唯一挖法。
- 挖通并激活能源石后，能源核心启动，地下灯光显著变化，小伙伴作出回应。
- 至少有一种可保存且刷新后恢复的进度状态；错误存档不致白屏。
- 不能误挖出地图边界、绕过坚硬岩层或破坏初始核心房间。
- 自动测试覆盖可挖/不可挖、撤销、任务状态、存档往返；浏览器验证点挖和拖动互不误触。
**P1 验收：** 一个新玩家能在不阅读教程的情况下，根据场景提示完成首次“点亮家园”，并清楚感知建成前后变化。

## P2：睡眠舱建设
- 开放可建设区域，设施嵌入岩层、位置可自由选择。
- 房间尺寸与空间占用规则清晰；建筑预览、无效位置提示和撤销。
- 小伙伴进入已建睡眠舱，产生可见互动；任务根据真实设施状态完成。

## P3：泉水与水培温室
- 寻找地下泉水；建立温室和简明供水/种植链条。
- 植物经历可见生长并可收获，无意义的强制等待不计入游戏时长。
- 完成第一夜后呈现全景庆祝，玩家可以继续在已开放区域自由建造。

## P4：打磨与儿童试玩
- 测试窗口、平板横屏的点击命中率、缩放与操作反馈。
- 整理成就反馈和动态细节；增加至少一个无需任务的自主建设目标。
- 实际让孩子试玩，记录是否知道下一步、是否误挖、是否自主想继续扩建，再决定后续版本。

## 每阶段交付格式
1. 改了什么（3—5句）。
2. 如何启动/复现。
3. 执行了什么测试、结果是什么。
4. 仍有哪些已知问题。
5. Git 提交记录或可回退点。
