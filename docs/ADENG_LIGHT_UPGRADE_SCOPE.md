# 第4阶段实施小方案：阿灯的聚光灯罩

日期：2026-10-18。用户已授权继续第4阶段，并在实施途中确认继续；本记录明确此次落地的解锁、范围、操作点与旧灯关系。依据[分阶段方案](ATU_HOME_IMPLEMENTATION_PLAN.md)第4阶段，仅做阿灯一项能力。状态：工程实施和自动检查完成，实际验证及限制见[验收记录](acceptance/adeng-light-v1/README.md)。

## 玩家闭环

1. 已找到泉水、把电送到第二层，至少装过一盏普通壁灯。
2. 在该灯附近挖出已连通、可到达的空间，其中有普通壁灯尚未覆盖、聚光灯可以照到的位置。阿灯给一个可忽略的建议，不增加主线任务或强制建造点。
3. 与阿灯对话，看到“左右各2格 → 各4格”的具体效果，主动选择“学会做聚光灯罩”。不收经验、材料或食物；只能学一次。
4. 继续使用壁灯工具：点原普通灯，阿灯沿真实通路到现场加装；点合法新灯位，则安装带灯罩的新灯。动手时才改变照明，工作仍可停止。
5. 同一片洞室的覆盖范围和暖光亮度实际扩大，后续扩大空间可少装几盏灯。

## 范围与规则

- 普通灯的原光圈、基础通电亮度和已有成果保留。当前代码只有固定光圈；本阶段新增独立的覆盖计算，增强覆盖真正驱动洞室亮度，而不只放大灯图标。
- 通电后的横向覆盖从左右各2格提高为各4格；只沿已挖通、至少两格身体净空的泉水层通道传播。土和岩截断传播，未挖空间不显露；不更改挖掘权限、探索发现或地层开放条件。
- 学会的是阿灯的持久能力；每盏灯是否已加装是设施配置。旧灯不自动全部改变，不要求拆灯重装，未加装旧灯照常亮。
- 加装不占新地面、不增加资源链。重复点已加装灯只提示，不重复结算。新灯继续沿用当前合法灯位和通路判定。
- 工作输入、真实站位、取消/后台/刷新、单项工作及不强拉镜头沿用第3阶段。学会能力不瞬移阿灯，也不直接替玩家照亮整层。
- 加装可撤销为原普通灯；撤销新灯只移除该灯。已学会的能力保留，旧存档先迁移为未学会、普通旧灯，原房间、水电、角色位置和工具完整保留。
- 使用稳定能力ID `light` 与升级ID `wide-lamp-shade`；学习状态只存一份，不新增“等级”镜像。新结构使用v11并严格校验。

## 交付验证

规则测试覆盖触发条件、边界、岩土阻光、实际覆盖差异、一次学习、加装/新灯/撤销及旧档迁移；会话测试覆盖走位落手、重复点击、取消和刷新。浏览器以同一位置/镜头记录前后对照，并检查900×620、触摸、旧档和阿土/房间/三项专业工作回归。

本阶段不做小满/小泉升级、经验材料、泵站、个人卧室、厨房、第三层或全图照明。未安装普通灯或没有需要改善的空间时，继续自由探索即可；不制造变暗或断电来强推升级。
