# 第一层玩法优化建议

日期：2026-10-17
基线：v0.1.0（阶段 1、2 已实施：床数=伙伴数、遗物 ×3、引水、种植、收获、开饭）
本文只谈玩法，不含代码改动清单。

## 一句话诊断

**第一层现在是一间"样板房"，不是一台"机器"。**

样板房：灯亮着、床铺好了、朋友睡着了——然后就没有然后了。玩家做过的每一件事都是"一次性"的：灯亮了不会灭，水引上来不会用完，伙伴住进来不会提新要求，遗物挖到就结束。所以第一层在 20 分钟后就会"静止"。而一个静止的房间，无论再塞多少家具，都只是布景。

机器不一样：有输入、有运转、有输出。你调一下，它会有反应；你不管它，它会出状况。孩子会想"我再改改看"。

## 三条反馈其实是同一个根因

| 反馈 | 表面看是 | 实际缺的是 |
| --- | --- | --- |
| 第一层内容太少 | 东西不够多 | **没有新的需求产生**——所有需求都是预设的、一次性的 |
| 和后面的关卡联系不大 | 剧情没接上 | **没有物资在两层之间流动**——水引上来就断线，第二层对第一层不再有意义 |
| 挖下去动力不足 | 奖励不够好 | **没有"我需要下面"的处境**——挖之前看不见，挖之后用不上 |

三条指向同一件事：**没有任何东西在持续流动。** 没有流，就没有循环；没有循环，内容做完就死。

## 三条设计原则

1. **让已建成的东西继续"需要"玩家。** 灯要油、菜要水、朋友要吃饭——不是数值压力，而是"照顾"的乐趣。
2. **让两层互相当上游。** 第一层的建造需要第二层的材料，第二层的探索需要第一层的支持。不是"门票关系"，是"供需关系"。
3. **让下面在挖通之前就看得见。** 水汽、微光、声音、阿土的描述——先有好奇，再有行动。

## 具体建议（按性价比排序）

### 1. 伙伴愿望：让"家"持续产生需求 ★最高优先

**现在的问题**：伙伴住进来就静止了。床满了，家就"完成"了。

**建议**：每位伙伴入住时带一个**愿望气泡**（不用文字，用图标），满足后过一阵再冒下一个。

| 愿望类型 | 例子 | 需要什么 | 指向哪一层 |
| --- | --- | --- | --- |
| 物品 | 想要一盏床头灯 | 床边 2 格内放一盏灯 | 第一层 |
| 空间 | 想要一个能看到地表光的角落 | 在竖井旁挖一间房 | 第一层 |
| 食物 | 想吃一口热的 | 灶台 + 一份收成 | 第一层（要水） |
| 装饰 | 想要一盆会发光的花 | 第二层的黏土 + 发光蘑菇 | **第二层** |
| 社交 | 想和新朋友一起住 | 建第二间舱 | 第一层（要水） |

**满足愿望的回报**：一件小装饰（画/地毯/风铃）、一张图纸（解锁新设施）、或一封"介绍信"（下一位伙伴）。

**为什么有效**：
- 愿望是**内容生成器**：不用手工设计每个任务，规则会持续产出"下一件事"。
- 愿望是**情感动力**："阿土想要一盏灯"比"建造 3 个设施"有力得多，7 岁孩子吃这套。
- 愿望可以**指向第二层**："想要会发光的花"就是下行的理由，而且是玩家自己的理由，不是任务的。

**成本**：小。不需要新系统，只需要"愿望"数据 + 气泡 UI + 满足判定；复用现有建造、种植、伙伴。

---

### 2. 第二层要有"第一层造不出来的东西" ★高优先

**现在的问题**：第二层只有水和土。水引上来就结束了，土和第一层的土没区别。所以第二层是"一次性取水点"，不是"资源层"。

**建议**：给第二层三样第一层没有的东西。

| 发现物 | 在哪 | 用途 | 玩家的感受 |
| --- | --- | --- | --- |
| **发光蘑菇** | 洞壁阴湿处，成簇 | 做"蘑菇灯"：不用电、光更柔、能挂在任何地方 | "下面的光比家里的灯好看" |
| **黏土** | 泉边，颜色偏红 | 烧"陶罐"：种植槽的升级版（长得更快/能种第二种作物） | "下面的土和上面的不一样" |
| **旧避难所遗迹** | 深处洞穴，半埋在土里 | 一张照片/一本日记/一把旧钥匙——讲上一批住户的故事 | "这里以前也有人住过" |

**关键是"第一层造不出来"**：如果第二层的东西第一层也能做，就没有下去的必要。

**再加一个钩子**：遗迹旁边有一道**被堵住的裂缝**，点它阿土会说"这后面还有路，但现在过不去"——这是第三层的门，也是"这个游戏还有后面"的承诺。

**成本**：中。需要新地块、新道具、新交互，但都可以复用现有的"点一下采集"和"放一个装饰"。

---

### 3. 向下要有"预告"：挖通之前就让玩家看见 ★高优先，成本最低

**现在的问题**：岩层是黑乎乎的一片。孩子在挖通之前完全不知道下面有什么，所以"下去"只能是任务指令。

**建议**：在裂纹和岩壁上加"下面有东西"的线索。

| 线索 | 表现 | 出现时机 |
| --- | --- | --- |
| 水汽 | 白色雾状粒子从裂纹缓慢渗出 | 一开始就有，不需要任务 |
| 湿痕 | 裂纹附近的岩壁颜色更深、有水光 | 同上 |
| 声音 | 已有的水滴声，靠近时变大 | 同上 |
| 阿土的碎碎念 | "我闻到潮湿的味道……下面好像有水" | 玩家路过裂纹时触发一次 |

**为什么有效**：这三样东西加起来，就把"任务让我挖"变成"我想去看看"。7 岁孩子对"雾从缝里冒出来"的反应，比任何任务文案都强。

**成本**：很小。纯视觉 + 音效 + 一两句台词，不改任何规则。

---

### 4. 设施要有"空间要求"：让"挖什么形状"变成决策 ★中优先

**现在的问题**：睡眠舱 3×2、种植槽 1×1，只要有空地就能放。所以"挖成什么样"不重要，"挖大就行"。

**建议**：给每种设施一个"形状偏好"，让空间有取舍。

| 设施 | 要求 | 玩家要做的决策 |
| --- | --- | --- |
| 睡眠舱 | 3×2 + 门口能走（已有） | 放左边还是右边？会不会挡住去梯道的路？ |
| 种植槽 | 1×1 + **上方 2 格空**（植物要长高） | 要挖高一点，还是挖宽一点？ |
| 灶台 | 2×1 + 上方 2 格空 + **旁边有水缸** | 厨房要挨着水源 |
| 挂灯 | 上方必须是岩石（挂天花板） | 天花板在哪？走廊要不要留顶？ |
| 储物箱 | 1×1 + 旁边有地面 | 仓库放在入口还是深处？ |

**为什么有效**：空间从"免费"变成"有形状的资源"，挖土就从"清空"变成"设计"。而且这些要求都是**看得懂的**（植物要高、灯要挂起来、灶台要挨着水）。

**成本**：小。规则 + 放置预览的红/绿反馈 + 一句孩子能读懂的提示。

---

### 5. 伙伴要有"特长"：让"招人"有实际收益 ★中优先

**现在的问题**：伙伴只是"住进床里的图标"。多一位伙伴，除了热闹一点，没有任何玩法变化。

**建议**：每位伙伴入住后解锁一个"搭把手"的能力。

| 伙伴 | 特长 | 效果（温和，不卡关） |
| --- | --- | --- |
| 阿土（鼹鼠） | 挖得快 | 每挖 5 格，额外松一格（不自动挖，只是标记"这里好挖"） |
| 小满（兔子） | 会种菜 | 作物每次多长半档（或成熟后多收一份） |
| 阿灯（萤火虫） | 会修灯 | 灯的光照范围 +1，且不需要材料 |
| 小泉（水獭） | 懂水 | 第二层探索时，附近有水会冒小气泡提示 |

**为什么有效**：伙伴从"装饰"变成"进度"，"招人"从"任务"变成"想要"。而且能力可以**指向第二层**（小泉的提示让探索更顺），形成跨层价值。

**注意**：特长必须是"锦上添花"，不能是"没有就卡关"——否则会变成"必须按顺序招人"。

**成本**：中。需要能力标记 + 效果接入现有系统；建议先做 1–2 个，不要一次做四个。

---

### 6. 土是建材：让每一铲都有产出 ★中优先，需谨慎

**现在的问题**：挖土只得到"空间"。土本身是垃圾，挖开就消失了。

**建议**：挖土 → "土 +1"；建造 → 消耗土。

| 设施 | 消耗 |
| --- | --- |
| 睡眠舱 | 6 土 |
| 种植槽 | 2 土 |
| 灯 | 1 土 |
| 灶台 | 4 土 |

挖出来的土在工地旁边堆成小土堆（可视化），建造时土堆变少。

**为什么有效**：每一铲都有产出，87 格土从"要清空的障碍"变成"要攒的建材"。孩子会主动想"再挖两格就够建床了"。

**风险**：可能变成"刷土"——玩家发现"挖土 → 建东西 → 再挖土"的循环，把游戏玩成"挖土模拟器"。

**控制方法**：
- 土只能用于建造，不能换食物、不能交易。
- 建造需求随进度增长（越往后越贵），让"土"始终略紧。
- 空间本身也是稀缺的（见建议 4），所以"挖太多"会破坏布局。

**成本**：中。材料计数 + 建造消耗 + 土堆可视化 + UI。

---

### 7. 水是"流量"不是"开关" ★中优先，需谨慎

**现在的问题**：`waterSupplied` 是一个布尔值——引水一次，永久生效。水不是"资源"，是"已完成"。

**建议**：引水之后，第一层有一个**水缸**（可视化水位）。

- 种植槽每长一档消耗一点水；水缸空了，作物**停止生长**（不枯死，只是不长）。
- 回第二层点一下泉眼"打水"，水缸 +5。
- 或者造一个"小水车"（需要材料），按玩家操作次数自动缓慢补水。

**为什么有效**：水从"一次性开关"变成"需要照看的东西"，第二层从"去过一次"变成"要回去的地方"。两层之间有了**往返**。

**风险**：可能变成"跑腿"——孩子每隔几分钟就要下去打一次水，很烦。

**控制方法**：
- 水缸容量大（10 点），消耗慢（每 3 次操作消耗 1 点），所以很少需要打水。
- 水车可以自动化，让"照顾"变成"前期手动、后期自动"的成长感。
- 水缸空了只是"不长"，不是"枯死"——没有惩罚，只有"该浇水了"的提示。

**成本**：中高。需要"水量"状态 + 消耗/补充逻辑 + 水位可视化 + 存档字段。

---

### 8. 家园相册：让建设有记录 ★低优先，成本最低

**现在的问题**：玩家建了什么、发现了什么，没有任何"记录"。关掉游戏再打开，只剩一个状态，没有"故事"。

**建议**：每达成一个里程碑，相册里多一张手绘图。

| 里程碑 | 图 |
| --- | --- |
| 第一盏灯亮起 | 黑暗大厅里的一点光 |
| 第一张床建好 | 两位伙伴挤在一起睡 |
| 第一位新朋友搬来 | 大厅里站着的新面孔 |
| 第一份收成 | 手里举着一颗菜 |
| 第一次引水 | 水管从地下通上来 |
| 第一次扩建 | 从大厅望向新挖的房间 |

**为什么有效**：对 7 岁孩子，"收集"和"回忆"是很强的动力。而且相册是**免费的叙事**——不用写剧情，玩家自己会讲"这是我们家第一次亮灯的时候"。

**成本**：很小。纯 UI + 里程碑判定，不碰规则。

---

## 推荐的最小组合

如果只做一轮，建议 **1 + 3 + 2（只做"发光蘑菇"一种发现物）**：

| 建议 | 解决什么 | 为什么先做 |
| --- | --- | --- |
| 1 伙伴愿望 | 内容少、动力不足 | 内容生成器，一次投入长期产出 |
| 3 向下预告 | 动力不足 | 成本最低，立刻改变"为什么要挖" |
| 2 发光蘑菇 | 两层联系 | 一个发现物就够证明"下面有上面没有的东西" |

这三条加起来，第一层会从"20 分钟做完"变成"一直有事可做"，而且"下去"第一次有了玩家自己的理由（"阿土想要一盆会发光的花"）。

如果这一轮效果不错，下一轮再加 **4（空间要求）+ 5（伙伴特长）**，让"规划"和"招人"变得有意义。

## 一个更根本的定位问题

现在第一层更像"教学关"：教完挖土、建造、引水，就可以丢掉了。但按 GAME_BRIEF 的"长期：仍在同一张地图上经营、完善地下堡垒"，第一层应该是**永久基地**，而不是教学关。

两者的区别：

| | 教学关 | 永久基地 |
| --- | --- | --- |
| 新层开放后 | 第一层没用了 | 新层的材料要拿回第一层加工 |
| 玩家回第一层 | 没事做 | 有愿望要满足、有东西要造 |
| 内容量 | 一次性 | 随层数增长 |

如果接受这个定位，那"第二层的黏土要拿回第一层烧陶罐""第三层的矿石要拿回第一层打工具"就不是"额外内容"，而是**主线结构**。第一层的价值会随着游戏进程**增长**，而不是"打完就结束"。

## 不建议做的

| 不建议 | 原因 |
| --- | --- |
| 用"挖 N 格土"当目标 | 违反 GAME_BRIEF："禁止使用纯挖 N 块土充当主线目标" |
| 加饥饿/死亡/倒计时 | 违反"温和生存"：不死亡、不强迫在线 |
| 加随机地图 | 违反"固定小地图 + 手写蓝图"的现有结构，且会打断存档 |
| 加战斗/怪物 | AGENTS.md 明确暂缓 |
| 把"土"做成可交易货币 | 会诱导刷土，且引入经济系统超出 7 岁范围 |
| 一次把 8 条全做 | 会变成"功能堆砌"，每条都做不深；建议按上面的最小组合走 |

## 一句话总结

第一层缺的不是"更多东西"，是**"还需要"**——让已经建成的东西继续需要玩家，让下面的东西上面造不出来，让每一铲土都有去处。做到这三点，第一层就从"样板房"变成"家"。
