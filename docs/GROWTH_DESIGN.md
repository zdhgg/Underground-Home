# 成长性设计：让玩家一直在变强

> 2026-10-18 后续决策：伙伴可加入、能力可升级，但以自由探索和建设为主体，由阿土串联单一主线。候选伙伴、章节和资源模拟保留为设想，未批准全部实施。升级边界与首个验证范围以 [伙伴、主线与能力成长](PARTNER_PROGRESSION_DESIGN.md) 为准；阿灯的当前出场设定以 `CHARACTERS.md` 为准。

日期：2026-10-17
上游：`docs/GAME_DEFINITION.md`（这是"为朋友造家"的游戏）
本文回答三个问题：**小动物怎么解锁、玩法怎么变丰富、第一层和下面怎么连起来。**

---

## 0. 先定义"成长性"

成长性不等于更多内容。

- **内容**是"又多了一个可以放的东西"——玩家玩完就忘。
- **成长**是"我又会做一件以前不会做的事"——玩家记得住。

对 7 岁孩子，成长的标志只有一句话：**"我现在能做的事，比刚才多了。"**

所以本文所有的设计，都围绕一个判断标准：**它有没有给玩家一个新动词？**

现在游戏里的动词只有四个：挖、建、收、喂。其中"收"和"喂"还是同一件事的两端。这就是"成长性欠缺"的真实原因——不是内容不够，是**动词不够**。

---

## 1. 成长的三个层次

用户提的三点，正好对应三个层次：

| 层次 | 是什么 | 用户的原话 | 现在 |
| --- | --- | --- | --- |
| **横向** | 同样的玩法，更大的规模 | （隐含） | 有：87 格土、2 间舱 |
| **纵向** | 新动词、新规则 | "小动物可以解锁""玩法可以逐步丰富" | **几乎没有** |
| **跨层** | 新空间 + 双向资源流 | "第一层和下面也是有联系的" | 只有一根一次性的水管 |

**横向成长是基础，纵向成长是灵魂，跨层成长是把两者串起来的骨架。**

现在的游戏只有横向：挖更多土、建更多床。所以玩到后面会累——因为"更多"不等于"更新"。

---

## 2. 核心设计：伙伴 = 动词

这是整份文档最重要的一条。

> **每解锁一位伙伴，就解锁一个新动词。伙伴不是收集品，是能力的载体。**

理由很简单：7 岁孩子记不住"解锁了种植系统"，但记得住"小满来了，我们能种菜了"。

角色驱动的教学，比弹窗教程有效十倍——**孩子是在跟一个朋友学，不是在读说明书。**

### 首版四位（正好对应现有系统）

| 伙伴 | 物种 | 怎么遇到 | 新动词 | 玩家能做什么新事 | 对应现有代码 |
| --- | --- | --- | --- | --- | --- |
| **阿土** | 鼹鼠 | 初始 | 挖 | 挖土、指挥施工 | `core/dig.ts`、`core/exploration.ts` |
| **阿灯** | 萤火虫 | 修好核心后，被光吸引来 | 照 | 造灯、照亮暗区（看得更远） | 现有灯具 + 黑暗遮罩 |
| **小满** | 兔子 | 第一次下到泉水层，在洞穴里遇见 | 种 | 摆种植槽、收菜 | `core/farm.ts` |
| **小泉** | 水獭 | 找到泉水后，从水里冒出来 | 引 | 引水、接水管、打水 | `core/farm.ts` 引水 |

### 完整版再加三位（对应后续章节）

| 伙伴 | 物种 | 怎么遇到 | 新动词 | 玩家能做什么新事 |
| --- | --- | --- | --- | --- |
| **阿岩** | 穿山甲 | 第二层通电后，从硬岩里钻出来 | 凿 | 挖开硬岩、开新层 |
| **阿风** | 蝙蝠 | 第三层入口打开后，从黑暗里飞出来 | 探 | 探测隐藏的空洞与矿脉（不用乱挖） |
| **阿木** | 松鼠 | 攒够第一批材料后，背着工具来 | 造 | 工作台、把材料变成高级设施 |

### 为什么这个顺序是"滚雪球"

每一位伙伴的解锁条件，都是上一位伙伴的产物：

```
阿土挖出土        → 有了空间
空间 + 能源       → 阿灯来了，能造灯
光                → 看得见远处，敢往深挖
挖通岩层          → 遇见小满，知道下面有水
找到泉水          → 小泉来了，能引水
水 + 空间         → 小满能种菜
菜 + 水           → 能做饭、请客
请客              → 新伙伴愿意来
更多伙伴 + 电     → 阿岩来了，能凿硬岩
硬岩              → 第三层
第三层 + 材料     → 阿木来了，能造高级设施
```

**每一环都用上一环的产物**，所以玩家感觉"我的能力在滚"，而不是"又开了一个新面板"。

## 3. 玩法阶梯：八个阶段，八个动词

| # | 阶段 | 新动词 | 用上一个的什么 | 解锁伙伴 | 家的变化 |
| --- | --- | --- | --- | --- | --- |
| 1 | 点亮 | 修 | 挖出的能源石 | 阿灯 | 第一盏灯 |
| 2 | 安家 | 建 | 挖出的空间 | — | 第一间床 |
| 3 | 找水 | 挖通 | 建好的床（才有理由下去） | 小满（在泉水层遇见） | 听见水声 |
| 4 | 引水 | 引 | 挖通的梯道 | 小泉 | 水缸、水管 |
| 5 | 种菜 | 种 | 引上来的水 | — | 第一棵菜 |
| 6 | 做饭 | 煮 | 种出来的菜 | 新朋友 | 第一顿饭 |
| 7 | 接电 | 接 | 修好的核心 | 阿岩 | 第二层亮起来 |
| 8 | 凿深 | 凿 | 第二层的电 + 铁镐 | 阿风 | 第三层入口 |
| 9 | 加工 | 造 | 挖上来的材料 | 阿木 | 工作台、高级设施 |
| 10 | 全景 | — | 以上全部 | — | 三层通明 |

这张表就是"成长地图"。每一行都应该能回答："玩家在这一步学会了什么以前不会的？"

**如果某一行答不出来，那一行就不该存在**——它只是内容，不是成长。

## 4. 跨层联系：四根管子

用户说"第一层和下面有联系"，现在的联系只有一根（水），而且是一次性的（引上来就永久有水）。

要有联系，需要**四根管子，而且每根都是持续的**。

### 管子一：水 ↑（从下往上）

```
泉水 → 水管 → 第二层菜园水缸 → 种植槽 / 灶台
```

- **持续**：种菜、做饭会消耗水；水缸空了，作物停长。
- **玩家要做的**：回第二层打水，或者造水车自动补水。
- **为什么不是跑腿**：水缸容量大、消耗慢，水车可以自动化，前期手动、后期自动。

### 管子二：材料 ↑（从下往上）

```
第二层黏土 / 石头 / 蘑菇 → 第一层工作台 → 陶罐 / 砖 / 高级设施
第三层矿石 / 晶簇 → 第一层工作台 → 更好的工具
```

- **持续**：高级设施需要材料，材料只在下面。
- **关键**：**第一层造不出来**。如果上面也能挖到，就没有下去的必要。
- **玩家要做的**：下去采，拿上来加工。

### 管子三：电 ↓（从上往下）

```
第一层能源核心 → 电线（沿梯道）→ 第二层的灯 / 水泵 / 电梯
```

- **持续**：第二层的设施需要电才能运转；核心没修好，下面就是黑的。
- **这是现在最缺的一根**：第二层的壁灯不需要电，所以第一层对第二层"没有用"。
- **视觉**：一根发光的电线从核心顺着梯子下去，孩子一眼就懂"电在往下走"。

### 管子四：人 ⇅（双向）

```
伙伴住在第一层 → 乘梯子/电梯下楼工作 → 晚上回第一层睡觉
```

- **持续**：小满去第二层浇水，阿岩去第三层挖矿。
- **实现方式**：复用现有的"一次性演出"（`playPodEntrance` 的模式），不做持续 AI。
- **为什么重要**：人一流动，"家"就从"一张平面图"变成"一个立体的地方"。

### 为什么"电向下"是关键

这是四根管子里最能改变结构的一根：

| 没有电向下 | 有电向下 |
| --- | --- |
| 第一层是"已经完成的地方" | 第一层是"整个堡垒的总电源" |
| 第二层是"另一个地方" | 第二层是"第一层供电的车间" |
| 玩家下去是"探索" | 玩家下去是"上班" |
| 核心修好之后就没用了 | 核心永远是全家的心脏 |

**第一层不是"第一关"，是"总部的四件套"：电、水、工坊、宿舍。**

- 电：核心（给下面供电）
- 水：水缸（给种植和做饭供水）
- 工坊：工作台（加工下面的材料）
- 宿舍：睡眠舱（伙伴住这里，才能下去工作）

下面越深，越依赖第一层。这才是"地下堡垒"该有的样子。

## 5. 让成长看得见

对 7 岁孩子，"我在变强"必须是**画面上能看出来的**，不能只是一个数字。

| 信号 | 从 → 到 | 玩家感受到 |
| --- | --- | --- |
| **家的样子** | 一个洞 → 一层楼 → 三层堡垒 | "我的家变大了" |
| **伙伴数量** | 1 位 → 4 位 → 7 位 | "家里越来越热闹" |
| **灯光** | 一盏 → 一层 → 三层通明 | "我把黑暗赶走了" |
| **深度尺** | 第 1 层 → 第 1–2 层 → 第 1–3 层 | "我挖得越来越深" |
| **工具** | 手 → 小铁镐 → 钻机 | "我的手变强了" |
| **能力图标** | 挖 → 挖/照/种/引/凿/探/造 | "我会的事变多了" |

前五个是"看得见的世界变化"，最后一个才是"UI"。**优先做前五个。**

## 6. 节奏：一次只给一个新东西

7 岁孩子的学习节奏是"学一个 → 用一次 → 再学下一个"。

- **不要**在同一个节点同时解锁两个东西（比如"找到水"同时给"引水"和"种植"）。
- **要**让新东西先被"用一次"，再给下一个。

具体节奏建议：

| 时间 | 新增 |
| --- | --- |
| 0–5 分钟 | 挖（阿土） |
| 5–10 分钟 | 修（点亮）→ 阿灯来 |
| 10–15 分钟 | 建（床）→ 小满来 |
| 15–20 分钟 | 挖通（找水） |
| 20–25 分钟 | 引（水）→ 小泉来 |
| 25–30 分钟 | 种（第一棵菜） |
| 30–35 分钟 | 煮（第一顿饭）→ 新朋友 |
| 35 分钟以后 | 每 10–15 分钟一个新东西 |

**第一章的目标是让玩家在 30 分钟内学会 6 个动词**，并且每个动词都用过一次。

## 7. 与现有实现的差距

| 设计 | 现在有什么 | 差什么 | 成本 |
| --- | --- | --- | --- |
| 伙伴 = 物种 | 4 个颜色的圆球（`FRIEND_COLORS`） | 物种形象（耳朵/尾巴/特征） | 中（美术） |
| 伙伴 = 动词 | 伙伴住进床就不动 | 能力标记 + 解锁条件 + 一次"教你"的演出 | 中 |
| 照（灯） | 有灯、有黑暗遮罩 | 灯要"照得更远"（现在是装饰） | 小 |
| 引（水） | 有引水（一次性） | 水要"持续"（水缸水位） | 中 |
| 种（菜） | 有种植（操作驱动） | 不够"小满教的"，缺角色 | 小 |
| 煮（饭） | 有"请大家吃饭" | 没有灶台，吃饭是按钮不是设施 | 中 |
| 接（电） | 只有第一层亮 | 第二层没有需要电的设施 | 中 |
| 凿（硬岩） | 有裂纹岩 + 铁镐 | 硬岩还不能挖 | 中 |
| 探（探测） | 无 | 新系统 | 大 |
| 造（工作台） | 无 | 材料系统 + 加工 | 大 |

**先做"小"和"中"，"大"留到后面。** 具体见下一节。

## 8. 分章实施

### 第一章（首版）：四位伙伴，六个动词

- 阿土（挖）、阿灯（照）、小满（种）、小泉（引）
- 新增：灯的照明范围、水缸水位、伙伴的物种形象
- 不做：灶台、接电、硬岩、探测、工作台
- 验收：孩子能说出"小满来了我们就能种菜了"

### 第二章：电向下（第一版已实施 · 2026-10-18）

**已做**：

| 内容 | 说明 |
| --- | --- |
| 状态与规则 | `world.powerDown`；`core/power.ts` 只放三个纯函数（能不能送、送、电线路径）；存档升到 **v7**，v6 旧档按"还没送电"读入 |
| 送电委托 | 第一夜做完后出现 **「⚡ 把电送到下面」**：阿土从当前位置走回梯道，通电；中断会自动解锁按钮 |
| 电线 | 核心 → 大厅地面 → 梯道 → 第二层，一条会呼吸的发光折线；送电瞬间一颗白光沿线跑下去 |
| 第二层点亮 | 黑暗遮罩从 `0.43` 渐变到 `0.05`（`powerLevel`，比第一层慢一点，像电流真的爬下去） |
| 壁灯 | 通电前只有一点余光（44px / 0.13），通电后真的亮起来（62px / 0.22） |
| 引导 | 第 9 步"把家里的电送到下面"；`finished` 需要送电，第一夜才算真的过完 |

**没做**：第二层"需要电才能运转"的设施（水泵 / 电梯）、阿岩（凿硬岩）登场。

**验收**：孩子能说出"下面的灯是家里的电送下去的"。

### 第三章：材料与工坊

- 第二层：黏土、石头、蘑菇
- 第一层：工作台（加工）
- 阿木（造）登场
- 验收：孩子会主动"下去采材料，上来做东西"

### 第四章：更深的探索

- 第三层入口、硬岩、探测
- 阿风（探）登场
- 验收：孩子会为了"看看下面有什么"而挖

## 9. 最小验证

和 `GAME_DEFINITION.md` 一样，先验证再加码。

**第一步（不动规则）**：给现有 4 位伙伴起名字、画物种特征、在入住时说一句"我能帮你做什么"。
→ 看孩子会不会说"小满是种菜的"。

**第二步（加一个能力）**：让阿灯的灯真的"照得更远"（照明范围随灯数量增加）。
→ 看孩子会不会主动造灯。

**第三步（加一个持久资源）**：水缸有水位，种菜会消耗。
→ 看孩子会不会主动回第二层打水。

三步都成立，再谈"电向下"和"工作台"。

## 一句话

**成长不是"内容变多"，是"我会的事变多"。**

每解锁一位伙伴，就解锁一个动词；每个动词都用上一个动词的产物；每根管子都让上下两层互相需要。

做到这三点，第一层就不是"第一关"，而是**整个堡垒的心脏**。
