# 首次突破岩层：实施决策与风险

基线：v0.1.0 / a608467；开发分支：`codex/first-spring-breakthrough`。依据 AGENTS.md、GAME_BRIEF v0.5、PHASES、DEPTH_PROTOTYPE_SCOPE 和 SPACE_DEPTH_REVIEW。此分支为下一阶段试玩，未发布。

## 最小闭环

1. 先完成原有点灯、第一间双人睡眠舱和入住。任务随后转到水声线索，建设不会直接解锁楼层。
2. 地板有两处可见裂纹（x=16、27）。挖通其上方地面，再点击裂纹检查水汽；播放轻微滴水提示。旧舱挡住右翼或梯口时，引导选择左侧，第一层舱位不移动。
3. 明确点一次“换上小铁镐”。只解锁裂纹岩，灰蓝坚硬基岩保持不可挖。所选岩脉从上到下逐格挖掘；每挖一格同时接好一段简易木梯，无建材计数和等待。
4. 通道连到 y=21 的地面后，点“沿梯子下去”。阿土的路线仅走有地面承托的水平空格和真实梯列。只有抵达回调完成，才允许第二层挖掘；“向下看看”一直只是镜头操作。
5. 地面开路逐步推进迷雾，泉水先隐藏，随后露出。点击泉水，阿土沿已挖地面走到水边才完成发现。冷色洞壁、蘑菇、苔藓和短暂庆祝区分新区域。
6. 到此闭环完成。可继续向两侧自由挖宽，安放可撤销的小壁灯。阿土可从当前地面位置走回梯脚、爬回第一层；两位睡眠舱伙伴继续休息，不添加居民 AI。

## 空间与建造

保留 44×28 连续地图，第一层全部原布局及 y9–11 的三格住宅层高；大厅、核心、地表入口均不改。第一层 y12 地板仅两列变为弱岩。第二层以 y19–21、x3–40 的连续建设带为基础，保留局部 y18 的天然高顶，y22 为不可挖的共用实心底面。岩脉延伸至天然洞顶，梯子一直落到共同地面。

本轮第二层的建设内容限定为嵌入洞壁的小壁灯，选址不预设，不挡交通。不开放新的睡眠舱入住、温室、生产设施或第三层。首次检查后选择一条梯道；本轮不做多条梯道同时经营。

## 风险与处理

| 检查发现 | 本轮处理 |
| --- | --- |
| v0.1.0 完全封锁第二层且提前直接展示泉水 | 替换为现场线索、工具门槛、实际交通和渐进探索 |
| 原撤销只恢复成泥土 | 历史记录挖前材质，裂纹岩恢复为裂纹岩 |
| 误撤销可能埋人或切断返程 | 保护脚下、已使用梯道、泉水通路、壁灯通路、梯口到大厅的地面路径；保护已用于启动探索的第一间舱 |
| 各种首层自由舱位可能封住单侧道路 | 两侧分别设突破口；指引检查舱体是否占住右翼地面，检查线索要求真实可走到 |
| 角色沿通用空格 BFS 会浮空或穿墙 | 探索专用的落地行走 + 梯列竖直连接，不使用入住演出的贴墙爬行 |
| 演出期间改地图会使路线失效 | 阿土移动期间暂停挖掘、建造、升级和撤销；返回回调后恢复 |
| 开新玩法会覆盖已发布进度 | 独立 v5 数据库；主动复制 v4 只读来源，第一层瓦片、舱、点灯进度保留，下部原先不可玩的蓝图更新；拒绝损坏档且禁止覆盖 |
| 复制时存在异步写入竞争 | 复制时暂停操作并清掉待存计时器；新档保存成功才替换当前世界 |
| 深层规则增加渲染器职责 | 探索、路径、可达和壁灯规则在 core/exploration；迷雾、裂纹、梯子和阿土画面在 render/explorationScene；session 只组合交互 |

未加依赖，不读取或提交密钥。更早的 `underground-home` 正式库不访问，v0.1.0 原型库 `underground-home-depth-prototype-v2` 仅在明确复制时只读访问。新分支从不向旧库保存。
