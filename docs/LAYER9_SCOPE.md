# 第九章 · 地心暖光（终章）

2026-10-26。用户授权设计并实现第九章。本章完成九层故事，回馈前八层的建设与九位既有伙伴。完成后持续自由建设，不开启第十层，也不要求全收集。

## 终章流程

第八章完成 → 检查泛金色的暖晶接缝 → 阿岩装护框 → 沿真实梯道逐格凿岩 → 阿土实际下到第九层 → 走近天然暖晶 → 同一面板读阿土的说明、确认留在原处继续建家 → 阿木接通第九站电梯 → 自由布置地心暖光台、九人暖屋长桌、九层纪念壁 → 阿灯调反光片、阿木接牢暖光 → 小满从花园旁取共享粮仓食物并送达 → 小泉在回廊装清水、团团实际送达 → 铃铃从工区带来新风铃 → 苔苔铺菌叶花边 → 阿土放好九层故事 → 玩家选“灯光暖屋”或“菌叶花园”，确认后由铃铃布置 → 九位伙伴各自沿实际通路赴席，到齐才开席 → 玩家主动拉远镜头 → 手动翻看九页家园回忆 → 确认终章，保存完成态 → 后日谈自由建设。

九页回忆对应九层，由对应伙伴各讲一段短故事。没有自动翻页、倒计时或强制返回镜头；收起后保留已读页，回来继续。已完成后可在纪念壁重读、再次看全景、改长桌布置、再办暖屋日、坐一坐或继续挖土建家。

每位伙伴都有实际用途：阿土探索和留故事、阿灯引光、小满送收成、小泉装水、阿岩凿岩、阿木建造与接台、苔苔铺菌叶、团团送清水、铃铃送风铃和布置。九人聚餐名单与四层原六人宴名单分开，稳定 ID 和床位顺序不变。

## 自由建设和旧层联系

地图为 **44×112**，新净空 y103—106，地板 y107，暖晶岩盖 y95—102。前八层的前 100 行蓝图保持，x16／x27 两条既有梯口都能接入。天然暖晶固定在右侧原岩壁，设施可自行选择位置与建造顺序。

| 设施／动作 | 费用 | 行为 |
| --- | --- | --- |
| 暖晶护框 | 石料 3、旧木料 2、部件 1 | 只开放最后一段新梯道 |
| 第九站电梯 | 部件 2、晶簇 1 | 旧八站保留，九层之间实际乘坐 |
| 地心暖光台 | 石料 4、旧木料 1、部件 2、晶簇 1 | 宽 4，嵌岩反光装置，天然暖晶不移走 |
| 九人暖屋长桌 | 石料 4、旧木料 5、部件 1 | 宽 10，九个不同座位，前侧通行 |
| 九层家园纪念壁 | 石料 3、旧木料 2 | 宽 4，九格故事记录，不要求全收藏 |
| 暖晶小憩石凳 | 石料 2、旧木料 2 | 宽 3，可选、可重复休息 |
| 送食物 | 共享粮仓食物 1 | 小满到五层菌床旁装粮，实际送到九层才扣除 |
| 送清水 | 回廊存水 1 格 | 小泉在六层装水，团团实际送达后才扣除 |
| 风铃／菌叶／故事／换布置 | 不额外收费 | 使用既有本领与设施，不建立新资源链 |
| 九人开席 | 消耗已送达的备餐 | 不再次扣粮仓或池水；到齐才记录聚餐 |

主线三种设施各一件，可选石凳一件。需要四格高、有实心地板、连到梯口的洞壁；不得占梯口、重叠或穿岩。后侧设施和插画不占前侧通行。长桌可放左翼或右翼，不使用唯一固定蓝图。

食物来自共享粮仓，并非到花园凭空收获；不足时可回原菜园或菌床继续生产。清水不足时回蓄水回廊关闸蓄水。各有一份待开席备餐，重复点击不重复扣费；食物／水途中取消不损失，已送到的另一份保留。风铃为工区新作，不移走四层大厅既有作品；不消耗或覆盖七层待送作品状态。

九层暖光标记沿实际已经开通的梯道绘制，原有供电、水路和风路继续运行，不模拟地热、电网或光线穿岩。新接缝只需检查和护框，不破坏旧家，不加入伤害、塌方、战斗、倒计时或后端。

## 单一关注对象与交接

| 情境 | 当前关注对象 | 唯一主要操作 | 退出方式 | 完成后的交接 |
| --- | --- | --- | --- | --- |
| 接缝／凿盖 | 当前接缝或这一段阿岩施工 | 检查、护框、凿岩之一；施工时无推进按钮 | 收起、Esc、停下来 | 下一段／实际下楼 |
| 暖晶发现 | 原岩壁暖晶与阿土 | 先走近，读完后确认留在原处继续建家 | 收起、Esc | 短说明后交电梯与建设 |
| 设施选址 | 当前设施的一个位置框 | 就在这里建造 | 收起、Esc，不扣料 | 建成后下一目标 |
| 引暖光 | 当前暖光台 | 请阿灯和阿木接好 | 停下来／收起 | 九层标记亮起，交备餐 |
| 跨层送物 | 当前搬运伙伴与这一份物品 | 开始；途中无推进按钮 | 停下来、收起、后台取消 | 到长桌才写进度，再交下一份 |
| 布置 | 当前长桌与一个待选主题 | 确认布置暖屋日 | 收起，实际布置不变 | 铃铃完成后交赴席 |
| 九人暖屋日 | 同一张长桌和赴席进度 | 邀请；途中无推进按钮 | 停下来、收起 | 九人到齐才开席，交主动回望 |
| 九层回望 | 全剖面与当前一页回忆 | 下一页，最后确认终章 | 收起、Esc、拖图、缩放 | 已读页保存，终章庆典接自由建设 |
| 后日谈 | 当前设施或当前相册页 | 下一页／休息／一次备餐／开席之一 | 收起、Esc、停止 | 保留 20/20，可再换目标 |

主题选择、折叠建设、相册重读与九站电梯为辅助操作。主要面板与主按钮分别使用 `data-attention-panel` 和 `data-primary-action`，真实 App 测试验证状态替换。移动端楼层导航改为两行五列，每项保持 44px 高，避免十个入口挤在一行；面板说明内部滚动，主操作／停止按钮固定。

九位赴席角色使用各自的实际行走轨道并行移动，逐个到达、逐个计数；九个座位不同，到齐并完成开席动作才写聚餐。取消或过期／重复回调不能补完成。跨层搬运抵达仅在玩家未接管镜头时定位长桌；玩家拖图／收起后不抢回。主动回望没有自动镜头返回，翻页不反复定位。

## 存档、撤销与完成态

存档升级 **v23**，支持真实 v22 44×100 及更早各层尺寸，只追加蓝图与空终章状态，不修改输入。保存护框、设施、自然暖晶、九站、备餐、搬运／聚餐次数、布置、已读页和永久完成态；不保存半段动画或待确认主题。损坏存档继续明确反馈加载失败。

备餐计数严格满足“送达次数 = 已开席次数 + 当前备餐一份”，禁止伪造重复产出。未开席不能回望，未翻完九页不能完成。完成后再聚餐或换布置不回退通关，继续游戏页明确显示“九层家园 · 终章已完成”。

本会话内可按依赖撤销建造、送达备餐和布置，退还材料／食物／清水；清水池已满时不允许溢出退款。已用电梯延长、新梯道、暖晶和所需通路受保护。开席、已读回忆和终章属于里程碑，不撤回已经吃掉的备餐或永久成就。
